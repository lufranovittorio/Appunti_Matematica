30.10 Convexity and the geometric Hahn–Banach theorem032X

Complete. This chapter is written; its proofs await independent checking.

In the plane, two disjoint convex sets, one of them open, can be separated by a line. In a normed space \(X\) the role of lines is played by the real hyperplanes \(\{ x : \operatorname {Re}\Lambda (x) = c\} \) for \(0 \neq \Lambda \in X^*\) and \(c \in \mathbb {R}\), and the separation theorem is a geometric form of the Hahn–Banach theorem. It needs the following version of the extension theorem, in which the seminorm is replaced by a sublinear function.

032Y Lemma 30.10.1

Let \(X\) be a real vector space and \(p \colon X \to \mathbb {R}\) sublinear: \(p(x + y) \leq p(x) + p(y)\) and \(p(tx) = tp(x)\) for \(t \geq 0\). If \(\ell \) is a linear functional on a subspace \(Y\) with \(\ell \leq p\) on \(Y\), there is a linear functional \(L\) on \(X\) extending \(\ell \) with \(L \leq p\) on \(X\).

Proof â–¼

This is the real case of the proof of Theorem 30.4.1, which uses only these two properties; we repeat it. By Zorn’s lemma there is a maximal extension \((Z, m)\) with \(m \leq p\) on \(Z\), extensions being ordered by inclusion of graphs. Suppose \(x \notin Z\). For \(z, z^{\prime } \in Z\), \(m(z) + m(z^{\prime }) = m(z + z^{\prime }) \leq p(z + x) + p(z^{\prime } - x)\), so \(a = \sup _{z^{\prime } \in Z}(m(z^{\prime }) - p(z^{\prime } - x)) \leq b = \inf _{z \in Z}(p(z + x) - m(z))\). Choose \(c \in [a, b]\) and put \(m(z + tx) = m(z) + tc\). For \(t {\gt} 0\), \(m(z) + tc = t(m(z/t) + c) \leq tp(z/t + x) = p(z + tx)\) since \(c \leq b\); for \(t = -s {\lt} 0\), \(m(z) - sc = s(m(z/s) - c) \leq sp(z/s - x) = p(z - sx)\) since \(c \geq a\). This contradicts maximality.

032Z Lemma 30.10.2 Minkowski functional

Let \(C\) be an open convex subset of a real normed space \(X\) with \(0 \in C\), and \(p_C(x) = \inf \{ t {\gt} 0 : x \in tC\} \). Then \(p_C\) is sublinear, \(0 \leq p_C(x) \leq \| x\| /r\) if \(B(0, r) \subseteq C\), and \(C = \{ x : p_C(x) {\lt} 1\} \).

Proof â–¼

If \(t {\gt} \| x\| /r\), then \(\| x/t\| {\lt} r\), so \(x \in tC\); hence \(p_C(x) \leq \| x\| /r\). If \(x \in tC\) and \(t^{\prime } {\gt} t\), then \(x/t^{\prime } = \frac{t}{t^{\prime }}(x/t) + (1 - \frac{t}{t^{\prime }})0 \in C\) by convexity, so \(x \in t^{\prime }C\). Since \(x \in tC\) if and only if \(sx \in stC\), \(p_C(sx) = sp_C(x)\) for \(s {\gt} 0\) (and trivially for \(s = 0\)). Given \(\varepsilon {\gt} 0\), put \(s = p_C(x) + \varepsilon \) and \(s^{\prime } = p_C(y) + \varepsilon \); then \(x/s, y/s^{\prime } \in C\) and

\[ \frac{x + y}{s + s^{\prime }} = \frac{s}{s + s^{\prime }}\cdot \frac xs + \frac{s^{\prime }}{s + s^{\prime }}\cdot \frac{y}{s^{\prime }} \in C, \]

so \(p_C(x + y) \leq p_C(x) + p_C(y) + 2\varepsilon \). If \(x \in C\), then \((1 + \delta )x \in C\) for small \(\delta {\gt} 0\) as \(C\) is open, so \(p_C(x) \leq 1/(1 + \delta ) {\lt} 1\); if \(p_C(x) {\lt} 1\), then \(x \in tC\) for some \(t {\lt} 1\), hence \(x \in C\).

For the unit ball, \(p_C\) is the norm; in general \(p_C\) is the “norm” whose unit ball is \(C\), possibly asymmetric.

0330 Theorem 30.10.3 Separation of convex sets

Let \(A\) and \(B\) be nonempty disjoint convex subsets of a normed space \(X\) over \(\mathbb {K}\).

  1. If \(A\) is open, there are \(\Lambda \in X^*\) and \(c \in \mathbb {R}\) with \(\operatorname {Re}\Lambda (a) {\lt} c \leq \operatorname {Re}\Lambda (b)\) for all \(a \in A\), \(b \in B\).

  2. If \(A\) is compact and \(B\) is closed, there are \(\Lambda \in X^*\) and \(c_1 {\lt} c_2\) with \(\operatorname {Re}\Lambda (a) \leq c_1 {\lt} c_2 \leq \operatorname {Re}\Lambda (b)\) for all \(a \in A\), \(b \in B\).

Proof â–¼

Suppose first \(\mathbb {K} = \mathbb {R}\). (1) Fix \(a_0 \in A\), \(b_0 \in B\), put \(x_0 = b_0 - a_0\) and \(C = A - B + x_0 = \{ a - b + x_0\} \). Then \(C\) is convex, open (a union of translates of the open set \(A\)), contains \(0\), and does not contain \(x_0\), since \(A \cap B = \emptyset \). Choose \(r {\gt} 0\) with \(B(0, r) \subseteq C\), and let \(p = p_C\) be the Minkowski functional of \(C\) (Lemma 30.10.2), so \(p(x_0) \geq 1\). On \(\mathbb {R}x_0\) define \(\ell (tx_0) = t\); then \(\ell (tx_0) \leq tp(x_0) = p(tx_0)\) for \(t \geq 0\), and \(\ell (tx_0) \leq 0 \leq p(tx_0)\) for \(t {\lt} 0\). By Lemma 30.10.1, \(\ell \) extends to a linear \(\Lambda \leq p\) on \(X\). Then \(\Lambda (x) \leq p(x) \leq \| x\| /r\) and \(-\Lambda (x) = \Lambda (-x) \leq \| x\| /r\), so \(\Lambda \in X^*\). For \(a \in A\) and \(b \in B\), \(\Lambda (a) - \Lambda (b) + 1 = \Lambda (a - b + x_0) \leq p(a - b + x_0) {\lt} 1\), so \(\Lambda (a) {\lt} \Lambda (b)\). Let \(c = \inf _{b \in B}\Lambda (b)\), so \(\Lambda (a) \leq c \leq \Lambda (b)\). Since \(\Lambda \neq 0\), choose \(v\) with \(\Lambda (v) = 1\); for \(a \in A\), \(a + sv \in A\) for small \(s {\gt} 0\), so \(\Lambda (a) + s \leq c\), and \(\Lambda (a) {\lt} c\).

(2) The continuous function \(a \mapsto \operatorname {dist}(a, B)\) is positive on the compact set \(A\), since \(B\) is closed, so it has a positive minimum \(\delta \). The set \(A^{\prime } = A + B(0, \delta /2)\) is open, convex and disjoint from \(B\). By (1) there are \(\Lambda \neq 0\) and \(c\) with \(\Lambda (a + u) {\lt} c \leq \Lambda (b)\) for \(a \in A\), \(\| u\| {\lt} \delta /2\), \(b \in B\). Taking the supremum over \(u\) gives \(\Lambda (a) + \frac{\delta }{2}\| \Lambda \| \leq c\), so (2) holds with \(c_1 = \sup _A\Lambda \leq c - \frac\delta 2\| \Lambda \| \) and \(c_2 = c\).

If \(\mathbb {K} = \mathbb {C}\), regard \(X\) as a real normed space, and let \(\Lambda _\mathbb {R}\) be the real functional just constructed. Then \(\Lambda (x) = \Lambda _\mathbb {R}(x) - i\Lambda _\mathbb {R}(ix)\) is complex linear, as \(\Lambda (ix) = \Lambda _\mathbb {R}(ix) + i\Lambda _\mathbb {R}(x) = i\Lambda (x)\), with \(\operatorname {Re}\Lambda = \Lambda _\mathbb {R}\); and it is bounded, since for \(|\Lambda (x)| = e^{-i\theta }\Lambda (x) = \Lambda (e^{-i\theta }x)\) this number is real, hence equal to \(\Lambda _\mathbb {R}(e^{-i\theta }x) \leq \| \Lambda _\mathbb {R}\| \, \| x\| \).

The compactness in (2) cannot be weakened to closedness: in \(\mathbb {R}^2\) the closed convex sets \(\{ y \leq 0\} \) and \(\{ y \geq e^x\} \) are disjoint, and every line separating them is horizontal, with \(\{ y = 0\} \) the only one; no line separates them strictly.

0331 Corollary 30.10.4 Mazur

Let \(X\) be a normed space.

  1. A convex subset of \(X\) is weakly closed if and only if it is norm closed.

  2. If \(x_n \rightharpoonup x\) weakly, then for every \(k\) there is a convex combination \(y_k\) of \(x_k, x_{k+1}, \ldots \) (a finite one) with \(\| y_k - x\| {\lt} 1/k\); in particular \(y_k \to x\) in norm.

  3. If \(x_n \rightharpoonup x\), then \(\| x\| \leq \liminf _n\| x_n\| \).

  4. A subspace \(M \subseteq X\) is dense if and only if every \(\Lambda \in X^*\) vanishing on \(M\) is zero.

Proof â–¼

(1) Every \(\Lambda \in X^*\) is norm continuous, so weakly open sets are norm open, and weakly closed sets norm closed. Conversely let \(C\) be convex and norm closed, and \(x \notin C\). By Theorem 30.10.3(2) applied to \(\{ x\} \) and \(C\) there are \(\Lambda \) and \(c_2\) with \(\operatorname {Re}\Lambda (x) {\lt} c_2 \leq \operatorname {Re}\Lambda (y)\) for \(y \in C\); the weakly open set \(\{ y : \operatorname {Re}\Lambda (y) {\lt} c_2\} \) contains \(x\) and misses \(C\). So the complement of \(C\) is weakly open.

(2) The norm closure \(K\) of the convex hull of \(\{ x_n : n \geq k\} \) is convex (the closure of a convex set is convex) and norm closed, hence weakly closed by (1); it contains \(x_n\) for \(n \geq k\), hence the weak limit \(x\) (if \(x \notin K\), a weakly open neighbourhood of \(x\) missing \(K\) would contain \(x_n\) for large \(n\)). So \(x\) is a norm limit of convex combinations of the \(x_n\), \(n \geq k\).

(3) By Theorem 30.4.1 there is \(\Lambda \) with \(\| \Lambda \| = 1\) and \(\Lambda (x) = \| x\| \); then \(\| x\| = \lim _n|\Lambda (x_n)| \leq \liminf _n\| x_n\| \).

(4) If \(M\) is dense and \(\Lambda |_M = 0\), then \(\Lambda = 0\) by continuity. If \(\overline{M} \neq X\), choose \(x \notin \overline{M}\) and separate \(\{ x\} \) from the closed subspace \(\overline{M}\) as in (1): \(\operatorname {Re}\Lambda (x) {\lt} c_2 \leq \operatorname {Re}\Lambda (m)\) for \(m \in \overline{M}\). Applying this to \(tm\) for all real \(t\) shows \(\operatorname {Re}\Lambda = 0\) on \(\overline{M}\), hence \(\Lambda = 0\) on \(\overline{M}\) (for \(\mathbb {K} = \mathbb {C}\) use \(\Lambda (m) = \operatorname {Re}\Lambda (m) - i\operatorname {Re}\Lambda (im)\)); and \(\Lambda \neq 0\) because \(\operatorname {Re}\Lambda (x) {\lt} c_2 \leq 0\).

0332 Example 30.10.5

The weak closure of the sphere. Let \(X\) be an infinite-dimensional normed space, \(S = \{ \| x\| = 1\} \) and \(\overline{B} = \{ \| x\| \leq 1\} \). Then the weak closure of \(S\) is \(\overline{B}\). Indeed \(\overline{B}\) is convex and norm closed, hence weakly closed by Mazur’s theorem, and contains \(S\). Conversely, let \(\| x\| {\lt} 1\) and let \(V = \{ y : |\Lambda _i(y - x)| {\lt} \varepsilon , \ i = 1, \ldots , k\} \) be a basic weak neighbourhood of \(x\). The subspace \(N = \bigcap _i\ker \Lambda _i\) is the kernel of the linear map \(X \to \mathbb {K}^k\), \(y \mapsto (\Lambda _i(y))_i\), so it has codimension at most \(k\) and contains some \(v \neq 0\). The continuous function \(t \mapsto \| x + tv\| \) on \([0, \infty )\) is less than \(1\) at \(t = 0\) and tends to infinity, so it takes the value \(1\) at some \(t\), and \(x + tv \in S \cap V\). So the norm-closed set \(S\) is not weakly closed: for instance an orthonormal sequence in a Hilbert space lies on \(S\) and converges weakly to \(0\) (Counterexample 30.9.3). This also shows that in (3) of the corollary the inequality can be strict.

0333 Proposition 30.10.6 The direct method

Let \(H\) be a separable Hilbert space and \(F \colon H \to \mathbb {R}\) a continuous convex function with \(F(x) \to \infty \) as \(\| x\| \to \infty \). Then \(F\) attains its minimum.

Proof â–¼

Let \(m = \inf F\), possibly \(-\infty \) a priori, and choose \(x_n\) with \(F(x_n) \to m\). Since \(F\) is coercive, \((x_n)\) is bounded, and by the Banach–Alaoglu theorem for Hilbert spaces (Theorem 30.9.2) a subsequence converges weakly to some \(x\). For every \(t {\gt} m\) the sublevel set \(\{ F \leq t\} \) is convex (by convexity of \(F\)) and norm closed (by continuity), hence weakly closed by Corollary 30.10.4(1); it contains \(x_n\) for \(n\) large, hence the weak limit \(x\). So \(F(x) \leq t\) for every \(t {\gt} m\), and \(F(x) = m\); in particular \(m {\gt} -\infty \).

This is the abstract form of Dirichlet’s principle: to solve a boundary value problem, minimise an energy such as \(\int |\nabla u|^2\) over a suitable Hilbert space. Weak compactness gives a weak limit of a minimising sequence, convexity makes the energy weakly lower semicontinuous, and it remains to show that the minimiser is a smooth solution, which is a regularity question. In Hodge theory the harmonic representative of a cohomology class is likewise the closed form of least energy in its class (Chapter 43). The theorem holds more generally in reflexive Banach spaces, for instance in \(L^p\) with \(1 {\lt} p {\lt} \infty \), by Kakutani’s theorem (Corollary 30.11.8 below). Without convexity the conclusion fails: on \(\ell ^2\) the function \(F(x) = (\| x\| ^2 - 1)^2 + \sum _n2^{-n}|x_n|^2\) is continuous and coercive, and \(F(e_N) = 2^{-N} \to 0\), but \(F {\gt} 0\) everywhere, since \(F(x) = 0\) would require both \(\| x\| = 1\) and \(x = 0\).
