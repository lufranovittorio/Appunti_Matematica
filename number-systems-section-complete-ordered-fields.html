4.7 Complete ordered fields009Q

Complete. This chapter is written; its proofs await independent checking.

009R Definition 4.7.1

An ordered field \(K\) is complete if every nonempty subset of \(K\) that is bounded above has a least upper bound (supremum) in \(K\). It is Archimedean if for every \(x \in K\) there is \(n \in \mathbb {N}\) with \(x {\lt} n\).

009S Lemma 4.7.2

In a complete ordered field every nonempty subset bounded below has a greatest lower bound (infimum), namely \(\inf A = -\sup (-A)\). If \(A, B\) are nonempty and bounded above, then \(\sup (A + B) = \sup A + \sup B\), where \(A + B = \{ a + b : a \in A, b \in B\} \); if moreover \(A\) and \(B\) consist of positive elements, then \(\sup (AB) = \sup A \cdot \sup B\).

Proof â–¼

The first claim is clear since \(x \mapsto -x\) reverses the order. Let \(s = \sup A\), \(t = \sup B\). Clearly \(s + t\) is an upper bound of \(A + B\). If \(u {\lt} s + t\), then \(u - t {\lt} s\), so there is \(a \in A\) with \(a {\gt} u - t\); then \(u - a {\lt} t\) and there is \(b \in B\) with \(b {\gt} u - a\), so \(a + b {\gt} u\). For products, \(st\) is an upper bound of \(AB\) by Lemma 4.3.4(2). If \(0 {\lt} u {\lt} st\), then \(u/t {\lt} s\), so some \(a \in A\) has \(a {\gt} u/t\), and then \(u/a {\lt} t\) and some \(b \in B\) has \(b {\gt} u/a\), so \(ab {\gt} u\). Upper bounds \(u \leq 0\) are not smaller than \(st {\gt} 0\).

009T Proposition 4.7.3

A complete ordered field is Archimedean. In an Archimedean ordered field, \(\mathbb {Q}\) is dense: for all \(x {\lt} y\) there is \(q \in \mathbb {Q}\) with \(x {\lt} q {\lt} y\).

Proof â–¼

If \(\mathbb {N}\subseteq K\) were bounded above, let \(s = \sup \mathbb {N}\). Then \(s - 1\) is not an upper bound, so \(n {\gt} s - 1\) for some \(n \in \mathbb {N}\), and \(n + 1 {\gt} s\); contradiction.

Let \(K\) be Archimedean and \(x {\lt} y\). Choose \(n \in \mathbb {N}\) with \(n {\gt} (y - x)^{-1}\), so \(ny {\gt} nx + 1\). The set of integers \(m\) with \(m {\gt} nx\) is nonempty and bounded below (both by the Archimedean property applied to \(\pm nx\)), so it has a least element \(m\) by Theorem 4.4.2. Then \(m - 1 \leq nx\), so \(nx {\lt} m \leq nx + 1 {\lt} ny\), and \(q = m/n\) works.

009U Proposition 4.7.4

Let \(K\) be a complete ordered field, \(x \in K\) with \(x \geq 0\), and \(n \geq 1\). There is a unique \(y \in K\) with \(y \geq 0\) and \(y^n = x\). We write \(y = \sqrt[n]{x}\), or \(\sqrt{x}\) if \(n = 2\). In particular the non-negative elements of \(K\) are exactly the squares.

Proof â–¼

Uniqueness: if \(0 \leq y_1 {\lt} y_2\) then \(y_1^n {\lt} y_2^n\). For existence we may assume \(x {\gt} 0\) and \(n \geq 2\) (for \(n = 1\) take \(y = x\)). For \(0 {\lt} a {\lt} b\) we have \(b^n - a^n = (b - a)(b^{n-1} + b^{n-2}a + \cdots + a^{n-1}) {\lt} (b - a) n b^{n-1}\). Let \(E = \{ t \in K : t \geq 0, t^n {\lt} x\} \). It contains \(0\), and is bounded above by \(1 + x\) (if \(t {\gt} 1 + x\) then \(t^n \geq t {\gt} x\)). Let \(y = \sup E\); then \(y {\gt} 0\), since \(t = x/(1 + x)\) lies in \(E\).

Suppose \(y^n {\lt} x\). Choose \(h\) with \(0 {\lt} h {\lt} 1\) and \(h {\lt} (x - y^n)/(n (y + 1)^{n-1})\). Then \((y + h)^n - y^n {\lt} h n (y + h)^{n-1} {\lt} h n (y+1)^{n-1} {\lt} x - y^n\), so \(y + h \in E\), contradicting that \(y\) is an upper bound.

Suppose \(y^n {\gt} x\). Let \(k = (y^n - x)/(n y^{n-1})\); then \(0 {\lt} k {\lt} y\). For \(t \geq y - k\) we have \(y^n - t^n \leq y^n - (y - k)^n {\lt} k n y^{n-1} = y^n - x\), so \(t^n {\gt} x\) and \(t \notin E\). Hence \(y - k\) is an upper bound of \(E\), contradicting that \(y\) is least. So \(y^n = x\).

009V Definition 4.7.5

Let \(K\) be an ordered field. A sequence \((x_n)_{n \in \mathbb {N}}\) in \(K\) converges to \(x \in K\) if for every \(\varepsilon {\gt} 0\) in \(K\) there is \(N\) with \(|x_n - x| {\lt} \varepsilon \) for all \(n \geq N\). It is a Cauchy sequence if for every \(\varepsilon {\gt} 0\) there is \(N\) with \(|x_n - x_m| {\lt} \varepsilon \) for all \(m, n \geq N\).

009W Proposition 4.7.6

In a complete ordered field every Cauchy sequence converges.

Proof â–¼

Let \((x_n)\) be Cauchy. Choosing \(N\) for \(\varepsilon = 1\), all terms lie between \(\min (x_0, \ldots , x_N) - 1\) and \(\max (x_0, \ldots , x_N) + 1\), so the sequence is bounded. Let \(s_n = \sup \{ x_k : k \geq n\} \); this sequence is decreasing and bounded below, and we let \(x = \inf _n s_n\). Given \(\varepsilon {\gt} 0\), choose \(N\) with \(|x_n - x_m| {\lt} \varepsilon \) for \(m, n \geq N\). For \(n \geq N\), every \(x_k\) with \(k \geq n\) lies in \((x_n - \varepsilon , x_n + \varepsilon )\), so \(x_n - \varepsilon \leq s_m \leq x_n + \varepsilon \) for all \(m \geq n\); since the \(s_m\) decrease, \(x = \inf _{m \geq n} s_m\) lies in \([x_n - \varepsilon , x_n + \varepsilon ]\). Hence \(|x_n - x| \leq \varepsilon \) for \(n \geq N\).

009X Theorem 4.7.7

Let \(K\) and \(L\) be complete ordered fields. There is exactly one ring homomorphism \(K \to L\), and it is an order-preserving isomorphism of fields.

Proof â–¼

Regard \(\mathbb {Q}\subseteq K\) and \(\mathbb {Q}\subseteq L\) by Proposition 4.6.3. For \(x \in K\) let \(D(x) = \{ q \in \mathbb {Q}: q {\lt} x\} \), which is nonempty and bounded above in \(\mathbb {Q}\) by Proposition 4.7.3. Define \(\varphi (x) = \sup _L D(x)\).

By density, \(x = \sup _K D(x)\), and \(x {\lt} y\) implies that \(D(x) \subsetneq D(y)\) contains two rationals between \(x\) and \(y\), so \(\varphi (x) {\lt} \varphi (y)\). For \(q \in \mathbb {Q}\), \(\varphi (q) = q\). Every \(y \in L\) is in the image: with \(D_L(y) = \{ q : q {\lt} y\} \) and \(x = \sup _K D_L(y)\) we get \(D(x) = D_L(y)\) by density in both fields, so \(\varphi (x) = y\). So \(\varphi \) is an order-preserving bijection.

By density, \(D(x + y) = D(x) + D(y)\), so Lemma 4.7.2 gives \(\varphi (x + y) = \varphi (x) + \varphi (y)\). For \(x, y {\gt} 0\), the positive elements of \(D(xy)\) are the products of positive elements of \(D(x)\) and \(D(y)\), so \(\varphi (xy) = \varphi (x)\varphi (y)\). Since \(\varphi (-x) = -\varphi (x)\) (from additivity) and \(\varphi (0) = 0\), multiplicativity follows for all signs. Hence \(\varphi \) is an isomorphism.

Let \(\psi \colon K \to L\) be any ring homomorphism. By Proposition 4.7.4, \(x \geq 0\) implies \(x = y^2\) and so \(\psi (x) = \psi (y)^2 \geq 0\); hence \(\psi \) is order-preserving. Also \(\psi \) is the identity on \(\mathbb {Q}\) by Proposition 4.6.3. For \(q \in D(x)\) we get \(q = \psi (q) \leq \psi (x)\), so \(\varphi (x) \leq \psi (x)\); applying this to \(-x\) gives \(\varphi (x) \geq \psi (x)\). So \(\psi = \varphi \).
