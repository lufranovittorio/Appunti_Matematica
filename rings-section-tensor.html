7.9 Tensor products00FV

Complete. This chapter is written; its proofs await independent checking.

In this section \(R\) is a commutative ring.

00FW Definition 7.9.1

Let \(M\), \(N\), \(P\) be \(R\)-modules. A map \(\beta \colon M \times N \to P\) is bilinear if it is \(R\)-linear in each variable. A tensor product of \(M\) and \(N\) is a module \(M \otimes _R N\) with a bilinear map \(\otimes \colon M \times N \to M \otimes _R N\), \((m, n) \mapsto m \otimes n\), such that every bilinear \(\beta \colon M \times N \to P\) factors as \(\beta = \tilde\beta \circ \otimes \) for a unique linear \(\tilde\beta \).

00FX Proposition 7.9.2

Tensor products exist and are unique up to unique isomorphism. The elements \(m \otimes n\) generate \(M \otimes _R N\).

Proof â–¼

Uniqueness is the usual argument for universal properties. Let \(F = R^{(M \times N)}\) and \(Q \subseteq F\) the submodule generated by the elements \(e_{(m+m', n)} - e_{(m,n)} - e_{(m',n)}\), \(e_{(m, n+n')} - e_{(m,n)} - e_{(m,n')}\), \(e_{(rm, n)} - re_{(m,n)}\) and \(e_{(m, rn)} - re_{(m,n)}\). Put \(M \otimes _R N = F/Q\) and \(m \otimes n = e_{(m,n)} + Q\). A bilinear \(\beta \) induces a linear map \(F \to P\), \(e_{(m,n)} \mapsto \beta (m,n)\), vanishing on \(Q\), hence a unique \(\tilde\beta \). The elements \(m \otimes n\) generate since the \(e_{(m,n)}\) generate \(F\).

00FY Proposition 7.9.3

There are natural isomorphisms \(R \otimes _R M \cong M\), \(M \otimes N \cong N \otimes M\), \((M \otimes N) \otimes P \cong M \otimes (N \otimes P)\) and \((\bigoplus _i M_i) \otimes N \cong \bigoplus _i (M_i \otimes N)\). In particular \(R^m \otimes R^n \cong R^{mn}\). For an ideal \(I\), \((R/I) \otimes _R M \cong M/IM\).

Proof â–¼

Each isomorphism is obtained by constructing maps in both directions from bilinear maps and checking that the composites fix generators \(m \otimes n\). For instance \((r, m) \mapsto rm\) induces \(R \otimes M \to M\), inverse to \(m \mapsto 1 \otimes m\). For associativity, for fixed \(p\) the map \((m, n) \mapsto m \otimes (n \otimes p)\) is bilinear, giving \((m \otimes n) \mapsto m \otimes (n \otimes p)\); this is bilinear in \((m \otimes n, p)\), and an inverse is constructed symmetrically. For direct sums, \(((m_i), n) \mapsto (m_i \otimes n)\) is bilinear, and the inverse is induced by the maps \(M_i \otimes N \to (\bigoplus M_i) \otimes N\). Finally, \((\bar r, m) \mapsto \overline{rm}\) induces \(R/I \otimes M \to M/IM\), with inverse \(\bar m \mapsto \bar1 \otimes m\), well defined since \(1 \otimes am = \bar a \otimes m = 0\) for \(a \in I\).

00FZ Theorem 7.9.4 Tensor–hom adjunction

For \(R\)-modules \(M\), \(N\), \(P\) there is a bijection, natural in all three variables,

\[ \operatorname {Hom}_R(M \otimes _R N, P) \cong \operatorname {Hom}_R(M, \operatorname {Hom}_R(N, P)), \qquad f \mapsto (m \mapsto (n \mapsto f(m \otimes n))). \]

So \(- \otimes _R N\) is left adjoint to \(\operatorname {Hom}_R(N, -)\). Consequently \(- \otimes _R N\) preserves colimits, and for every exact sequence \(A \to B \to C \to 0\) the sequence \(A \otimes N \to B \otimes N \to C \otimes N \to 0\) is exact.

Proof â–¼

Both sides are in bijection with bilinear maps \(M \times N \to P\), naturally. The functor \(- \otimes _R N\) preserves colimits by Theorem 5.10.4. A sequence \(A \xrightarrow {u} B \xrightarrow {v} C \to 0\) is exact if and only if \(v\) is a cokernel of \(u\), that is, a coequaliser of \(u\) and \(0\); this is preserved.

00G0 Example 7.9.5

\(\mathbb {Z}/m\mathbb {Z}\otimes _\mathbb {Z}\mathbb {Z}/n\mathbb {Z}\cong \mathbb {Z}/d\mathbb {Z}\) with \(d = \gcd (m, n)\), since by Proposition 7.9.3 it is \((\mathbb {Z}/n\mathbb {Z})/m(\mathbb {Z}/n\mathbb {Z}) = \mathbb {Z}/(m, n) = \mathbb {Z}/d\mathbb {Z}\). In particular \(\mathbb {Z}/2\mathbb {Z}\otimes \mathbb {Z}/3\mathbb {Z}= 0\), and \(\mathbb {Q}\otimes _\mathbb {Z}\mathbb {Z}/n\mathbb {Z}= 0\) since \(x \otimes \bar1 = nx/n \otimes \bar1 = x/n \otimes \bar n = 0\).

00G1 Counterexample 7.9.6

Tensoring does not preserve injectivity. The map \(2 \colon \mathbb {Z}\to \mathbb {Z}\) is injective, but tensoring with \(\mathbb {Z}/2\mathbb {Z}\) gives the zero map \(\mathbb {Z}/2\mathbb {Z}\to \mathbb {Z}/2\mathbb {Z}\). Similarly \(\operatorname {Hom}_R(N, -)\) does not preserve surjectivity: \(\mathbb {Z}\to \mathbb {Z}/2\mathbb {Z}\) is surjective but \(\operatorname {Hom}(\mathbb {Z}/2\mathbb {Z}, \mathbb {Z}) = 0 \to \operatorname {Hom}(\mathbb {Z}/2\mathbb {Z}, \mathbb {Z}/2\mathbb {Z}) \cong \mathbb {Z}/2\mathbb {Z}\) is not.

00G2 Definition 7.9.7

An \(R\)-module \(N\) is flat if \(- \otimes _R N\) preserves injective homomorphisms. Free modules are flat, by Proposition 7.9.3.

00G3 Proposition 7.9.8 Extension of scalars

Let \(\varphi \colon R \to S\) be a homomorphism of commutative rings. For an \(R\)-module \(M\), \(S \otimes _R M\) is an \(S\)-module via \(s(s' \otimes m) = ss' \otimes m\), and for every \(S\)-module \(N\) (an \(R\)-module via \(\varphi \)) there is a natural bijection \(\operatorname {Hom}_S(S \otimes _R M, N) \cong \operatorname {Hom}_R(M, N)\), \(f \mapsto (m \mapsto f(1 \otimes m))\).

Proof â–¼

For \(s \in S\), multiplication by \(s\) on \(S\) is \(R\)-linear, so it induces an endomorphism of \(S \otimes _R M\); this gives the module structure. Given an \(R\)-linear \(g \colon M \to N\), the map \((s, m) \mapsto sg(m)\) is \(R\)-bilinear and induces an \(S\)-linear map \(S \otimes M \to N\); the two constructions are inverse because \(1 \otimes m\) generate \(S \otimes M\) as an \(S\)-module.
