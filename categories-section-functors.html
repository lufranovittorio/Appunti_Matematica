5.4 Functors001B

Complete. This chapter is written; its proofs await independent checking.

001C Definition 5.4.1

Let \(\mathcal{C}\) and \(\mathcal{D}\) be categories. A functor \(F \colon \mathcal{C} \to \mathcal{D}\) consists of a map \(F \colon \operatorname {Ob}(\mathcal{C}) \to \operatorname {Ob}(\mathcal{D})\) and, for all \(X, Y \in \mathcal{C}\), a map \(F \colon \operatorname {Hom}_{\mathcal{C}}(X, Y) \to \operatorname {Hom}_{\mathcal{D}}(F(X), F(Y))\), such that \(F(\mathrm{id}_X) = \mathrm{id}_{F(X)}\) for all \(X\) and \(F(g \circ f) = F(g) \circ F(f)\) for all composable morphisms \(f\) and \(g\). A contravariant functor from \(\mathcal{C}\) to \(\mathcal{D}\) is a functor \(\mathcal{C}^{\mathrm{op}} \to \mathcal{D}\).

001D Remark 5.4.2

Unwinding the definitions, a contravariant functor \(F\) from \(\mathcal{C}\) to \(\mathcal{D}\) assigns to each \(f \colon X \to Y\) in \(\mathcal{C}\) a morphism \(F(f) \colon F(Y) \to F(X)\), and \(F(g \circ f) = F(f) \circ F(g)\).

001E Example 5.4.3

Some functors.

  1. Every category \(\mathcal{C}\) has an identity functor \(\mathrm{id}_{\mathcal{C}}\). If \(F \colon \mathcal{C} \to \mathcal{D}\) and \(G \colon \mathcal{D} \to \mathcal{E}\) are functors, then so is their composition \(G \circ F\), defined on objects and on morphisms by composing maps.

  2. Forgetful functors, such as \(\mathsf{Grp} \to \mathsf{Set}\), which send a group to its underlying set and a homomorphism to its underlying map.

  3. The covariant power set functor \(\mathcal{P} \colon \mathsf{Set}\to \mathsf{Set}\) sends \(X\) to its power set \(\mathcal{P}(X)\) and \(f \colon X \to Y\) to the map \(A \mapsto f(A)\). It is a functor because \((g \circ f)(A) = g(f(A))\).

  4. The contravariant power set functor \(\mathcal{P}^* \colon \mathsf{Set}^{\mathrm{op}} \to \mathsf{Set}\) sends \(X\) to \(\mathcal{P}(X)\) and \(f \colon X \to Y\) to the map \(\mathcal{P}(Y) \to \mathcal{P}(X)\), \(B \mapsto f^{-1}(B)\). It is a functor because \((g \circ f)^{-1}(C) = f^{-1}(g^{-1}(C))\).

  5. If \(P\) and \(Q\) are preorders, viewed as categories, a functor \(P \to Q\) is the same thing as a map \(\varphi \colon P \to Q\) with \(\varphi (x) \leq \varphi (y)\) whenever \(x \leq y\).

  6. If \(M\) and \(N\) are monoids, a functor \(BM \to BN\) is the same thing as a homomorphism of monoids \(M \to N\).

001F Definition 5.4.4

Let \(\mathcal{C}\) be a locally small category and \(X \in \mathcal{C}\). The functor \(h_X \colon \mathcal{C}^{\mathrm{op}} \to \mathsf{Set}\) sends \(Y\) to \(\operatorname {Hom}_{\mathcal{C}}(Y, X)\) and a morphism \(f \colon Y' \to Y\) of \(\mathcal{C}\) to the map

\[ h_X(f) \colon \operatorname {Hom}_{\mathcal{C}}(Y, X) \to \operatorname {Hom}_{\mathcal{C}}(Y', X), \qquad g \mapsto g \circ f. \]

Dually, the functor \(h^X \colon \mathcal{C} \to \mathsf{Set}\) sends \(Y\) to \(\operatorname {Hom}_{\mathcal{C}}(X, Y)\) and \(f \colon Y \to Y'\) to \(g \mapsto f \circ g\).

001G Lemma 5.4.5

Let \(F \colon \mathcal{C} \to \mathcal{D}\) be a functor. If \(f\) is an isomorphism in \(\mathcal{C}\), then \(F(f)\) is an isomorphism in \(\mathcal{D}\), with inverse \(F(f^{-1})\).

Proof â–¼

If \(f \colon X \to Y\), then \(F(f^{-1}) \circ F(f) = F(f^{-1} \circ f) = F(\mathrm{id}_X) = \mathrm{id}_{F(X)}\), and similarly \(F(f) \circ F(f^{-1}) = \mathrm{id}_{F(Y)}\).

001H Definition 5.4.6

A functor \(F \colon \mathcal{C} \to \mathcal{D}\) is faithful (respectively full) if for all \(X, Y \in \mathcal{C}\) the map \(\operatorname {Hom}_{\mathcal{C}}(X, Y) \to \operatorname {Hom}_{\mathcal{D}}(F(X), F(Y))\) is injective (respectively surjective). It is fully faithful if it is both full and faithful. It is essentially surjective if every object of \(\mathcal{D}\) is isomorphic to an object of the form \(F(X)\).

001I Lemma 5.4.7

Let \(F \colon \mathcal{C} \to \mathcal{D}\) be a fully faithful functor and \(f \colon X \to Y\) a morphism of \(\mathcal{C}\). If \(F(f)\) is an isomorphism, then \(f\) is an isomorphism. In particular, if \(F(X) \cong F(Y)\) then \(X \cong Y\).

Proof â–¼

Let \(h \colon F(Y) \to F(X)\) be the inverse of \(F(f)\). Since \(F\) is full, there is \(g \colon Y \to X\) with \(F(g) = h\). Then \(F(g \circ f) = h \circ F(f) = \mathrm{id}_{F(X)} = F(\mathrm{id}_X)\), and since \(F\) is faithful, \(g \circ f = \mathrm{id}_X\). In the same way \(f \circ g = \mathrm{id}_Y\).

For the second statement, let \(\varphi \colon F(X) \to F(Y)\) be an isomorphism. Since \(F\) is full, \(\varphi = F(f)\) for some \(f \colon X \to Y\), and \(f\) is an isomorphism by the first statement.

001J Counterexample 5.4.8

Faithfulness alone does not suffice in Lemma 5.4.7. Let \(P\) be the category \(0 \leq 1\) of Counterexample 5.3.7, let \(\mathbf{1}\) be the category with one object and one morphism, and let \(F \colon P \to \mathbf{1}\) be the unique functor. Every set of morphisms of \(P\) has at most one element, so \(F\) is faithful. The morphism \(u \colon 0 \to 1\) is not an isomorphism, but \(F(u)\) is an identity, hence an isomorphism. (The functor \(F\) is not full: \(\operatorname {Hom}_P(1, 0)\) is empty.)

001K Remark 5.4.9

A more natural instance of the same phenomenon is the forgetful functor \(\mathsf{Top} \to \mathsf{Set}\), which is faithful. The identity map of \(\mathbb {R}\), viewed as a map from \(\mathbb {R}\) with the discrete topology to \(\mathbb {R}\) with the Euclidean topology, is a continuous bijection, so its image in \(\mathsf{Set}\) is an isomorphism; but it is not a homeomorphism.
