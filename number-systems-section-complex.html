4.9 The complex numbers00A5

Complete. This chapter is written; its proofs await independent checking.

00A6 Definition 4.9.1

The set of complex numbers is \(\mathbb {C}= \mathbb {R}\times \mathbb {R}\) with

\[ (a, b) + (c, d) = (a + c, b + d), \qquad (a, b)(c, d) = (ac - bd, ad + bc). \]

We identify \(a \in \mathbb {R}\) with \((a, 0)\) and write \(i = (0, 1)\), so that \((a, b) = a + bi\). For \(z = a + bi\), the real part is \(\operatorname {Re} z = a\), the imaginary part is \(\operatorname {Im} z = b\), the conjugate is \(\bar z = a - bi\), and the absolute value is \(|z| = \sqrt{a^2 + b^2}\).

00A7 Theorem 4.9.2

\(\mathbb {C}\) is a field containing \(\mathbb {R}\) as a subfield, and \(i^2 = -1\). Every \(z \in \mathbb {C}\) can be written uniquely as \(a + bi\) with \(a, b \in \mathbb {R}\). Complex conjugation is a field automorphism of \(\mathbb {C}\) that is the identity exactly on \(\mathbb {R}\), and for all \(z, w \in \mathbb {C}\): \(z \bar z = |z|^2\), \(|zw| = |z||w|\), \(|\operatorname {Re} z| \leq |z|\) and \(|z + w| \leq |z| + |w|\).

Proof â–¼

The ring axioms are direct computations; for instance the product is associative because both \(((a,b)(c,d))(e,f)\) and \((a,b)((c,d)(e,f))\) equal \((ace - bde - adf - bcf,\ acf - bdf + ade + bce)\). The unit is \((1, 0)\), and \((0,1)(0,1) = (-1, 0)\). If \(z = a + bi \neq 0\), then \(a^2 + b^2 {\gt} 0\) and \(z \cdot (a - bi)/(a^2 + b^2) = 1\). The map \(a \mapsto (a, 0)\) is an injective ring homomorphism. Conjugation preserves sums, and \(\overline{(a + bi)(c + di)} = (ac - bd) - (ad + bc)i = (a - bi)(c - di)\); it is its own inverse and fixes \(a + bi\) iff \(b = 0\).

\(z \bar z = a^2 + b^2 = |z|^2\). Then \(|zw|^2 = zw\bar z\bar w = |z|^2|w|^2\), and both \(|zw|\) and \(|z||w|\) are non-negative, so they are equal by the uniqueness in Proposition 4.7.4. Clearly \(|\operatorname {Re} z| = |a| \leq \sqrt{a^2 + b^2}\). Finally \(|z + w|^2 = |z|^2 + 2\operatorname {Re}(z \bar w) + |w|^2 \leq |z|^2 + 2|z||w| + |w|^2 = (|z| + |w|)^2\).

00A8 Proposition 4.9.3

Every complex number has a square root: for \(z = a + bi\), the number

\[ w = \sqrt{\tfrac {|z| + a}{2}} + \sigma \sqrt{\tfrac {|z| - a}{2}}\, i, \qquad \sigma = 1 \text{ if } b \geq 0, \ \sigma = -1 \text{ if } b {\lt} 0, \]

satisfies \(w^2 = z\). Consequently every polynomial equation \(z^2 + pz + q = 0\) with \(p, q \in \mathbb {C}\) has a solution in \(\mathbb {C}\).

Proof â–¼

Both radicands are non-negative since \(|a| \leq |z|\). We have \(w^2 = \frac{|z| + a}{2} - \frac{|z| - a}{2} + 2\sigma \sqrt{\frac{|z|^2 - a^2}{4}}\, i = a + \sigma |b| i = a + bi\). For the equation, take \(z = (-p + w)/2\) where \(w^2 = p^2 - 4q\).

00A9 Counterexample 4.9.4

There is no order on \(\mathbb {C}\) making it an ordered field. Indeed, in an ordered field squares are non-negative and \(-1 {\lt} 0\) (Lemma 4.3.4), but \(-1 = i^2\).

00AA Remark 4.9.5

The fundamental theorem of algebra, which says that every nonconstant complex polynomial has a root, is proved algebraically in Chapter 9 and again analytically in Chapter 28. The polar form \(z = |z| e^{i\theta }\) requires the exponential function, which is defined in Chapter 26.
