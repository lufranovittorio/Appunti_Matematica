Complete. This chapter is written; its proofs await independent checking.

00O2 Lemma 14.4.1 Snake lemma

Consider a commutative diagram of modules with exact rows

There is a homomorphism \(\delta \colon \ker h \to \operatorname {coker} f\) such that the sequence

\[ \ker f \to \ker g \to \ker h \xrightarrow {\delta } \operatorname {coker} f \to \operatorname {coker} g \to \operatorname {coker} h \]

is exact. If \(i'\) is injective so is \(\ker f \to \ker g\), and if \(p\) is surjective so is \(\operatorname {coker} g \to \operatorname {coker} h\).

Proof â–¼

Definition of \(\delta \). Let \(c' \in \ker h\). Choose \(b' \in B'\) with \(p'(b') = c'\). Then \(p(g(b')) = h(c') = 0\), so \(g(b') = i(a)\) for a unique \(a \in A\); put \(\delta (c') = [a]\). If \(b'\) is replaced by \(b' + i'(a')\), then \(a\) is replaced by \(a + f(a')\), with the same class; so \(\delta \) is well defined, and it is clearly a homomorphism.

Exactness at \(\ker g\). The composite is zero. If \(b' \in \ker g\) and \(p'(b') = 0\), then \(b' = i'(a')\) and \(i(f(a')) = g(b') = 0\), so \(f(a') = 0\).

Exactness at \(\ker h\). If \(c' = p'(b')\) with \(g(b') = 0\), then \(a = 0\) and \(\delta (c') = 0\). Conversely if \(\delta (c') = 0\), then \(a = f(a'')\), and \(b' - i'(a'')\) is a preimage of \(c'\) with \(g(b' - i'(a'')) = i(a) - i(f(a'')) = 0\).

Exactness at \(\operatorname {coker} f\). The image of \(\delta (c')\) in \(\operatorname {coker} g\) is the class of \(i(a) = g(b')\), which is zero. Conversely, if \(i(a) = g(b')\) for some \(b'\), then \(c' = p'(b')\) satisfies \(h(c') = p(g(b')) = pi(a) = 0\) and \(\delta (c') = [a]\).

Exactness at \(\operatorname {coker} g\). The composite is zero. If \(b \in B\) maps to zero in \(\operatorname {coker} h\), then \(p(b) = h(p'(b'))\) for some \(b'\), so \(p(b - g(b')) = 0\) and \(b - g(b') = i(a)\); hence \([b]\) is the image of \([a]\).

The last two statements are clear.

00O3 Lemma 14.4.2 Five lemma

Consider a commutative diagram of modules with exact rows \(A_1 \to A_2 \to A_3 \to A_4 \to A_5\) and \(B_1 \to B_2 \to B_3 \to B_4 \to B_5\) and vertical maps \(f_1, \ldots , f_5\). If \(f_2\) and \(f_4\) are isomorphisms, \(f_1\) is surjective and \(f_5\) is injective, then \(f_3\) is an isomorphism.

Proof â–¼

Write \(\alpha _i \colon A_i \to A_{i+1}\) and \(\beta _i \colon B_i \to B_{i+1}\). Injectivity: let \(f_3(x) = 0\). Then \(f_4\alpha _3(x) = 0\), so \(\alpha _3(x) = 0\) and \(x = \alpha _2(y)\). Now \(\beta _2f_2(y) = 0\), so \(f_2(y) = \beta _1(z)\) and \(z = f_1(w)\). Then \(f_2(y - \alpha _1(w)) = 0\), so \(y = \alpha _1(w)\) and \(x = \alpha _2\alpha _1(w) = 0\). Surjectivity: let \(u \in B_3\). Choose \(x \in A_4\) with \(f_4(x) = \beta _3(u)\). Then \(f_5\alpha _4(x) = \beta _4\beta _3(u) = 0\), so \(\alpha _4(x) = 0\) and \(x = \alpha _3(y)\). Then \(\beta _3(u - f_3(y)) = 0\), so \(u - f_3(y) = \beta _2(v)\) with \(v = f_2(t)\), and \(u = f_3(y + \alpha _2(t))\).

00O4 Theorem 14.4.3 Long exact sequence, or zig-zag lemma

A short exact sequence \(0 \to A^\bullet \xrightarrow {f} B^\bullet \xrightarrow {g} C^\bullet \to 0\) of complexes in an abelian category induces a long exact sequence

\[ \cdots \to H^n(A) \to H^n(B) \to H^n(C) \xrightarrow {\delta } H^{n+1}(A) \to H^{n+1}(B) \to \cdots , \]

natural in the short exact sequence. For \(c \in Z^n(C)\) (in the case of modules), \(\delta [c]\) is the class of \(a\) where \(f(a) = d(b)\) and \(g(b) = c\).

Proof â–¼

Applying the snake lemma to the vertical maps \(d^{n-1}\) between the short exact sequences in degrees \(n - 1\) and \(n\), the cokernel sequence \(A^n/B^n(A) \to B^n/B^n(B) \to C^n/B^n(C) \to 0\) is exact; applying it to \(d^{n+1}\), the kernel sequence \(0 \to Z^{n+1}(A) \to Z^{n+1}(B) \to Z^{n+1}(C)\) is exact. The differential \(d^n\) induces vertical maps from the first of these rows to the second, whose kernels are the \(H^n\) and whose cokernels are the \(H^{n+1}\). Apply Lemma 14.4.1. Naturality follows from the explicit formula for \(\delta \).

02GQ Remark 14.4.4

The name zig-zag lemma comes from the path that defines the connecting map \(\delta \). Start from a cocycle \(c \in C^n\); go up to a preimage \(b \in B^n\) with \(g(b) = c\); go across by the differential to \(d(b) \in B^{n+1}\), which satisfies \(g(d(b)) = d(g(b)) = d(c) = 0\); and go down to the unique \(a \in A^{n+1}\) with \(f(a) = d(b)\). Then \(\delta [c] = [a]\):

The element \(a\) depends on the choice of \(b\), but its class does not; Exercise 14.10.2 checks this and the exactness of the long sequence directly, by chasing elements through the diagram, without the snake lemma. In singular homology, where the short exact sequence is \(0 \to C_\bullet (A) \to C_\bullet (X) \to C_\bullet (X, A) \to 0\), the recipe says: a relative cycle is a chain in \(X\) whose boundary lies in \(A\), and \(\delta \) sends it to that boundary.

00O5 Proposition 14.4.5

For \(f \colon A^\bullet \to B^\bullet \) there is a short exact sequence \(0 \to B^\bullet \to \mathrm{Cone}(f) \to A[1]^\bullet \to 0\) whose connecting map \(H^n(A[1]) = H^{n+1}(A) \to H^{n+1}(B)\) is \(H^{n+1}(f)\). In particular \(f\) is a quasi-isomorphism if and only if \(\mathrm{Cone}(f)\) is acyclic.

Proof â–¼

The maps \(b \mapsto (0, b)\) and \((a, b) \mapsto a\) are morphisms of complexes (with the sign convention of Notation 14.3.2 for \(A[1]\)). For a cocycle \(a \in A^{n+1}\), the element \((a, 0)\) lifts it, and \(d(a, 0) = (-da, f(a)) = (0, f(a))\); so \(\delta [a] = [f(a)]\). The last statement follows from the long exact sequence.
