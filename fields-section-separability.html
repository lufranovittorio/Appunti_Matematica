9.4 Separability00H3

Complete. This chapter is written; its proofs await independent checking.

00H4 Definition 9.4.1

A nonzero polynomial \(f \in K[x]\) is separable if it has no repeated root in a splitting field. An algebraic element is separable if its minimal polynomial is, and an algebraic extension is separable if all its elements are. The derivative of \(f = \sum a_i x^i\) is \(f' = \sum i a_i x^{i-1}\); it satisfies \((fg)' = f'g + fg'\).

00H5 Proposition 9.4.2

A nonzero polynomial \(f\) is separable if and only if \(\gcd (f, f') = 1\) in \(K[x]\). An irreducible polynomial is separable if and only if \(f' \neq 0\). If \(\operatorname {char} K = 0\), every irreducible polynomial is separable; if \(\operatorname {char} K = p {\gt} 0\), an irreducible \(f\) is inseparable if and only if \(f = g(x^p)\) for some \(g \in K[x]\).

Proof â–¼

In a splitting field, if \(f = (x - \alpha )^2 h\) then \(f'(\alpha ) = 0\); if \(f = (x - \alpha )h\) with \(h(\alpha ) \neq 0\) then \(f'(\alpha ) = h(\alpha ) \neq 0\). So \(f\) has a repeated root iff \(f\) and \(f'\) have a common root in a splitting field, iff they have a common factor of positive degree in \(K[x]\) (a common root \(\alpha \) makes \(m_\alpha \) a common factor; conversely a common factor has a root in the splitting field). If \(f\) is irreducible and \(f' \neq 0\), the gcd divides \(f\) and has degree \({\lt} \deg f\), so it is \(1\). If \(f' = 0\) then \(\gcd (f, f') = f\). Finally \(f' = 0\) iff \(i a_i = 0\) for all \(i\), which in characteristic \(0\) means \(f\) is constant, and in characteristic \(p\) means \(a_i = 0\) unless \(p \mid i\).

00H6 Definition 9.4.3

A field \(K\) is perfect if it has characteristic \(0\), or characteristic \(p\) and the Frobenius \(x \mapsto x^p\) is surjective. (The Frobenius is always an injective ring homomorphism in characteristic \(p\), since \(p\) divides the binomial coefficients \(\binom {p}{i}\) for \(0 {\lt} i {\lt} p\).)

00H7 Proposition 9.4.4

Over a perfect field every irreducible polynomial is separable, so every algebraic extension is separable. Finite fields are perfect.

Proof â–¼

If \(\operatorname {char} K = p\) and \(f = \sum b_i x^{pi}\) with \(b_i = c_i^p\), then \(f = (\sum c_i x^i)^p\) is not irreducible. A finite field is perfect because an injective map from a finite set to itself is surjective.

00H8 Counterexample 9.4.5

Let \(K = \mathbb {F}_p(t)\) be the field of fractions of \(\mathbb {F}_p[t]\). The polynomial \(f = x^p - t\) is irreducible, by Eisenstein’s criterion for the prime \(t\) of the UFD \(\mathbb {F}_p[t]\), but \(f' = 0\). In a splitting field, with \(\beta ^p = t\), we have \(f = (x - \beta )^p\): a single root of multiplicity \(p\). So \(K\) is not perfect and \(K(\beta )/K\) is not separable.
