10.3 Orders and primitive roots02XU

Complete. This chapter is written; its proofs await independent checking.

The powers of \(2\) modulo \(11\) are

\[ 2, \ 4, \ 8, \ 5, \ 10, \ 9, \ 7, \ 3, \ 6, \ 1, \]

so every nonzero residue modulo \(11\) is a power of \(2\), and \(U_{11}\) is a cyclic group generated by \(2\). The powers of any \(a\) modulo \(8\), on the other hand, are only \(1\) and \(a\), since \(1^2 = 3^2 - 8 = 5^2 - 24 = 7^2 - 48 = 1\); so \(U_8\), of order \(4\), is not cyclic. This section determines all \(n\) for which \(U_n\) is cyclic.

02XV Definition 10.3.1

Let \(n \geq 1\) and \(\gcd (a, n) = 1\). The order of \(a\) modulo \(n\), written \(\operatorname {ord}_n(a)\), is the order of \(\bar{a}\) in the group \(U_n\): the least \(k \geq 1\) with \(a^k \equiv 1 \pmod n\). An integer \(g\) is a primitive root modulo \(n\) if \(\operatorname {ord}_n(g) = \varphi (n)\), that is, if \(\bar{g}\) generates \(U_n\).

02XW Lemma 10.3.2

Let \(G\) be a group and \(x \in G\) an element of finite order \(m\).

  1. \(x^k = 1\) if and only if \(m \mid k\).

  2. For \(k \geq 1\), the order of \(x^k\) is \(m/\gcd (k, m)\).

  3. If \(G\) is cyclic of order \(m\) generated by \(x\), its generators are the \(x^k\) with \(\gcd (k, m) = 1\), and there are \(\varphi (m)\) of them. For each \(d \mid m\), \(G\) has exactly one subgroup of order \(d\), generated by \(x^{m/d}\), and the elements of \(G\) whose order divides \(d\) are exactly the elements of this subgroup.

In particular \(\operatorname {ord}_n(a)\) divides \(\varphi (n)\), and \(a^k \equiv 1 \pmod n\) if and only if \(\operatorname {ord}_n(a) \mid k\).

Proof â–¼

(1) Write \(k = qm + r\) with \(0 \leq r {\lt} m\). Then \(x^k = (x^m)^qx^r = x^r\) (Lemma 7.2.9), which is \(1\) exactly when \(r = 0\), by the minimality of \(m\).

(2) Let \(g = \gcd (k, m)\). By (1), \((x^k)^j = 1\) if and only if \(m \mid kj\), that is, \(\frac{m}{g} \mid \frac{k}{g}j\), that is, \(\frac{m}{g} \mid j\), since \(\gcd (\frac{k}{g}, \frac{m}{g}) = 1\) (as in the proof of Proposition 10.2.4). So the order of \(x^k\) is \(m/g\).

(3) Every element is some \(x^k\) with \(0 \leq k {\lt} m\), and by (2) it generates \(G\), that is, has order \(m\), if and only if \(\gcd (k, m) = 1\); the number of such \(k\) is \(\varphi (m)\). Let \(d \mid m\). An element \(x^k\) has order dividing \(d\) if and only if \(x^{kd} = 1\), that is, \(m \mid kd\), that is, \(\frac{m}{d} \mid k\); so these elements are the \(d\) powers of \(x^{m/d}\), which form the subgroup generated by \(x^{m/d}\), of order \(d\) by (2). Any subgroup \(H\) of order \(d\) consists of elements of order dividing \(d\) (Theorem 7.3.3), so \(H\) is contained in this subgroup and, having the same number of elements, equals it. The last assertion is (1) for \(G = U_n\), with Lagrange’s theorem.

02XX Theorem 10.3.3

For every prime \(p\) the group \(U_p = \mathbb {F}_p^\times \) is cyclic of order \(p - 1\): there is a primitive root modulo \(p\), and there are exactly \(\varphi (p - 1)\) primitive roots among \(1, \ldots , p - 1\).

Proof â–¼

\(\mathbb {F}_p^\times \) is a finite subgroup of the multiplicative group of the field \(\mathbb {F}_p\), so it is cyclic by Lemma 9.6.1. The number of generators is \(\varphi (p - 1)\) by Lemma 10.3.2(3).

It is worth recalling why this is true, since the proof of Lemma 9.6.1 is short but indirect. The essential input is that a polynomial of degree \(d\) over a field has at most \(d\) roots (Corollary 8.6.7): so for each \(d\) there are at most \(d\) residues with \(x^d \equiv 1 \pmod p\). In \(\mathbb {Z}/8\mathbb {Z}\), which is not a field, the polynomial \(x^2 - 1\) has the four roots \(1, 3, 5, 7\), and this is exactly why \(U_8\) is not cyclic. Exercise 10.9.5 gives a second proof of the theorem by counting with Proposition 10.2.8(4).

02XY Example 10.3.4

  1. By the list above, \(2\) is a primitive root modulo \(11\). There are \(\varphi (10) = 4\) primitive roots, the powers \(2^k\) with \(\gcd (k, 10) = 1\): \(2^1 = 2\), \(2^3 = 8\), \(2^7 \equiv 7\) and \(2^9 \equiv 6\).

  2. Modulo \(7\), the powers of \(3\) are \(3, 2, 6, 4, 5, 1\), so \(3\) is a primitive root; the powers of \(2\) are \(2, 4, 1\), so \(2\) is not.

  3. To find a primitive root modulo \(p\) in practice, one tests \(g = 2, 3, \ldots \): by Lemma 10.3.2, \(g\) is a primitive root if and only if \(g^{(p-1)/\ell } \not\equiv 1 \pmod p\) for every prime \(\ell \mid p - 1\), since a proper divisor of \(p - 1\) divides some \((p - 1)/\ell \). For \(p = 23\), \(p - 1 = 2 \cdot 11\); \(2^{11} = 2048 = 89 \cdot 23 + 1\), so \(2\) is not a primitive root; \(5^2 = 25 \equiv 2\) and \(5^{11} = 5 \cdot (5^2)^5 \equiv 5 \cdot 2^5 = 160 \equiv -1 \pmod{23}\), so \(5\) is a primitive root modulo \(23\).

02XZ Remark 10.3.5

Whether \(2\) is a primitive root modulo infinitely many primes is not known. Artin conjectured in 1927 that every integer \(a\) that is neither \(-1\) nor a perfect square is a primitive root modulo infinitely many primes; this is still open for every single value of \(a\).

To pass from primes to prime powers we need a lemma on how powers of numbers close to \(1\) behave modulo powers of \(p\).

02Y0 Lemma 10.3.6

Let \(p\) be a prime and \(j \geq 1\), with \(j \geq 2\) if \(p = 2\). If \(x \equiv 1 + p^jc \pmod{p^{j+1}}\) with \(p \nmid c\), then \(x^p \equiv 1 + p^{j+1}c \pmod{p^{j+2}}\). Consequently, under the same hypothesis, \(x^{p^i} \equiv 1 + p^{j+i}c \pmod{p^{j+i+1}}\) for all \(i \geq 0\).

Proof â–¼

Write \(x = 1 + p^jy\) with \(y \equiv c \pmod p\). By the binomial theorem

\[ x^p = 1 + p \cdot p^jy + \sum _{k=2}^{p}\binom {p}{k}p^{kj}y^k . \]

The second term is \(p^{j+1}y \equiv p^{j+1}c \pmod{p^{j+2}}\). For \(2 \leq k \leq p - 1\), \(p\) divides \(\binom {p}{k} = \frac{p!}{k!(p - k)!}\) (it divides the numerator and not the denominator, by Lemma 4.5.4), so the term is divisible by \(p^{1 + kj}\), and \(1 + kj \geq 1 + 2j \geq j + 2\). The last term \(p^{pj}y^p\) is divisible by \(p^{j+2}\) if \(pj \geq j + 2\), that is, \((p - 1)j \geq 2\), which holds if \(p \geq 3\) or if \(p = 2\) and \(j \geq 2\). (For \(p = 2\) there are no middle terms.) This proves the first statement; the second follows by induction on \(i\), since \(x^{p^i}\) again satisfies the hypothesis, with \(j + i\) in place of \(j\).

02Y1 Theorem 10.3.7

Let \(p\) be an odd prime and \(k \geq 1\). Then \(U_{p^k}\) is cyclic. More precisely, if \(g\) is a primitive root modulo \(p\) with \(g^{p-1} \not\equiv 1 \pmod{p^2}\), then \(g\) is a primitive root modulo \(p^k\) for every \(k \geq 1\); and if \(g\) is any primitive root modulo \(p\), then \(g\) or \(g + p\) has this property.

Proof â–¼

Let \(g\) be a primitive root modulo \(p\). If \(g^{p-1} \equiv 1 \pmod{p^2}\), then by the binomial theorem

\[ (g + p)^{p-1} \equiv g^{p-1} + (p - 1)g^{p-2}p \equiv 1 - pg^{p-2} \pmod{p^2}, \]

which is \(\not\equiv 1\) since \(p \nmid g\); and \(g + p \equiv g \pmod p\) is again a primitive root modulo \(p\). So we may assume \(g^{p-1} = 1 + pc\) with \(p \nmid c\).

Let \(d = \operatorname {ord}_{p^k}(g)\). Then \(g^d \equiv 1 \pmod p\), so \(p - 1 = \operatorname {ord}_p(g)\) divides \(d\), and \(d\) divides \(\varphi (p^k) = (p - 1)p^{k-1}\) (Lemma 10.3.2, Proposition 10.2.8). Hence \(d = (p - 1)p^i\) for some \(0 \leq i \leq k - 1\). If \(k \geq 2\) and \(i \leq k - 2\), then \(d\) divides \((p - 1)p^{k-2}\), so \(g^{(p-1)p^{k-2}} \equiv 1 \pmod{p^k}\); but Lemma 10.3.6 with \(x = g^{p-1}\) and \(j = 1\) gives \(g^{(p-1)p^{k-2}} \equiv 1 + p^{k-1}c \pmod{p^k}\), which is \(\not\equiv 1\). So \(i = k - 1\) and \(d = \varphi (p^k)\). (For \(k = 1\) there is nothing to prove.)

02Y2 Example 10.3.8

\(3\) is a primitive root modulo \(7\), and \(3^6 = 729 = 14 \cdot 49 + 43 \not\equiv 1 \pmod{49}\). So \(3\) is a primitive root modulo \(7^k\) for every \(k\): for instance modulo \(343\) the powers of \(3\) run through all \(\varphi (343) = 294\) residues prime to \(7\). The exceptional case of the theorem does occur, but rarely: \(p = 29\), \(g = 14\) is a primitive root modulo \(29\) with \(14^{28} \equiv 1 \pmod{29^2}\) (Exercise 10.9.6).

Powers of \(2\) behave differently, as \(U_8\) already showed.

02Y3 Theorem 10.3.9

\(U_2\) and \(U_4\) are cyclic, of orders \(1\) and \(2\). For \(k \geq 3\), \(\operatorname {ord}_{2^k}(5) = 2^{k-2}\), and the map

\[ \mathbb {Z}/2\mathbb {Z}\times \mathbb {Z}/2^{k-2}\mathbb {Z}\to U_{2^k}, \qquad (a, b) \mapsto (-1)^a5^b, \]

is an isomorphism of groups. In particular \(U_{2^k}\) is not cyclic for \(k \geq 3\).

Proof â–¼

\(U_2 = \{ \bar{1}\} \) and \(U_4 = \{ \bar{1}, \bar{3}\} \). Let \(k \geq 3\). Since \(5 = 1 + 2^2\), Lemma 10.3.6 with \(p = 2\), \(j = 2\), \(c = 1\) gives \(5^{2^i} \equiv 1 + 2^{i+2} \pmod{2^{i+3}}\). For \(i = k - 3\) this says \(5^{2^{k-3}} \equiv 1 + 2^{k-1} \not\equiv 1 \pmod{2^k}\); for \(i = k - 2\) it gives \(5^{2^{k-2}} \equiv 1 \pmod{2^k}\). So the order of \(5\) divides \(2^{k-2}\) but not \(2^{k-3}\), and equals \(2^{k-2}\). The map of the statement is therefore a well defined homomorphism (both \(-1\) and \(5\) have orders dividing \(2\) and \(2^{k-2}\), and \(U_{2^k}\) is abelian). It is injective: if \((-1)^a5^b \equiv 1 \pmod{2^k}\), then reducing modulo \(4\), where \(5 \equiv 1\), gives \((-1)^a \equiv 1 \pmod4\), so \(a\) is even, and then \(5^b \equiv 1\) gives \(2^{k-2} \mid b\). Both groups have \(2 \cdot 2^{k-2} = 2^{k-1} = \varphi (2^k)\) elements, so it is an isomorphism. Finally \(\mathbb {Z}/2\mathbb {Z}\times \mathbb {Z}/2^{k-2}\mathbb {Z}\) has the three elements \((1, 0)\), \((0, 2^{k-3})\), \((1, 2^{k-3})\) of order \(2\), while a cyclic group has at most one, by Lemma 10.3.2(3) with \(d = 2\).

02Y4 Theorem 10.3.10 Gauss

Let \(n \geq 1\). There is a primitive root modulo \(n\) if and only if \(n\) is \(1\), \(2\), \(4\), \(p^k\) or \(2p^k\), with \(p\) an odd prime and \(k \geq 1\).

Proof â–¼

For \(n = 1, 2, 4\) and \(p^k\) this is Theorems 10.3.9 and 10.3.7, and \(U_{2p^k} \cong U_2 \times U_{p^k} \cong U_{p^k}\) by Theorem 10.2.6, as \(U_2\) is trivial. Conversely, a product \(A \times B\) of two finite groups of even order is not cyclic: by Cauchy’s theorem (Theorem 7.6.8) there are \(x \in A\) and \(y \in B\) of order \(2\), and then \((x, 1)\), \((1, y)\) and \((x, y)\) are three elements of order \(2\), while a cyclic group has at most one. Now \(\varphi (p^k) = p^{k-1}(p - 1)\) is even for odd \(p\), and \(\varphi (2^k) = 2^{k-1}\) is even for \(k \geq 2\).

Now let \(n\) be not of the listed forms. If \(n\) is a power of \(2\), then \(n = 2^k\) with \(k \geq 3\), and \(U_n\) is not cyclic by Theorem 10.3.9. Otherwise \(n\) has an odd prime factor \(p\); write \(n = p^km\) with \(k \geq 1\) and \(p \nmid m\). Since \(n\) is neither \(p^k\) nor \(2p^k\), we have \(m \geq 3\). If \(m\) has an odd prime factor \(q\), write \(m = q^lm^{\prime }\) with \(q \nmid m^{\prime }\); then \(\varphi (m) = \varphi (q^l)\varphi (m^{\prime })\) is even. If \(m\) has no odd prime factor, then \(m = 2^a\) with \(a \geq 2\), and \(\varphi (m) = 2^{a-1}\) is even. In both cases \(U_n \cong U_{p^k} \times U_m\) (Theorem 10.2.6) is a product of two groups of even order, hence not cyclic.

A primitive root \(g\) modulo \(p\) turns multiplication into addition, as a logarithm does: every \(a\) prime to \(p\) is \(a \equiv g^t\) for a unique \(t\) modulo \(p - 1\), the index or discrete logarithm of \(a\). This immediately answers the question of which residues are \(k\)-th powers.

02Y5 Proposition 10.3.11

Let \(p\) be a prime, \(k \geq 1\), \(d = \gcd (k, p - 1)\), and \(p \nmid a\). The congruence \(x^k \equiv a \pmod p\) has a solution if and only if \(a^{(p-1)/d} \equiv 1 \pmod p\), and then it has exactly \(d\) solutions modulo \(p\). The \(k\)-th powers form a subgroup of \(U_p\) of index \(d\).

Proof â–¼

Fix a primitive root \(g\) (Theorem 10.3.3); then \(t \mapsto g^t\) is an isomorphism \(\mathbb {Z}/(p - 1)\mathbb {Z}\to U_p\), under which \(x \mapsto x^k\) becomes \(s \mapsto ks\). Write \(a = g^t\) and \(x = g^s\). The congruence becomes \(ks \equiv t \pmod{p - 1}\), which by Proposition 10.2.4 is solvable if and only if \(d \mid t\), and then has \(d\) solutions \(s\) modulo \(p - 1\), that is, \(d\) solutions \(x\) modulo \(p\). Finally \(a^{(p-1)/d} = g^{t(p-1)/d} \equiv 1\) if and only if \(p - 1 \mid t(p - 1)/d\), that is, \(d \mid t\). The \(k\)-th powers are the image of the homomorphism \(x \mapsto x^k\), whose kernel has \(d\) elements (the solutions for \(a = 1\)), so the image has \((p - 1)/d\) elements and index \(d\).

For instance, for \(p \equiv 2 \pmod3\) every residue is a cube modulo \(p\) (as \(d = \gcd (3, p - 1) = 1\)), while for \(p \equiv 1 \pmod3\) exactly a third of the nonzero residues are cubes. The case \(k = 2\), where \(d = 2\) for every odd prime, is the subject of the next section.
