6.3 Isomorphisms, monomorphisms and epimorphisms0011

Complete. This chapter is written; its proofs await independent checking.

0012 Definition 6.3.1

A morphism \(f \colon X \to Y\) in a category \(\mathcal{C}\) is an isomorphism if there is a morphism \(g \colon Y \to X\) with \(g \circ f = \mathrm{id}_X\) and \(f \circ g = \mathrm{id}_Y\). Two objects \(X\) and \(Y\) are isomorphic, written \(X \cong Y\), if there is an isomorphism \(X \to Y\).

0013 Lemma 6.3.2

Let \(f \colon X \to Y\) be an isomorphism. There is exactly one morphism \(g \colon Y \to X\) with \(g \circ f = \mathrm{id}_X\) and \(f \circ g = \mathrm{id}_Y\).

Proof â–¼

Suppose \(g\) and \(g'\) both have the property. Then \(g = g \circ \mathrm{id}_Y = g \circ (f \circ g') = (g \circ f) \circ g' = \mathrm{id}_X \circ g' = g'\).

0014 Notation 6.3.3

The morphism of Lemma 6.3.2 is the inverse of \(f\), written \(f^{-1}\).

0015 Definition 6.3.4

A morphism \(f \colon X \to Y\) is a monomorphism if for every object \(W\) and all \(g_1, g_2 \colon W \to X\), the equality \(f \circ g_1 = f \circ g_2\) implies \(g_1 = g_2\). It is an epimorphism if for every object \(Z\) and all \(h_1, h_2 \colon Y \to Z\), the equality \(h_1 \circ f = h_2 \circ f\) implies \(h_1 = h_2\).

0016 Lemma 6.3.5

Let \(\mathcal{C}\) be a category.

  1. Every isomorphism is both a monomorphism and an epimorphism.

  2. A composition of monomorphisms is a monomorphism, and a composition of epimorphisms is an epimorphism.

  3. If \(g \circ f\) is a monomorphism, then \(f\) is a monomorphism. If \(g \circ f\) is an epimorphism, then \(g\) is an epimorphism.

Proof â–¼

By Remark 6.2.12, a monomorphism in \(\mathcal{C}\) is the same thing as an epimorphism in \(\mathcal{C}^{\mathrm{op}}\), so in each part it suffices to prove the statement about monomorphisms.

(1) Let \(f\) be an isomorphism and suppose \(f \circ g_1 = f \circ g_2\). Composing with \(f^{-1}\) on the left gives \(g_1 = g_2\).

(2) Let \(f \colon X \to Y\) and \(f' \colon Y \to Z\) be monomorphisms and suppose \(f' \circ f \circ g_1 = f' \circ f \circ g_2\). Since \(f'\) is a monomorphism, \(f \circ g_1 = f \circ g_2\), and since \(f\) is a monomorphism, \(g_1 = g_2\).

(3) Suppose \(f \circ g_1 = f \circ g_2\). Then \((g \circ f) \circ g_1 = (g \circ f) \circ g_2\), so \(g_1 = g_2\).

0017 Lemma 6.3.6

In the category \(\mathsf{Set}\), a map is a monomorphism if and only if it is injective, and an epimorphism if and only if it is surjective.

Proof â–¼

Let \(f \colon X \to Y\) be a map of small sets.

Suppose \(f\) is injective and \(f \circ g_1 = f \circ g_2\) for maps \(g_1, g_2 \colon W \to X\). For every \(w \in W\) we have \(f(g_1(w)) = f(g_2(w))\), hence \(g_1(w) = g_2(w)\); so \(g_1 = g_2\). Conversely, suppose \(f\) is a monomorphism and \(f(x_1) = f(x_2)\). Let \(W = \{ 0\} \), which is a small set, and let \(g_i \colon W \to X\) be the map with \(g_i(0) = x_i\). Then \(f \circ g_1 = f \circ g_2\), so \(g_1 = g_2\), that is, \(x_1 = x_2\).

Suppose \(f\) is surjective and \(h_1 \circ f = h_2 \circ f\) for maps \(h_1, h_2 \colon Y \to Z\). Every \(y \in Y\) is of the form \(f(x)\), so \(h_1(y) = h_1(f(x)) = h_2(f(x)) = h_2(y)\); hence \(h_1 = h_2\). Conversely, suppose \(f\) is an epimorphism. Let \(Z = \{ 0, 1\} \), let \(h_1 \colon Y \to Z\) be the map with \(h_1(y) = 1\) if \(y \in f(X)\) and \(h_1(y) = 0\) otherwise, and let \(h_2\) be the constant map with value \(1\). Then \(h_1 \circ f = h_2 \circ f\), so \(h_1 = h_2\), which says exactly that \(f(X) = Y\).

0018 Counterexample 6.3.7

A morphism that is both a monomorphism and an epimorphism need not be an isomorphism. Let \(P = \{ 0, 1\} \) with the usual order \(0 \leq 1\), viewed as a category as in Example 6.2.9, and let \(u \colon 0 \to 1\) be the unique morphism. Every set of morphisms of \(P\) has at most one element, so any two parallel morphisms are equal; hence every morphism of \(P\) is a monomorphism and an epimorphism. But \(u\) is not an isomorphism, because \(\operatorname {Hom}_P(1, 0) = \emptyset \).

0019 Counterexample 6.3.8

The same phenomenon occurs in categories of algebraic objects. Let \(i \colon \mathbb {N}\to \mathbb {Z}\) be the inclusion, a homomorphism of monoids under addition. Then \(i\) is a monomorphism and an epimorphism in \(\mathsf{Mon}\), but not an isomorphism.

Indeed, if \(u, v \colon M \to \mathbb {N}\) are homomorphisms with \(i \circ u = i \circ v\), then \(u = v\) because \(i\) is injective. Next, let \(f, g \colon \mathbb {Z}\to M\) be homomorphisms with \(f \circ i = g \circ i\), that is, \(f(n) = g(n)\) for all \(n \in \mathbb {N}\). Writing the operation of \(M\) multiplicatively, for every \(n \in \mathbb {N}\) we have

\[ f(-n) = f(-n) \, g(n + (-n)) = f(-n) \, g(n) \, g(-n) = f(-n) \, f(n) \, g(-n) = f(-n + n) \, g(-n) = g(-n), \]

where we used \(g(0) = e\) and \(f(0) = e\). Hence \(f = g\). Finally, an isomorphism of monoids is in particular a bijection, and \(i\) is not surjective.

001A Remark 6.3.9

Counterexample 6.3.8 shows that being an epimorphism is not the same as being surjective, even in categories whose morphisms are maps. Whether a morphism is an epimorphism depends on the whole category, not only on the morphism itself.
