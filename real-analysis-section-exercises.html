26.14 Exercises012R

Complete. This chapter is written; its proofs await independent checking.

012S Exercise 26.14.1

Show that \(e = \exp (1)\) is irrational.

Solution â–¼

If \(e = p/q\), then \(x = q!(e - \sum _{k \leq q}1/k!)\) is a positive integer, but \(x = \sum _{k {\gt} q}q!/k! {\lt} \sum _{j \geq 1}(q + 1)^{-j} = 1/q \leq 1\).

012T Exercise 26.14.2

Show that \(\sum 1/n\) diverges while \(\sum (-1)^n/n\) converges, and that the latter series can be rearranged to converge to any given real number.

Solution â–¼

\(\sum _{2^j {\lt} n \leq 2^{j+1}}1/n \geq 1/2\), so the partial sums are unbounded; the alternating series converges by Lemma 26.5.5. For a target \(c\), add positive terms \(1/(2k)\) until the partial sum exceeds \(c\), then negative terms until it is below \(c\), and so on; since both the positive and the negative parts diverge and the terms tend to \(0\), the partial sums converge to \(c\).

012U Exercise 26.14.3

Show that \(f_n(x) = \sqrt{x^2 + 1/n}\) are smooth and converge uniformly on \(\mathbb {R}\) to \(|x|\), which is not differentiable. Prove that if \(f_n \to f\) pointwise and \(f_n' \to g\) uniformly on an interval, with \(f_n\) continuously differentiable, then \(f\) is differentiable with \(f' = g\).

Solution â–¼

\(0 \leq \sqrt{x^2 + 1/n} - |x| = \frac{1/n}{\sqrt{x^2 + 1/n} + |x|} \leq 1/\sqrt{n}\). For the second part, \(f_n(x) = f_n(a) + \int _a^xf_n'\) converges to \(f(a) + \int _a^xg\), so \(f(x) = f(a) + \int _a^xg\) and Theorem 26.8.3 applies.

012V Exercise 26.14.4

Show that \((r, \theta ) \mapsto (r\cos \theta , r\sin \theta )\) is a local diffeomorphism \((0, \infty ) \times \mathbb {R}\to \mathbb {R}^2 \setminus \{ 0\} \), but not injective, and compute its Jacobian determinant.

012W Exercise 26.14.5

(Peano’s theorem.) Show that if \(F\) is only continuous, \(x' = F(t, x)\) still has local solutions, by applying the Arzelà–Ascoli theorem to the Euler polygons \(\varphi _k\) with step \(1/k\).

025O Exercise 26.14.7

Compute \(\lim _n\frac{n^2 + 1}{2n^2 - n}\), \(\lim _n(\sqrt{n^2 + n} - n)\) and \(\lim _n(2^n + 3^n)^{1/n}\).

Solution â–¼

Dividing by \(n^2\), the first is \(\frac{1 + 1/n^2}{2 - 1/n} \to \frac12\). For the second, \(\sqrt{n^2 + n} - n = \frac{n}{\sqrt{n^2 + n} + n} = \frac{1}{\sqrt{1 + 1/n} + 1} \to \frac12\). For the third, \(3 \leq (2^n + 3^n)^{1/n} \leq (2 \cdot 3^n)^{1/n} = 3 \cdot 2^{1/n} \to 3\) (Proposition 26.2.9(2)), so the limit is \(3\) by the squeeze theorem.

025P Exercise 26.14.8

Show that \(\limsup _na_n\) is the largest element of \(\bar{\mathbb {R}}\) that is a limit of a subsequence of \((a_n)\), and \(\liminf _na_n\) the smallest.

Solution â–¼

Let \(S_n = \sup _{k \geq n}a_k\), a decreasing sequence with limit \(L = \limsup a_n\) (Proposition 26.2.10). If \(a_{n_k} \to \ell \), then \(a_{n_k} \leq S_n\) for \(n_k \geq n\), so \(\ell \leq S_n\) for all \(n\), and \(\ell \leq L\). Conversely, if \(L \in \mathbb {R}\), choose recursively \(n_k {\gt} n_{k-1}\) with \(S_{n_{k-1}+1} - \frac1k {\lt} a_{n_k} \leq S_{n_{k-1}+1}\); both bounds tend to \(L\), so \(a_{n_k} \to L\) by the squeeze theorem. If \(L = +\infty \) the sequence is unbounded above and Theorem 26.2.12 applies; if \(L = -\infty \) then \(a_n \leq S_n \to -\infty \). The statement for \(\liminf \) follows by passing to \((-a_n)\).

025Q Exercise 26.14.9

Show that \(f(x) = x\mathbf{1}_\mathbb {Q}(x)\) is continuous at \(0\) and discontinuous at every \(a \neq 0\).

Solution â–¼

\(|f(x)| \leq |x|\), so \(f(x) \to 0 = f(0)\) as \(x \to 0\). For \(a \neq 0\), choose rational \(x_n \to a\) and irrational \(y_n \to a\) (Counterexample 26.3.10); then \(f(x_n) = x_n \to a\) and \(f(y_n) = 0\), so \(f\) has no limit at \(a\) (Theorem 26.3.4), in particular it is not continuous there.

025R Exercise 26.14.10

Let \(f \colon \mathbb {R}\to \mathbb {R}\) be continuous with \(f(x + y) = f(x) + f(y)\) for all \(x, y\). Show that \(f(x) = cx\) with \(c = f(1)\).

Solution â–¼

\(f(0) = f(0) + f(0)\) gives \(f(0) = 0\), then \(f(-x) = -f(x)\), and by induction \(f(nx) = nf(x)\) for \(n \in \mathbb {N}\), hence for \(n \in \mathbb {Z}\). For \(x = p/q\) with \(q \geq 1\), \(qf(p/q) = f(p) = pc\), so \(f(x) = cx\) on \(\mathbb {Q}\). For real \(x\), choose rational \(x_n \to x\) (density of \(\mathbb {Q}\)); by continuity \(f(x) = \lim f(x_n) = \lim cx_n = cx\).

025S Exercise 26.14.11

Show that a continuous periodic function \(f \colon \mathbb {R}\to \mathbb {R}\) is bounded and uniformly continuous.

Solution â–¼

Let \(p {\gt} 0\) be a period. On \([0, 2p]\), \(f\) is bounded and uniformly continuous (Theorem 26.4.10 and Proposition 26.4.13(3)), and every value of \(f\) is taken on \([0, p]\). Given \(\varepsilon \), let \(\delta {\lt} p\) work on \([0, 2p]\). If \(|x - y| {\lt} \delta \), translating both by the same multiple of \(p\) we may assume \(0 \leq \min (x, y) {\lt} p\), and then \(x, y \in [0, 2p]\), so \(|f(x) - f(y)| {\lt} \varepsilon \).

025T Exercise 26.14.12

Show that \(n(a^{1/n} - 1) \to \log a\) for every \(a {\gt} 0\).

Solution â–¼

Let \(t = \log a\), so \(a^{1/n} = e^{t/n}\). If \(t = 0\) both sides vanish. Otherwise \(n(e^{t/n} - 1) = t\cdot \frac{e^{t/n} - 1}{t/n} \to t\) by Proposition 26.7.5(1) and Theorem 26.3.4, since \(t/n \to 0\) and \(t/n \neq 0\).
