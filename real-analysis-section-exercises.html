27.16 Exercises012R

Complete. This chapter is written; its proofs await independent checking.

012S Exercise 27.16.1

Show that \(e = \exp (1)\) is irrational.

Solution â–¼

If \(e = p/q\), then \(x = q!(e - \sum _{k \leq q}1/k!)\) is a positive integer, but \(x = \sum _{k {\gt} q}q!/k! {\lt} \sum _{j \geq 1}(q + 1)^{-j} = 1/q \leq 1\).

012T Exercise 27.16.2

Show that \(\sum 1/n\) diverges while \(\sum (-1)^n/n\) converges, and that the latter series can be rearranged to converge to any given real number.

Solution â–¼

\(\sum _{2^j {\lt} n \leq 2^{j+1}}1/n \geq 1/2\), so the partial sums are unbounded; the alternating series converges by Lemma 27.5.7. For a target \(c\), add positive terms \(1/(2k)\) until the partial sum exceeds \(c\), then negative terms until it is below \(c\), and so on; since both the positive and the negative parts diverge and the terms tend to \(0\), the partial sums converge to \(c\). This is the special case \(\alpha = \beta = c\) of Theorem 27.5.9, where the details are written out.

02ZJ Exercise 27.16.3

Let \(\sum _na_n\) be a convergent series of real numbers and \(\sigma \colon \mathbb {N}\to \mathbb {N}\) a bijection that moves every index by a bounded amount: \(|\sigma (n) - n| \leq K\) for all \(n\). Show that \(\sum _na_{\sigma (n)}\) converges to the same sum. Deduce that the rearrangement of Example 27.5.11(1) moves some indices arbitrarily far.

Solution â–¼

Let \(S_N = \sum _{n \leq N}a_n\) and \(T_N = \sum _{n \leq N}a_{\sigma (n)} = \sum _{m \in \sigma (\{ 0, \ldots , N\} )}a_m\). If \(m \leq N - K\), then \(\sigma ^{-1}(m) \leq m + K \leq N\), so \(m \in \sigma (\{ 0, \ldots , N\} )\); and every \(m \in \sigma (\{ 0, \ldots , N\} )\) satisfies \(m \leq N + K\). So \(\{ 0, \ldots , N\} \) and \(\sigma (\{ 0, \ldots , N\} )\) differ only in indices between \(N - K\) and \(N + K\), and \(|T_N - S_N| \leq \sum _{N - K {\lt} m \leq N + K}|a_m|\), a sum of at most \(2K\) terms, which tends to \(0\) as \(a_m \to 0\). Hence \(T_N - S_N \to 0\). The rearrangement of the example changes the sum, so it cannot move indices by a bounded amount; indeed its \(3m\)-th term is \(-1/(4m)\), the \(4m\)-th term of \(S\), moved by \(m\) places.

012U Exercise 27.16.4

Show that \(f_n(x) = \sqrt{x^2 + 1/n}\) are smooth and converge uniformly on \(\mathbb {R}\) to \(|x|\), which is not differentiable. Prove that if \(f_n \to f\) pointwise and \(f_n' \to g\) uniformly on an interval, with \(f_n\) continuously differentiable, then \(f\) is differentiable with \(f' = g\).

Solution â–¼

\(0 \leq \sqrt{x^2 + 1/n} - |x| = \frac{1/n}{\sqrt{x^2 + 1/n} + |x|} \leq 1/\sqrt{n}\). For the second part, \(f_n(x) = f_n(a) + \int _a^xf_n'\) converges to \(f(a) + \int _a^xg\), so \(f(x) = f(a) + \int _a^xg\) and Theorem 27.8.3 applies.

025O Exercise 27.16.8

Compute \(\lim _n\frac{n^2 + 1}{2n^2 - n}\), \(\lim _n(\sqrt{n^2 + n} - n)\) and \(\lim _n(2^n + 3^n)^{1/n}\).

Solution â–¼

Dividing by \(n^2\), the first is \(\frac{1 + 1/n^2}{2 - 1/n} \to \frac12\). For the second, \(\sqrt{n^2 + n} - n = \frac{n}{\sqrt{n^2 + n} + n} = \frac{1}{\sqrt{1 + 1/n} + 1} \to \frac12\). For the third, \(3 \leq (2^n + 3^n)^{1/n} \leq (2 \cdot 3^n)^{1/n} = 3 \cdot 2^{1/n} \to 3\) (Proposition 27.2.9(2)), so the limit is \(3\) by the squeeze theorem.

025P Exercise 27.16.9

Show that \(\limsup _na_n\) is the largest element of \(\bar{\mathbb {R}}\) that is a limit of a subsequence of \((a_n)\), and \(\liminf _na_n\) the smallest.

Solution â–¼

Let \(S_n = \sup _{k \geq n}a_k\), a decreasing sequence with limit \(L = \limsup a_n\) (Proposition 27.2.10). If \(a_{n_k} \to \ell \), then \(a_{n_k} \leq S_n\) for \(n_k \geq n\), so \(\ell \leq S_n\) for all \(n\), and \(\ell \leq L\). Conversely, if \(L \in \mathbb {R}\), choose recursively \(n_k {\gt} n_{k-1}\) with \(S_{n_{k-1}+1} - \frac1k {\lt} a_{n_k} \leq S_{n_{k-1}+1}\); both bounds tend to \(L\), so \(a_{n_k} \to L\) by the squeeze theorem. If \(L = +\infty \) the sequence is unbounded above and Theorem 27.2.12 applies; if \(L = -\infty \) then \(a_n \leq S_n \to -\infty \). The statement for \(\liminf \) follows by passing to \((-a_n)\).

025Q Exercise 27.16.10

Show that \(f(x) = x\mathbf{1}_\mathbb {Q}(x)\) is continuous at \(0\) and discontinuous at every \(a \neq 0\).

Solution â–¼

\(|f(x)| \leq |x|\), so \(f(x) \to 0 = f(0)\) as \(x \to 0\). For \(a \neq 0\), choose rational \(x_n \to a\) and irrational \(y_n \to a\) (Counterexample 27.3.10); then \(f(x_n) = x_n \to a\) and \(f(y_n) = 0\), so \(f\) has no limit at \(a\) (Theorem 27.3.4), in particular it is not continuous there.

025R Exercise 27.16.11

Let \(f \colon \mathbb {R}\to \mathbb {R}\) be continuous with \(f(x + y) = f(x) + f(y)\) for all \(x, y\). Show that \(f(x) = cx\) with \(c = f(1)\).

Solution â–¼

\(f(0) = f(0) + f(0)\) gives \(f(0) = 0\), then \(f(-x) = -f(x)\), and by induction \(f(nx) = nf(x)\) for \(n \in \mathbb {N}\), hence for \(n \in \mathbb {Z}\). For \(x = p/q\) with \(q \geq 1\), \(qf(p/q) = f(p) = pc\), so \(f(x) = cx\) on \(\mathbb {Q}\). For real \(x\), choose rational \(x_n \to x\) (density of \(\mathbb {Q}\)); by continuity \(f(x) = \lim f(x_n) = \lim cx_n = cx\).

025S Exercise 27.16.12

Show that a continuous periodic function \(f \colon \mathbb {R}\to \mathbb {R}\) is bounded and uniformly continuous.

Solution â–¼

Let \(p {\gt} 0\) be a period. On \([0, 2p]\), \(f\) is bounded and uniformly continuous (Theorem 27.4.10 and Proposition 27.4.13(3)), and every value of \(f\) is taken on \([0, p]\). Given \(\varepsilon \), let \(\delta {\lt} p\) work on \([0, 2p]\). If \(|x - y| {\lt} \delta \), translating both by the same multiple of \(p\) we may assume \(0 \leq \min (x, y) {\lt} p\), and then \(x, y \in [0, 2p]\), so \(|f(x) - f(y)| {\lt} \varepsilon \).

025T Exercise 27.16.13

Show that \(n(a^{1/n} - 1) \to \log a\) for every \(a {\gt} 0\).

Solution â–¼

Let \(t = \log a\), so \(a^{1/n} = e^{t/n}\). If \(t = 0\) both sides vanish. Otherwise \(n(e^{t/n} - 1) = t\cdot \frac{e^{t/n} - 1}{t/n} \to t\) by Proposition 27.7.5(1) and Theorem 27.3.4, since \(t/n \to 0\) and \(t/n \neq 0\).

02P3 Exercise 27.16.14

Compute \(\int _0^\pi x^2\sin x\, dx\), and show by integration by parts and induction on \(n\) that \(\int _0^1x^m(1 - x)^n\, dx = \frac{m!\, n!}{(m + n + 1)!}\) for integers \(m, n \geq 0\).

Solution â–¼

Twice by parts: \(\int _0^\pi x^2\sin x\, dx = [-x^2\cos x]_0^\pi + 2\int _0^\pi x\cos x\, dx = \pi ^2 + 2\bigl([x\sin x]_0^\pi - \int _0^\pi \sin x\, dx\bigr) = \pi ^2 + 2(0 - 2) = \pi ^2 - 4\). For the second, let \(B(m, n)\) be the integral. For \(n \geq 1\), take \(f(x) = x^{m+1}/(m + 1)\) and \(g(x) = (1 - x)^n\); the boundary term vanishes at both ends, and \(B(m, n) = \frac{n}{m+1}B(m + 1, n - 1)\). Iterating, \(B(m, n) = \frac{n(n-1) \cdots 1}{(m+1)(m+2) \cdots (m+n)}B(m + n, 0)\), and \(B(m + n, 0) = \frac{1}{m + n + 1}\), which gives \(\frac{m!\, n!}{(m + n + 1)!}\).

02TI Exercise 27.16.15

Let \(f \colon I \to \mathbb {R}\) be continuous on an interval and midpoint convex: \(f(\frac{x + y}2) \leq \frac{f(x) + f(y)}2\) for all \(x, y \in I\). Show that \(f\) is convex. (Without continuity this fails: a \(\mathbb {Q}\)-linear map \(\mathbb {R}\to \mathbb {R}\) that is not \(\mathbb {R}\)-linear, which exists by choosing a basis of \(\mathbb {R}\) over \(\mathbb {Q}\), is midpoint affine but not convex.)

Solution â–¼

By induction on \(k\), \(f(\sum _ix_i/2^k) \leq \sum _if(x_i)/2^k\) for \(2^k\) points \(x_i \in I\) (split them into two halves and apply midpoint convexity to the two averages). Given \(x, y\) and a dyadic \(t = j/2^k \in [0, 1]\), take \(j\) copies of \(x\) and \(2^k - j\) copies of \(y\): \(f(tx + (1 - t)y) \leq tf(x) + (1 - t)f(y)\). Dyadic numbers are dense in \([0, 1]\), and both sides are continuous in \(t\), so the inequality holds for all \(t \in [0, 1]\).

02TJ Exercise 27.16.16

Decide whether the following series converge: \(\sum _{n \geq 1}\frac{n^n}{n!\, 3^n}\), \(\sum _{n \geq 2}\frac{1}{(\log n)^{\log n}}\), \(\sum _{n \geq 1}\bigl(1 - \frac1n\bigr)^{n^2}\), \(\sum _{n \geq 2}\frac{(-1)^n}{\sqrt n + (-1)^n}\).

Solution â–¼

(1) The ratio is \(\frac13(1 + \frac1n)^n \to \frac e3 {\lt} 1\): converges. (2) \((\log n)^{\log n} = n^{\log \log n} \geq n^2\) once \(\log \log n \geq 2\), so it converges by comparison with \(\sum n^{-2}\). (3) The \(n\)-th root is \((1 - \frac1n)^n \to e^{-1} {\lt} 1\): converges. (4) \(\frac{(-1)^n}{\sqrt n + (-1)^n} = \frac{(-1)^n}{\sqrt n} - \frac{1}{\sqrt n(\sqrt n + (-1)^n)}\); the first series converges (alternating), the second diverges by limit comparison with \(\sum \frac1n\); so the series diverges, although its terms are alternating and tend to \(0\) (they are not monotone in absolute value).

037T Exercise 27.16.17

Find the largest volume of a box with edges parallel to the coordinate axes inscribed in the ellipsoid \(x^2/a^2 + y^2/b^2 + z^2/c^2 = 1\) (\(a, b, c {\gt} 0\)).

Solution â–¼

A vertex \((x, y, z)\) with \(x, y, z {\gt} 0\) on the ellipsoid determines the box, of volume \(V = 8xyz\). The volume is a continuous function on the compact part of the ellipsoid with \(x, y, z \geq 0\), positive somewhere and zero when a coordinate vanishes, so its maximum is attained with \(x, y, z {\gt} 0\), where \(\nabla h = (2x/a^2, 2y/b^2, 2z/c^2) \neq 0\). Theorem 27.13.6 gives \(8yz = 2\lambda x/a^2\), \(8xz = 2\lambda y/b^2\), \(8xy = 2\lambda z/c^2\). Multiplying by \(x\), \(y\), \(z\) respectively, \(x^2/a^2 = y^2/b^2 = z^2/c^2 = 4xyz/\lambda \), and the constraint makes each equal to \(\frac13\). So \((x, y, z) = (a, b, c)/\sqrt3\) and the maximal volume is \(8abc/(3\sqrt3)\), a fraction \(2/(\sqrt3\pi ) \approx 0.37\) of the volume \(\frac43\pi abc\) of the ellipsoid.

037U Exercise 27.16.18

Find the points of the hyperbola \(xy = 1\) nearest to the origin, and confirm with Example 27.13.12 that they are strict local minima of the distance.

Solution â–¼

Minimise \(f = x^2 + y^2\) on \(M = \{ h = 0\} \), \(h = xy - 1\); \(M\) is closed and \(f \to \infty \) along \(M\), so a minimum exists, and \(\nabla h = (y, x) \neq 0\) on \(M\). The equations \(2x = \lambda y\), \(2y = \lambda x\) give \(2x^2 = \lambda xy = 2y^2\), so \(y = \pm x\), and \(xy = 1\) forces \(y = x = \pm 1\), with \(\lambda = 2\): the nearest points are \(\pm (1, 1)\), at distance \(\sqrt2\). With \(L = x^2 + y^2 - 2(xy - 1)\), \(L_{xx} = L_{yy} = 2\), \(L_{xy} = -2\), and at \((1, 1)\), \((h_x, h_y) = (1, 1)\); the bordered determinant is \(-(L_{xx} - 2L_{xy} + L_{yy}) = -8 {\lt} 0\), a strict local minimum. Note that \(D^2f = 2I\) alone would also suggest a minimum here, but \(D^2L\) is only semidefinite on \(\mathbb {R}^2\); its restriction to the tangent line \(\mathbb {R}(-1, 1)\) is what counts.

037V Exercise 27.16.19

Prove Hadamard’s inequality: for a real \(n \times n\) matrix \(A\) with columns \(a_1, \ldots , a_n\), \(|\det A| \leq \| a_1\| \cdots \| a_n\| \), with equality for nonzero columns exactly when the columns are pairwise orthogonal. (Geometrically: among parallelepipeds with given edge lengths, the rectangular box has the largest volume.) Hint: maximise \(\det \) on the set of matrices with unit columns.

Solution â–¼

If a column vanishes both sides are \(0\); otherwise divide each column by its length, which divides both sides by \(\prod _j\| a_j\| \). So we must show \(\det A \leq 1\) when all \(\| a_j\| = 1\). The set \(S\) of such matrices is compact in \(\mathbb {R}^{n^2}\), so \(\det \) has a maximum on \(S\) at some \(A\), and the maximum is \(\geq \det I = 1 {\gt} 0\). The constraints \(h_j(A) = \| a_j\| ^2 - 1\) have gradients \(2a_j\) placed in the \(j\)-th block of coordinates, which are nonzero and lie in different blocks, hence are independent. Expanding along the \(j\)-th column, \(\partial \det /\partial a_{ij} = C_{ij}\), the \((i, j)\) cofactor (Proposition 11.5.3). Theorem 27.13.6 gives \(C_{ij} = 2\lambda _ja_{ij}\), that is, \(C = 2A\Lambda \) with \(\Lambda = \operatorname {diag}(\lambda _j)\) and \(C = (C_{ij})\). Since \(\det A \neq 0\), the adjugate formula \(A\, C^T = \det (A)\, I\) gives \(C = \det (A)(A^{-1})^T\), so \(\det (A)\, I = A^TC = 2A^TA\Lambda \). Hence \(\Lambda \) is invertible and \(A^TA = \det (A)(2\Lambda )^{-1}\) is diagonal: the columns of \(A\) are orthogonal unit vectors, \(A\) is orthogonal, and \(\det A = 1\) at the maximum. For the equality case, if the columns are orthogonal, \(|\det A|^2 = \det (A^TA) = \prod _j\| a_j\| ^2\); conversely, equality means that the normalised matrix (with columns \(a_j/\| a_j\| \), possibly after changing the sign of one column) is a maximum point, hence has orthogonal columns by the argument above.

037W Exercise 27.16.20

Let \(y \in \mathbb {R}^n\). Show that the point of the simplex \(\Delta = \{ x \in \mathbb {R}^n : x_i \geq 0, \sum _ix_i = 1\} \) nearest to \(y\) is \(x_i = \max (0, y_i - \tau )\), where \(\tau \) is the unique number with \(\sum _i\max (0, y_i - \tau ) = 1\). Compute it for \(y = (0.8, 0.6, -0.5)\).

Solution â–¼

Minimise the strictly convex function \(f(x) = \frac12\| x - y\| ^2\) subject to \(g_i = -x_i \leq 0\) and \(h = \sum _ix_i - 1 = 0\). The conditions 27.6 read \(x_i - y_i - \mu _i + \lambda = 0\), \(\mu _i \geq 0\), \(\mu _ix_i = 0\). If \(x_i {\gt} 0\) then \(x_i = y_i - \lambda \); if \(x_i = 0\) then \(y_i - \lambda = -\mu _i \leq 0\). In both cases \(x_i = \max (0, y_i - \lambda )\), and \(\sum _ix_i = 1\) determines \(\lambda = \tau \): the function \(t \mapsto \sum _i\max (0, y_i - t)\) is continuous, decreasing, strictly so where positive, equal to \(0\) for \(t \geq \max _iy_i\) and tending to \(\infty \) as \(t \to -\infty \). Conversely, this \(x\) with \(\mu _i = \max (0, \tau - y_i)\) satisfies the conditions, so it is the unique minimum by Theorem 27.13.18 (like the water-filling of Example 27.13.19, with the vessel upside down). For \(y = (0.8, 0.6, -0.5)\), trying \(x_3 = 0\): \((0.8 - \tau ) + (0.6 - \tau ) = 1\) gives \(\tau = 0.2\), and indeed \(-0.5 - 0.2 {\lt} 0\); so \(x = (0.6, 0.4, 0)\).

03DO Exercise 27.16.21

Show that the astroid \(\gamma (t) = (\cos ^3t, \sin ^3t)\), \(t \in [0, 2\pi ]\), has length \(6\), and that it is not regular.

Solution â–¼

\(\gamma ^{\prime }(t) = (-3\cos ^2t\sin t, 3\sin ^2t\cos t)\), so \(|\gamma ^{\prime }(t)| = 3|\sin t\cos t|\sqrt{\cos ^2t + \sin ^2t} = 3|\sin t\cos t|\), which vanishes at the multiples of \(\pi /2\) (the four cusps). By symmetry \(L(\gamma ) = 4\int _0^{\pi /2}3\sin t\cos t\, dt = 4 \cdot \frac32\bigl[\sin ^2t\bigr]_0^{\pi /2} = 6\).

03DP Exercise 27.16.22

Let \(\cosh x = \frac12(e^x + e^{-x})\) and \(\sinh x = \frac12(e^x - e^{-x})\). Show that the graph of \(\cosh \) over \([0, a]\) has length \(\sinh a\).

Solution â–¼

\(\cosh ^{\prime } = \sinh \), \(\sinh ^{\prime } = \cosh \) and \(\cosh ^2 - \sinh ^2 = 1\), so \(\sqrt{1 + \sinh ^2x} = \cosh x\) (which is positive), and \(\int _0^a\cosh x\, dx = \sinh a\) by Example 27.11.5(2) and the fundamental theorem of calculus.

03DQ Exercise 27.16.23

Let \(\gamma (t) = e^{-t}(\cos t, \sin t)\) for \(t \geq 0\). Show that \(\gamma |_{[0, T]}\) has length \(\sqrt2(1 - e^{-T})\). So the logarithmic spiral winds infinitely often around the origin but has finite total length \(\sqrt2\).

Solution â–¼

\(\gamma ^{\prime }(t) = e^{-t}(-\cos t - \sin t, \cos t - \sin t)\), and \(|\gamma ^{\prime }(t)|^2 = e^{-2t}\bigl((\cos t + \sin t)^2 + (\cos t - \sin t)^2\bigr) = 2e^{-2t}\). Hence \(L = \int _0^T\sqrt2e^{-t}\, dt = \sqrt2(1 - e^{-T})\).

03DR Exercise 27.16.24

Show that the Newtonian field \(F(x) = -x/|x|^3\) on \(\mathbb {R}^3 \setminus \{ 0\} \) is the gradient of \(g(x) = 1/|x|\), and compute the work \(\int _\gamma F \cdot d\gamma \) along any piecewise \(C^1\) curve in \(\mathbb {R}^3 \setminus \{ 0\} \) from a point at distance \(r_1\) from the origin to a point at distance \(r_2\).

Solution â–¼

\(\partial _j|x|^{-1} = -\frac12(x_1^2 + x_2^2 + x_3^2)^{-3/2} \cdot 2x_j = -x_j/|x|^3\). By Proposition 27.11.13(5) the work is \(g(\gamma (b)) - g(\gamma (a)) = 1/r_2 - 1/r_1\), whatever the path; it is positive when the particle falls towards the origin, \(r_2 {\lt} r_1\).
