2.5 Formal deductions005C

Complete. This chapter is written; its proofs await independent checking.

We now define formal proofs. The system below, a Hilbert-style system with modus ponens as its only rule, is the one of [End01].

005D Definition 2.5.1

A formula is prime if it is atomic or of the form \(\forall x\, \varphi \). Every formula is built from prime formulas using \(\neg \) and \(\to \) alone. A truth assignment for \(\mathcal{L}\) is a map \(v\) from the set of prime formulas to \(\{ 0, 1\} \); it extends to \(\bar v\) on all formulas as in Definition 2.2.6. A formula is a tautology if \(\bar v(\varphi ) = 1\) for all \(v\), and a set \(\Sigma \) tautologically implies \(\varphi \) if \(\bar v(\varphi ) = 1\) for all \(v\) with \(\bar v(\Sigma ) = \{ 1\} \).

005E Definition 2.5.2

A generalization of a formula \(\alpha \) is a formula \(\forall x_1 \cdots \forall x_n\, \alpha \) with \(n \geq 0\). The logical axioms are all generalizations of formulas of the following forms, where \(x, y, z\) are variables, \(t\) is a term and \(\alpha , \beta \) are formulas:

  1. tautologies;

  2. \(\forall x\, \alpha \to \alpha [t/x]\), where \(t\) is substitutable for \(x\) in \(\alpha \);

  3. \(\forall x\, (\alpha \to \beta ) \to (\forall x\, \alpha \to \forall x\, \beta )\);

  4. \(\alpha \to \forall x\, \alpha \), where \(x \notin \mathrm{FV}(\alpha )\);

  5. \(x = x\);

  6. \(x = y \to (\alpha [x/z] \to \alpha [y/z])\), where \(\alpha \) is atomic.

005F Definition 2.5.3

Let \(\Gamma \) be a set of formulas. A deduction from \(\Gamma \) is a finite sequence \((\alpha _0, \ldots , \alpha _n)\) of formulas such that each \(\alpha _i\) is a logical axiom, or belongs to \(\Gamma \), or is obtained by modus ponens from earlier formulas, that is, there are \(j, k {\lt} i\) with \(\alpha _k = (\alpha _j \to \alpha _i)\). We write \(\Gamma \vdash \varphi \), and say that \(\varphi \) is a theorem of \(\Gamma \), if there is a deduction from \(\Gamma \) whose last formula is \(\varphi \). The set \(\Gamma \) is inconsistent if there is a formula \(\beta \) with \(\Gamma \vdash \beta \) and \(\Gamma \vdash \neg \beta \), and consistent otherwise.

005G Remark 2.5.4

A deduction is finite, so it uses only finitely many formulas of \(\Gamma \). Hence \(\Gamma \vdash \varphi \) if and only if \(\Gamma _0 \vdash \varphi \) for some finite \(\Gamma _0 \subseteq \Gamma \), and \(\Gamma \) is consistent if and only if all its finite subsets are. Whether \(\Gamma \vdash \varphi \) holds could depend on the language in which deductions are carried out; see Lemma 2.5.12 below.

005H Lemma 2.5.5 Rule T

If \(\Gamma \vdash \alpha _1, \ldots , \Gamma \vdash \alpha _n\) and \(\{ \alpha _1, \ldots , \alpha _n\} \) tautologically implies \(\beta \), then \(\Gamma \vdash \beta \). In particular, if \(\Gamma \) is inconsistent, then \(\Gamma \vdash \beta \) for every formula \(\beta \).

Proof â–¼

The formula \(\alpha _1 \to (\alpha _2 \to \cdots (\alpha _n \to \beta ) \cdots )\) is a tautology, hence a logical axiom. Applying modus ponens \(n\) times gives \(\Gamma \vdash \beta \). For the second claim, \(\{ \gamma , \neg \gamma \} \) tautologically implies every formula.

005I Theorem 2.5.6 Soundness

If \(\Gamma \vdash \varphi \), then \(\Gamma \models \varphi \). In particular, a set of formulas that is satisfied by some structure and assignment is consistent.

Proof â–¼

We first show that every logical axiom is valid. If \(\alpha \) is valid, so is every generalization of \(\alpha \), by the definition of satisfaction. Fix \(\mathcal{A}\) and \(s\). (A1) Let \(v(\pi ) = 1\) if and only if \(\mathcal{A} \models \pi [s]\), for prime \(\pi \). By induction, \(\bar v(\alpha ) = 1\) if and only if \(\mathcal{A} \models \alpha [s]\); so tautologies are satisfied. (A2) If \(\mathcal{A} \models \forall x\, \alpha [s]\) then \(\mathcal{A} \models \alpha [s[x \mapsto t^{\mathcal{A}}[s]]]\), which by Lemma 2.4.6 means \(\mathcal{A} \models \alpha [t/x][s]\). (A3) is immediate from the definitions. (A4) If \(x \notin \mathrm{FV}(\alpha )\), then \(s\) and \(s[x \mapsto a]\) agree on \(\mathrm{FV}(\alpha )\), so this follows from Lemma 2.4.4. (A5) is clear. (A6) If \(s(x) = s(y) = a\), then by Lemma 2.4.6 both \(\alpha [x/z]\) and \(\alpha [y/z]\) are satisfied under \(s\) if and only if \(\alpha \) is satisfied under \(s[z \mapsto a]\).

Now let \((\alpha _0, \ldots , \alpha _n)\) be a deduction from \(\Gamma \) and let \((\mathcal{A}, s)\) satisfy \(\Gamma \). By induction on \(i\), \(\mathcal{A} \models \alpha _i[s]\): this holds for axioms and elements of \(\Gamma \), and if \(\mathcal{A} \models \alpha _j[s]\) and \(\mathcal{A} \models (\alpha _j \to \alpha _i)[s]\) then \(\mathcal{A} \models \alpha _i[s]\). For the last claim, no \((\mathcal{A}, s)\) satisfies both \(\beta \) and \(\neg \beta \).

005J Theorem 2.5.7 Generalization theorem

If \(\Gamma \vdash \varphi \) and \(x\) is not free in any formula of \(\Gamma \), then \(\Gamma \vdash \forall x\, \varphi \).

Proof â–¼

We show by induction on \(i\) that \(\Gamma \vdash \forall x\, \alpha _i\) for every formula \(\alpha _i\) of a deduction \((\alpha _0, \ldots , \alpha _n)\) from \(\Gamma \). If \(\alpha _i\) is a logical axiom, so is its generalization \(\forall x\, \alpha _i\). If \(\alpha _i \in \Gamma \), then \(x \notin \mathrm{FV}(\alpha _i)\), so \(\alpha _i \to \forall x\, \alpha _i\) is an instance of (A4), and modus ponens gives \(\Gamma \vdash \forall x\, \alpha _i\). If \(\alpha _i\) is obtained from \(\alpha _j\) and \(\alpha _j \to \alpha _i\) by modus ponens, then by induction \(\Gamma \vdash \forall x\, \alpha _j\) and \(\Gamma \vdash \forall x\, (\alpha _j \to \alpha _i)\); using the instance \(\forall x\, (\alpha _j \to \alpha _i) \to (\forall x\, \alpha _j \to \forall x\, \alpha _i)\) of (A3) and modus ponens twice, \(\Gamma \vdash \forall x\, \alpha _i\).

005K Theorem 2.5.8 Deduction theorem

\(\Gamma \cup \{ \gamma \} \vdash \varphi \) if and only if \(\Gamma \vdash \gamma \to \varphi \).

Proof â–¼

If \(\Gamma \vdash \gamma \to \varphi \), then \(\Gamma \cup \{ \gamma \} \) proves both \(\gamma \to \varphi \) and \(\gamma \), hence \(\varphi \). Conversely, let \((\alpha _0, \ldots , \alpha _n)\) be a deduction from \(\Gamma \cup \{ \gamma \} \); we show \(\Gamma \vdash \gamma \to \alpha _i\) by induction on \(i\). If \(\alpha _i = \gamma \), then \(\gamma \to \gamma \) is a tautology. If \(\alpha _i\) is a logical axiom or lies in \(\Gamma \), then \(\Gamma \vdash \alpha _i\), and \(\alpha _i\) tautologically implies \(\gamma \to \alpha _i\); apply Lemma 2.5.5. If \(\alpha _i\) comes from \(\alpha _j\) and \(\alpha _j \to \alpha _i\) by modus ponens, then by induction \(\Gamma \) proves \(\gamma \to \alpha _j\) and \(\gamma \to (\alpha _j \to \alpha _i)\), and these two formulas tautologically imply \(\gamma \to \alpha _i\).

005L Corollary 2.5.9 Reductio ad absurdum

If \(\Gamma \cup \{ \neg \varphi \} \) is inconsistent, then \(\Gamma \vdash \varphi \). If \(\Gamma \cup \{ \varphi \} \) is inconsistent, then \(\Gamma \vdash \neg \varphi \).

Proof â–¼

If \(\Gamma \cup \{ \neg \varphi \} \) proves \(\beta \) and \(\neg \beta \), then by Theorem 2.5.8 \(\Gamma \) proves \(\neg \varphi \to \beta \) and \(\neg \varphi \to \neg \beta \), which tautologically imply \(\varphi \). The second statement is proved in the same way, using that \(\{ \varphi \to \beta , \varphi \to \neg \beta \} \) tautologically implies \(\neg \varphi \).

For a constant symbol \(c\) and a variable \(y\), let \(\alpha [y/c]\) denote the result of replacing every occurrence of \(c\) in \(\alpha \) by \(y\) (defined by recursion like substitution, but also inside the scope of quantifiers).

005M Lemma 2.5.10

Let \((\alpha _0, \ldots , \alpha _n)\) be a deduction from \(\Gamma \), let \(c\) be a constant symbol that does not occur in any formula of \(\Gamma \), and let \(y\) be a variable that does not occur in any \(\alpha _i\). Then \((\alpha _0[y/c], \ldots , \alpha _n[y/c])\) is a deduction from \(\Gamma \).

Proof â–¼

Elements of \(\Gamma \) are unchanged, and replacement commutes with \(\to \), so applications of modus ponens remain applications of modus ponens. It remains to see that the replacement of a logical axiom \(\alpha \) is a logical axiom. Replacement commutes with generalization, so we may assume \(\alpha \) is of one of the forms (A1)–(A6). Note that \(y\) does not occur in \(\alpha \).

(A1) Let \(w\) be a truth assignment, and define \(v(\pi ) = w(\pi [y/c])\) for prime \(\pi \); replacement sends prime formulas to prime formulas and commutes with \(\neg \) and \(\to \), so \(\bar v(\alpha ) = \bar w(\alpha [y/c])\). Hence if \(\alpha \) is a tautology so is \(\alpha [y/c]\). (A2) By induction on formulas, \(\beta [t/x][y/c] = \beta [y/c][t[y/c]/x]\). The term \(t[y/c]\) is substitutable for \(x\) in \(\beta [y/c]\): the only variable it may contain besides those of \(t\) is \(y\), and \(y\) is not quantified anywhere in \(\beta \). (A3), (A5) are clear, and (A4) is preserved because the variable \(x\) occurs in \(\alpha \), so \(x \neq y\), and replacing a constant by \(y\) does not make \(x\) free. (A6) Write the axiom as \(x = x' \to (\beta [x/z] \to \beta [x'/z])\) with \(\beta \) atomic; renaming \(z\) if necessary we may assume \(z \neq y\). Then its replacement is \(x = x' \to (\beta [y/c][x/z] \to \beta [y/c][x'/z])\), again an instance of (A6).

005N Corollary 2.5.11 Generalization on constants

Suppose \(\Gamma \vdash \varphi [c/x]\), where the constant symbol \(c\) occurs neither in \(\Gamma \) nor in \(\varphi \). Then \(\Gamma \vdash \forall x\, \varphi \).

Proof â–¼

Choose a deduction of \(\varphi [c/x]\) from \(\Gamma \), and a variable \(y \neq x\) that occurs neither in this deduction nor in \(\varphi \). Since \(c\) does not occur in \(\varphi \), we have \(\varphi [c/x][y/c] = \varphi [y/x]\). By Lemma 2.5.10, there is a deduction of \(\varphi [y/x]\) from a finite subset \(\Gamma _0 \subseteq \Gamma \) in whose formulas \(y\) does not occur. By Theorem 2.5.7, \(\Gamma _0 \vdash \forall y\, \varphi [y/x]\).

By Lemma 2.3.9, \(x\) is substitutable for \(y\) in \(\varphi [y/x]\) and \(\varphi [y/x][x/y] = \varphi \), so \(\forall y\, \varphi [y/x] \to \varphi \) is an instance of (A2). Hence \(\{ \forall y\, \varphi [y/x]\} \vdash \varphi \). The variable \(x\) is not free in \(\forall y\, \varphi [y/x]\), so Theorem 2.5.7 and Theorem 2.5.8 give \(\vdash \forall y\, \varphi [y/x] \to \forall x\, \varphi \). By modus ponens, \(\Gamma \vdash \forall x\, \varphi \).

005O Lemma 2.5.12

Let \(\mathcal{L}'\) be obtained from \(\mathcal{L}\) by adding new constant symbols. If \(\Gamma \cup \{ \varphi \} \) is a set of \(\mathcal{L}\)-formulas and \(\Gamma \vdash \varphi \) by a deduction in \(\mathcal{L}'\), then \(\Gamma \vdash \varphi \) by a deduction in \(\mathcal{L}\). In particular, a set of \(\mathcal{L}\)-formulas that is consistent in \(\mathcal{L}\) is consistent in \(\mathcal{L}'\).

Proof â–¼

A deduction in \(\mathcal{L}'\) contains finitely many new constants. Replace them one at a time by distinct variables not occurring in the deduction. By Lemma 2.5.10 (applied in \(\mathcal{L}'\)), the result is a deduction from \(\Gamma \) of \(\varphi \), which is unchanged because it contains no new constants. All its formulas are \(\mathcal{L}\)-formulas, and an \(\mathcal{L}\)-formula that is a logical axiom of \(\mathcal{L}'\) is a logical axiom of \(\mathcal{L}\) (for (A1), every prime \(\mathcal{L}\)-formula is a prime \(\mathcal{L}'\)-formula). The last statement follows by applying the first to \(\varphi = (x = x)\) and \(\varphi = \neg (x = x)\), using Lemma 2.5.5.

005P Lemma 2.5.13 Equality

For all terms \(t, t', t'', t_1, \ldots , t_n, s_1, \ldots , s_n\):

  1. \(\vdash t = t\);

  2. \(\{ t = t'\} \vdash t' = t\);

  3. \(\{ t = t', t' = t''\} \vdash t = t''\);

  4. \(\{ t_1 = s_1, \ldots , t_n = s_n\} \vdash f(t_1, \ldots , t_n) = f(s_1, \ldots , s_n)\) for every \(n\)-ary function symbol \(f\);

  5. \(\{ t_1 = s_1, \ldots , t_n = s_n, R(t_1, \ldots , t_n)\} \vdash R(s_1, \ldots , s_n)\) for every \(n\)-ary relation symbol \(R\).

Proof â–¼

We use the following observation. If \(\vdash \beta \) where \(\beta \) has no quantifiers, and \(x_1, \ldots , x_k\) are distinct variables not occurring in the terms \(u_1, \ldots , u_k\), then \(\vdash \beta [u_1/x_1] \cdots [u_k/x_k]\). Indeed, by Theorem 2.5.7, \(\vdash \forall x_1 \cdots \forall x_k\, \beta \), and we remove the quantifiers one at a time with (A2): each term \(u_i\) is substitutable because it contains none of the quantified variables and the remaining formula has no other quantifiers. In each part below, the variables used are chosen distinct and not occurring in the terms of the statement.

(1) Apply the observation to the axiom \(x = x\). (2) Let \(\alpha \) be \(z = x\). The instance \(x = y \to (x = x \to y = x)\) of (A6), with \(x := t\) and \(y := t'\), together with (1) gives the claim. (3) Let \(\alpha \) be \(z = w\). The instance \(x = y \to (x = w \to y = w)\) of (A6), with \(x := t'\), \(y := t\), \(w := t''\), gives \(\vdash t' = t \to (t' = t'' \to t = t'')\); combine with (2). (4) For \(0 \leq k \leq n\) let \(a_k = f(y_1, \ldots , y_k, x_{k+1}, \ldots , x_n)\). With \(\alpha \) the atomic formula \(f(x_1, \ldots , x_n) = f(y_1, \ldots , y_{k-1}, z, x_{k+1}, \ldots , x_n)\), axiom (A6) gives \(\vdash x_k = y_k \to (f(x_1, \ldots , x_n) = a_{k-1} \to f(x_1, \ldots , x_n) = a_k)\). Starting from \(f(x_1, \ldots , x_n) = a_0\), which holds by (1), we obtain \(\{ x_1 = y_1, \ldots , x_n = y_n\} \vdash f(x_1, \ldots , x_n) = a_n\). By the deduction theorem this becomes a deducible quantifier-free implication, and the observation with \(x_i := t_i\), \(y_i := s_i\) gives the claim. (5) is proved in the same way as (4), with \(\alpha \) the atomic formula \(R(y_1, \ldots , y_{k-1}, z, x_{k+1}, \ldots , x_n)\).

005Q Lemma 2.5.14 Alphabetic variants

Let \(\varphi \) be a formula, \(x\) a variable and \(t\) a term. There is a formula \(\varphi '\) with \(c(\varphi ') = c(\varphi )\) such that \(t\) is substitutable for \(x\) in \(\varphi '\), \(\vdash \varphi \to \varphi '\) and \(\vdash \varphi ' \to \varphi \).

Proof â–¼

By induction on \(\varphi \). For atomic \(\varphi \) take \(\varphi ' = \varphi \). For \(\neg \psi \) and \(\psi \to \chi \), take \(\neg \psi '\) and \(\psi ' \to \chi '\) and use Lemma 2.5.5. Let \(\varphi = \forall y\, \psi \), and let \(\psi '\) be given by induction. Choose a variable \(z\) that does not occur in \(\psi '\) or in \(t\) and is different from \(x\), and put \(\varphi ' = \forall z\, \psi '[z/y]\).

The term \(t\) is substitutable for \(x\) in \(\varphi '\). If \(x = y\), then \(x\) is not free in \(\varphi '\). If \(x \neq y\), then \(z\) does not occur in \(t\), and \(t\) is substitutable for \(x\) in \(\psi '[z/y]\) because it is substitutable in \(\psi '\) and \(\psi '[z/y]\) has the same quantifiers as \(\psi '\) in the same places.

From \(\vdash \psi \to \psi '\), Theorem 2.5.7 and (A3) give \(\vdash \forall y\, \psi \to \forall y\, \psi '\), and similarly \(\vdash \forall y\, \psi ' \to \forall y\, \psi \). By Lemma 2.3.9, \(\forall y\, \psi ' \to \psi '[z/y]\) and \(\forall z\, \psi '[z/y] \to \psi '\) are instances of (A2). The variable \(z\) is not free in \(\forall y\, \psi '\), and \(y\) is not free in \(\forall z\, \psi '[z/y]\); so by Theorems 2.5.7 and 2.5.8, \(\vdash \forall y\, \psi ' \to \forall z\, \psi '[z/y]\) and \(\vdash \forall z\, \psi '[z/y] \to \forall y\, \psi '\). Combining these implications with Lemma 2.5.5 gives the claim. Finally \(c(\varphi ') = c(\psi ') + 1 = c(\varphi )\).

005R Example 2.5.15

Let us check that \(\vdash \forall x \forall y\, \varphi \to \forall y \forall x\, \varphi \). By (A2) twice (a variable is substitutable for itself), \(\{ \forall x \forall y\, \varphi \} \vdash \varphi \). Neither \(x\) nor \(y\) is free in \(\forall x \forall y\, \varphi \), so the generalization theorem gives \(\{ \forall x \forall y\, \varphi \} \vdash \forall y \forall x\, \varphi \), and the deduction theorem gives the claim. In practice, one rarely writes deductions: by Corollary 2.6.2 below it suffices to check that the implication is valid.
