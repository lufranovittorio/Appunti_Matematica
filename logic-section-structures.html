2.4 Structures and satisfaction0050

Complete. This chapter is written; its proofs await independent checking.

0051 Definition 2.4.1

A structure \(\mathcal{A}\) for a language \(\mathcal{L}\) consists of a nonempty set \(A\), its universe, together with an element \(c^{\mathcal{A}} \in A\) for every constant symbol \(c\), a map \(f^{\mathcal{A}} \colon A^n \to A\) for every \(n\)-ary function symbol \(f\), and a subset \(R^{\mathcal{A}} \subseteq A^n\) for every \(n\)-ary relation symbol \(R\). An assignment in \(\mathcal{A}\) is a map \(s\) from the set of variables to \(A\). For an assignment \(s\), a variable \(x\) and \(a \in A\), we write \(s[x \mapsto a]\) for the assignment that agrees with \(s\) except that it sends \(x\) to \(a\).

0052 Definition 2.4.2

Let \(\mathcal{A}\) be a structure and \(s\) an assignment. The value \(t^{\mathcal{A}}[s] \in A\) of a term is defined by \(x^{\mathcal{A}}[s] = s(x)\), \(c^{\mathcal{A}}[s] = c^{\mathcal{A}}\) and \(f(t_1, \ldots , t_n)^{\mathcal{A}}[s] = f^{\mathcal{A}}(t_1^{\mathcal{A}}[s], \ldots , t_n^{\mathcal{A}}[s])\). The relation \(\mathcal{A} \models \varphi [s]\), read “\(\mathcal{A}\) satisfies \(\varphi \) under \(s\)”, is defined by recursion on \(\varphi \):

  1. \(\mathcal{A} \models (t_1 = t_2)[s]\) if and only if \(t_1^{\mathcal{A}}[s] = t_2^{\mathcal{A}}[s]\);

  2. \(\mathcal{A} \models R(t_1, \ldots , t_n)[s]\) if and only if \((t_1^{\mathcal{A}}[s], \ldots , t_n^{\mathcal{A}}[s]) \in R^{\mathcal{A}}\);

  3. \(\mathcal{A} \models \neg \varphi [s]\) if and only if \(\mathcal{A} \not\models \varphi [s]\);

  4. \(\mathcal{A} \models (\varphi \to \psi )[s]\) if and only if \(\mathcal{A} \not\models \varphi [s]\) or \(\mathcal{A} \models \psi [s]\);

  5. \(\mathcal{A} \models \forall x\, \varphi [s]\) if and only if \(\mathcal{A} \models \varphi [s[x \mapsto a]]\) for every \(a \in A\).

0053 Remark 2.4.3

With the abbreviations of Notation 2.3.4, \(\mathcal{A} \models \exists x\, \varphi [s]\) if and only if \(\mathcal{A} \models \varphi [s[x \mapsto a]]\) for some \(a \in A\), and the connectives \(\wedge \), \(\vee \), \(\leftrightarrow \) have their usual meaning, by the same computation as in Lemma 2.2.8.

0054 Lemma 2.4.4 Coincidence lemma

Let \(s\) and \(s'\) be assignments in \(\mathcal{A}\). If they agree on \(\mathrm{Var}(t)\), then \(t^{\mathcal{A}}[s] = t^{\mathcal{A}}[s']\). If they agree on \(\mathrm{FV}(\varphi )\), then \(\mathcal{A} \models \varphi [s]\) if and only if \(\mathcal{A} \models \varphi [s']\).

Proof â–¼

The statement for terms follows by induction on terms, and implies the statement for atomic formulas; the cases \(\neg \) and \(\to \) follow by induction. If \(\varphi = \forall x\, \psi \) and \(s, s'\) agree on \(\mathrm{FV}(\varphi ) = \mathrm{FV}(\psi ) \setminus \{ x\} \), then for each \(a \in A\) the assignments \(s[x \mapsto a]\) and \(s'[x \mapsto a]\) agree on \(\mathrm{FV}(\psi )\), and the claim follows from the induction hypothesis.

0055 Notation 2.4.5

By Lemma 2.4.4, whether \(\mathcal{A} \models \sigma [s]\) holds for a sentence \(\sigma \) does not depend on \(s\); we then write \(\mathcal{A} \models \sigma \) and say that \(\sigma \) is true in \(\mathcal{A}\).

0056 Lemma 2.4.6 Substitution lemma

Let \(t\) be substitutable for \(x\) in \(\varphi \), let \(s\) be an assignment in \(\mathcal{A}\), and put \(a = t^{\mathcal{A}}[s]\). Then \(\mathcal{A} \models \varphi [t/x][s]\) if and only if \(\mathcal{A} \models \varphi [s[x \mapsto a]]\). Also \(u[t/x]^{\mathcal{A}}[s] = u^{\mathcal{A}}[s[x \mapsto a]]\) for every term \(u\).

Proof â–¼

The statement for terms follows by induction on \(u\) and gives the atomic case; the cases \(\neg \) and \(\to \) follow by induction. Let \(\varphi = \forall y\, \psi \).

If \(x \notin \mathrm{FV}(\varphi )\), then \(\varphi [t/x] = \varphi \) (Remark 2.3.8), and \(s\) and \(s[x \mapsto a]\) agree on \(\mathrm{FV}(\varphi )\), so the claim follows from Lemma 2.4.4.

Otherwise \(y \neq x\), \(y\) does not occur in \(t\), and \(t\) is substitutable for \(x\) in \(\psi \). Then \(\varphi [t/x] = \forall y\, \psi [t/x]\). For \(b \in A\), since \(y\) does not occur in \(t\), we have \(t^{\mathcal{A}}[s[y \mapsto b]] = a\), so by induction \(\mathcal{A} \models \psi [t/x][s[y \mapsto b]]\) if and only if \(\mathcal{A} \models \psi [s[y \mapsto b][x \mapsto a]]\). Since \(x \neq y\), the assignment \(s[y \mapsto b][x \mapsto a]\) equals \(s[x \mapsto a][y \mapsto b]\). Quantifying over all \(b \in A\) gives the claim.

0057 Counterexample 2.4.7

The hypothesis that \(t\) is substitutable cannot be dropped. Let \(\varphi \) be \(\exists y\, (x \neq y)\) and \(t = y\). In a structure with at least two elements, \(\varphi \) is true under every assignment, but \(\varphi [y/x] = \exists y\, (y \neq y)\) is false: the variable \(y\) of \(t\) has been “captured” by the quantifier \(\exists y\).

0058 Definition 2.4.8

Let \(\Gamma \) be a set of formulas. A structure \(\mathcal{A}\) with an assignment \(s\) satisfies \(\Gamma \) if \(\mathcal{A} \models \gamma [s]\) for all \(\gamma \in \Gamma \). The set \(\Gamma \) logically implies \(\varphi \), written \(\Gamma \models \varphi \), if every \((\mathcal{A}, s)\) satisfying \(\Gamma \) satisfies \(\varphi \); \(\varphi \) is valid if \(\emptyset \models \varphi \). A theory is a set of sentences. A model of a theory \(T\) is a structure in which all sentences of \(T\) are true. For a structure \(\mathcal{A}\), the theory of \(\mathcal{A}\), written \(\operatorname {Th}(\mathcal{A})\), is the set of sentences true in \(\mathcal{A}\).

0059 Example 2.4.9

Let \(T_{\mathrm{grp}}\) consist of the sentences \(\forall x \forall y \forall z\, ((x \cdot y) \cdot z = x \cdot (y \cdot z))\), \(\forall x\, (x \cdot e = x \wedge e \cdot x = x)\) and \(\forall x\, (x \cdot x^{-1} = e \wedge x^{-1} \cdot x = e)\) in the language of groups. Its models are exactly the groups (with the inverse map and the identity element as interpretations of \({}^{-1}\) and \(e\)). Adding \(\forall x \forall y\, (x \cdot y = y \cdot x)\) gives a theory whose models are the abelian groups.

005A Definition 2.4.10

An isomorphism of \(\mathcal{L}\)-structures \(h \colon \mathcal{A} \to \mathcal{B}\) is a bijection \(h \colon A \to B\) with \(h(c^{\mathcal{A}}) = c^{\mathcal{B}}\), \(h(f^{\mathcal{A}}(a_1, \ldots , a_n)) = f^{\mathcal{B}}(h(a_1), \ldots , h(a_n))\) and \((a_1, \ldots , a_n) \in R^{\mathcal{A}}\) if and only if \((h(a_1), \ldots , h(a_n)) \in R^{\mathcal{B}}\), for all symbols and all \(a_i \in A\).

005B Proposition 2.4.11

Let \(h \colon \mathcal{A} \to \mathcal{B}\) be an isomorphism and \(s\) an assignment in \(\mathcal{A}\). Then \(\mathcal{A} \models \varphi [s]\) if and only if \(\mathcal{B} \models \varphi [h \circ s]\). In particular, isomorphic structures have the same theory.

Proof â–¼

By induction on terms, \(h(t^{\mathcal{A}}[s]) = t^{\mathcal{B}}[h \circ s]\). Since \(h\) is injective and preserves relations in both directions, the atomic case follows; the cases \(\neg \), \(\to \) follow by induction. For \(\forall x\, \psi \), note that \(h \circ (s[x \mapsto a]) = (h \circ s)[x \mapsto h(a)]\) and that \(a \mapsto h(a)\) is a bijection \(A \to B\), so quantifying over \(a \in A\) is the same as quantifying over \(b \in B\).
