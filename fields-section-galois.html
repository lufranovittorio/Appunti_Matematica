9.5 Galois extensions00H9

Complete. This chapter is written; its proofs await independent checking.

00HA Definition 9.5.1

An algebraic extension \(L/K\) is normal if every irreducible polynomial in \(K[x]\) with a root in \(L\) splits into linear factors in \(L[x]\). For a group \(G\) of automorphisms of a field \(L\), the fixed field is \(L^G = \{ x \in L : \sigma (x) = x \text{ for all } \sigma \in G\} \).

00HB Lemma 9.5.2 Artin

Let \(G\) be a finite group of automorphisms of a field \(L\). Then \([L : L^G] \leq |G|\).

Proof â–¼

Let \(K = L^G\), \(G = \{ \sigma _1, \ldots , \sigma _n\} \) with \(\sigma _1 = \mathrm{id}\), and let \(\alpha _1, \ldots , \alpha _m \in L\) with \(m {\gt} n\). The \(m\) vectors \((\sigma _i(\alpha _j))_i \in L^n\) are linearly dependent over \(L\) by Lemma 8.8.1, so the system \(\sum _j \sigma _i(\alpha _j) x_j = 0\), \(i = 1, \ldots , n\), has a nonzero solution \((x_j) \in L^m\). Choose one with the fewest nonzero entries and, scaling, with \(x_{j_0} = 1\) for some \(j_0\). For \(\tau \in G\), applying \(\tau \) gives \(\sum _j \tau \sigma _i(\alpha _j)\tau (x_j) = 0\) for all \(i\), and since \(\tau \sigma _i\) runs over \(G\) as \(i\) does, \((\tau (x_j))_j\) is also a solution. The difference \((x_j - \tau (x_j))_j\) is a solution with fewer nonzero entries (the \(j_0\) entry vanishes), so it is zero. Hence all \(x_j \in K\), and the equation for \(\sigma _1 = \mathrm{id}\) is a nontrivial \(K\)-linear relation \(\sum _j \alpha _j x_j = 0\). So any \(m {\gt} n\) elements are linearly dependent over \(K\).

00HC Theorem 9.5.3

For a finite extension \(L/K\) with \(G = \operatorname {Aut}(L/K)\), the following are equivalent:

  1. \(|G| = [L : K]\);

  2. \(L^G = K\);

  3. \(L\) is a splitting field over \(K\) of a separable polynomial;

  4. \(L/K\) is normal and separable.

Such an extension is called Galois, and \(\mathrm{Gal}(L/K) = G\) its Galois group. Moreover, if \(G\) is any finite group of automorphisms of a field \(L\), then \(L/L^G\) is Galois with group \(G\).

Proof â–¼

For the last statement: \(G \subseteq \operatorname {Aut}(L/L^G)\), so by Lemma 9.5.2 and Corollary 9.3.4, \([L : L^G] \leq |G| \leq |\operatorname {Aut}(L/L^G)| \leq [L : L^G]\).

(1) \(\Rightarrow \) (2): \(K \subseteq L^G\) and by the last statement \([L : L^G] = |G| = [L : K]\), so \(L^G = K\) by the tower law.

(2) \(\Rightarrow \) (4): Let \(\alpha \in L\) and let \(\alpha _1, \ldots , \alpha _r\) be the distinct elements of the orbit \(G\alpha \). The polynomial \(g = \prod _i (x - \alpha _i)\) has coefficients fixed by \(G\), hence in \(K\), and \(g(\alpha ) = 0\), so \(m_\alpha \mid g\). Every \(\alpha _i = \sigma (\alpha )\) is a root of \(m_\alpha \), so \(g \mid m_\alpha \). Thus \(m_\alpha = g\) splits in \(L\) with distinct roots.

(4) \(\Rightarrow \) (3): Write \(L = K(\beta _1, \ldots , \beta _s)\) and let \(f\) be the product of the distinct minimal polynomials of the \(\beta _j\). It is separable (distinct monic irreducible polynomials have no common root), it splits in \(L\) by normality, and its roots generate \(L\).

(3) \(\Rightarrow \) (1): Apply Theorem 9.3.3 with \(M = L\) and \(\tau \) the inclusion \(K \to L\): at every stage the minimal polynomial divides \(f\), which splits into distinct linear factors in \(L\). So there are exactly \([L : K]\) \(K\)-homomorphisms \(L \to L\). Each is an injective \(K\)-linear map of the finite-dimensional \(K\)-vector space \(L\) to itself, hence bijective by Theorem 8.8.5 (its image is a subspace of the same finite dimension). So \(|G| = [L : K]\).

00HD Theorem 9.5.4 Fundamental theorem of Galois theory

Let \(L/K\) be a finite Galois extension with group \(G\). The maps \(H \mapsto L^H\) and \(F \mapsto \mathrm{Gal}(L/F)\) are mutually inverse, inclusion-reversing bijections between subgroups \(H \leq G\) and intermediate fields \(K \subseteq F \subseteq L\). Moreover \([L : L^H] = |H|\) and \([L^H : K] = [G : H]\). An intermediate field \(F\) is Galois over \(K\) if and only if \(\mathrm{Gal}(L/F)\) is normal in \(G\), and then restriction induces an isomorphism \(G/\mathrm{Gal}(L/F) \cong \mathrm{Gal}(F/K)\).

Proof â–¼

If \(L\) is the splitting field of a separable \(f \in K[x]\), it is also the splitting field of \(f\) over \(F\), so \(L/F\) is Galois and \(L^{\mathrm{Gal}(L/F)} = F\) by Theorem 9.5.3. For \(H \leq G\), the last statement of that theorem gives \(\mathrm{Gal}(L/L^H) = H\) and \([L : L^H] = |H|\); then \([L^H : K] = [L : K]/|H| = [G : H]\) by the tower law. The maps clearly reverse inclusions.

For \(\sigma \in G\), \(\mathrm{Gal}(L/\sigma (F)) = \sigma \mathrm{Gal}(L/F)\sigma ^{-1}\). If \(F/K\) is Galois, it is normal, so \(\sigma \) maps each \(\alpha \in F\) to a root of \(m_\alpha \), which lies in \(F\); thus \(\sigma (F) = F\) and \(\mathrm{Gal}(L/F)\) is normal. Conversely, if \(N = \mathrm{Gal}(L/F)\) is normal, then \(\sigma (F) = L^{\sigma N \sigma ^{-1}} = F\) for all \(\sigma \), and restriction is a homomorphism \(G \to \operatorname {Aut}(F/K)\) with kernel \(N\). Its image has \([G : N] = [F : K]\) elements and lies in a group with at most \([F : K]\) elements (Corollary 9.3.4), so \(|\operatorname {Aut}(F/K)| = [F : K]\), \(F/K\) is Galois and the restriction map is surjective.

00HE Example 9.5.5

The field \(L = \mathbb {Q}(\sqrt2, \sqrt3)\) is the splitting field of \((x^2 - 2)(x^2 - 3)\), of degree \(4\) over \(\mathbb {Q}\): if \(\sqrt3 = a + b\sqrt2\) with \(a, b \in \mathbb {Q}\), squaring gives \(2ab = 0\), and neither \(a = 0\) nor \(b = 0\) is possible by the argument of Proposition 4.6.4. Its Galois group consists of the four automorphisms \(\sqrt2 \mapsto \pm \sqrt2\), \(\sqrt3 \mapsto \pm \sqrt3\), so it is isomorphic to \(\mathbb {Z}/2\mathbb {Z}\times \mathbb {Z}/2\mathbb {Z}\). It has three subgroups of order \(2\), corresponding to the three quadratic subfields \(\mathbb {Q}(\sqrt2)\), \(\mathbb {Q}(\sqrt3)\) and \(\mathbb {Q}(\sqrt6)\).

00HF Counterexample 9.5.6

The extension \(\mathbb {Q}(\sqrt[3]{2})/\mathbb {Q}\) of degree \(3\) is not Galois. A \(\mathbb {Q}\)-automorphism must send \(\sqrt[3]{2}\) to a cube root of \(2\) in \(\mathbb {Q}(\sqrt[3]{2}) \subseteq \mathbb {R}\), and the only real cube root of \(2\) is \(\sqrt[3]{2}\) (Proposition 4.7.4); so the automorphism group is trivial. The polynomial \(x^3 - 2\) has a root in \(\mathbb {Q}(\sqrt[3]{2})\) but does not split there, so the extension is not normal.
