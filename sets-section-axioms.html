3.2 The axioms006J

Complete. This chapter is written; its proofs await independent checking.

We use the abbreviations \(x \subseteq y\) for \(\forall z\, (z \in x \to z \in y)\), \(\forall z \in x\, \varphi \) for \(\forall z\, (z \in x \to \varphi )\) and \(\exists z \in x\, \varphi \) for \(\exists z\, (z \in x \wedge \varphi )\).

006K Definition 3.2.1

The axioms of Zermelo–Fraenkel set theory ZF are the following sentences.

  1. (Extensionality) \(\forall x \forall y\, (\forall z\, (z \in x \leftrightarrow z \in y) \to x = y)\).

  2. (Foundation) \(\forall x\, (\exists y\, (y \in x) \to \exists y \in x\, \neg \exists z\, (z \in x \wedge z \in y))\).

  3. (Separation) For every formula \(\varphi \) in which \(y\) is not free: \(\forall w_1 \cdots \forall w_n \forall x \exists y \forall z\, (z \in y \leftrightarrow (z \in x \wedge \varphi ))\), where \(w_1, \ldots , w_n\) are the other free variables of \(\varphi \).

  4. (Pairing) \(\forall x \forall y \exists z\, (x \in z \wedge y \in z)\).

  5. (Union) \(\forall F \exists A \forall Y \forall x\, ((x \in Y \wedge Y \in F) \to x \in A)\).

  6. (Replacement) For every formula \(\varphi \) in which \(B\) is not free: \(\forall w_1 \cdots \forall w_n \forall A\, \bigl(\forall x \in A\, \exists ! y\, \varphi \to \exists B\, \forall x \in A\, \exists y \in B\, \varphi \bigr)\), where \(\exists ! y\, \varphi \) abbreviates “there is exactly one \(y\) with \(\varphi \)” and \(w_1, \ldots , w_n\) are the other free variables of \(\varphi \).

  7. (Infinity) \(\exists x\, \bigl(\exists e \in x\, \forall z\, (z \notin e) \wedge \forall y \in x\, \exists s \in x\, \forall z\, (z \in s \leftrightarrow (z \in y \vee z = y))\bigr)\).

  8. (Power set) \(\forall x \exists y \forall z\, (z \subseteq x \to z \in y)\).

The theory ZFC consists of ZF together with the axiom of choice, Definition 3.7.1. The axioms of separation and replacement are schemas: they consist of one axiom for each formula \(\varphi \).

006L Remark 3.2.2

Extensionality says that a set is determined by its elements. Separation says that for a set \(x\) and a property \(\varphi \), the elements of \(x\) with the property form a set, written \(\{ z \in x : \varphi (z)\} \). Pairing, union and power set provide sets containing the pair \(\{ x, y\} \), the union of the elements of \(F\), and the subsets of \(x\); by separation and extensionality there are then unique sets with exactly these elements. Replacement says that the image of a set under a class function is contained in a set. Infinity provides a set containing \(\emptyset \) and closed under \(y \mapsto y \cup \{ y\} \). Foundation says that every nonempty set has an \(\in \)-minimal element.

006M Lemma 3.2.3

  1. There is a unique set \(\emptyset \) with no elements.

  2. For all sets \(x, y\) there are unique sets \(\{ x, y\} \), \(\bigcup x\) and \(\mathcal{P}(x)\) with, respectively, the elements \(x\) and \(y\); the elements of elements of \(x\); the subsets of \(x\).

  3. For all sets \(x, y\) there are unique sets \(x \cup y\), \(x \cap y\) and \(x \setminus y\) with the usual elements. If \(F\) is a nonempty set, there is a unique set \(\bigcap F\) whose elements are the sets belonging to every element of \(F\).

Proof â–¼

Uniqueness always follows from extensionality. (1) Some set \(x\) exists, because \(\exists x\, (x = x)\) is valid (structures are nonempty); apply separation with the formula \(z \neq z\). (2) Apply separation to the sets given by pairing, union and power set, with the formulas \(z = x \vee z = y\), \(\exists Y \in x\, (z \in Y)\) and \(z \subseteq x\). (3) Put \(x \cup y = \bigcup \{ x, y\} \), and use separation on \(x\) for \(x \cap y\) and \(x \setminus y\). If \(X \in F\), put \(\bigcap F = \{ z \in X : \forall Y \in F\, (z \in Y)\} \).

006N Proposition 3.2.4 Russell

There is no set of which every set is an element.

Proof â–¼

Suppose \(V\) is such a set and let \(R = \{ x \in V : x \notin x\} \). Then \(R \in V\), so \(R \in R\) if and only if \(R \notin R\), a contradiction.

006O Remark 3.2.5

So the class \(\{ x : x = x\} \) of all sets is not a set; such classes are called proper classes. Proposition 3.2.4 holds even without foundation. With foundation it is also immediate from Lemma 3.2.6.

006P Lemma 3.2.6

There is no set \(x\) with \(x \in x\), and there are no sets \(x, y\) with \(x \in y\) and \(y \in x\).

Proof â–¼

If \(x \in x\), the set \(\{ x\} \) has no \(\in \)-minimal element: its only element \(x\) satisfies \(x \in x \cap \{ x\} \). If \(x \in y \in x\), the set \(\{ x, y\} \) has no \(\in \)-minimal element, since \(y \in x \cap \{ x,y\} \) and \(x \in y \cap \{ x,y\} \).
