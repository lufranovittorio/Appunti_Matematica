Complete. This chapter is written; its proofs await independent checking.

008P Exercise 3.9.1

Let \(A\), \(B\), \(C\) be sets. Show that \(f \mapsto (a \mapsto (b \mapsto f(a, b)))\) is a bijection \(C^{A \times B} \to (C^B)^A\), and that \((A \times B) \times C \approx A \times (B \times C)\).

008Q Exercise 3.9.2

Show that the axiom of choice is equivalent (in ZF) to the statement that every surjection \(f \colon A \to B\) has a section, that is, a map \(s \colon B \to A\) with \(f \circ s = \mathrm{id}_B\).

Solution â–¼

Given AC and a surjection \(f\), choose \(s(b)\) from the nonempty set \(f^{-1}[\{ b\} ]\). Conversely, given a set \(F\) of nonempty sets, let \(A = \{ (X, x) : X \in F, x \in X\} \) and let \(f \colon A \to F\) be the first projection, which is surjective. If \(s\) is a section, then \(X \mapsto \) (second coordinate of \(s(X)\)) is a choice function.

008R Exercise 3.9.3

Using the axiom of choice, show that every infinite set has a countably infinite subset.

008S Exercise 3.9.4

Show that an ordinal \(\alpha \) is a limit ordinal if and only if \(\alpha \neq 0\) and \(\alpha = \bigcup \alpha \).

008T Exercise 3.9.5

Show that \(V_\omega \) is a Grothendieck universe which does not contain \(\omega \), and that every element of \(V_\omega \) is a finite set. Show that \(\emptyset \) is also a universe. (So the condition \(\omega \in \mathcal{U}\) in Remark 3.8.5 is not automatic.)

008U Exercise 3.9.6

Show that \(\omega ^\omega \) (the set of maps \(\omega \to \omega \)) and \(\mathcal{P}(\omega )\) are equinumerous.

008V Exercise 3.9.7

Show that for every set \(A\) of sets there is a set not equinumerous with a subset of any element of \(A\). Deduce that the class of all cardinals is not a set.
