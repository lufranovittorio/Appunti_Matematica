006B Exercise 2.9.1

Show that every function \(\{ 0,1\} ^n \to \{ 0,1\} \) with \(n \geq 1\) is computed by a formula built from variables using only \(\neg \) and \(\wedge \) (as primitive connectives with their usual truth tables). Show that a formula built from variables using only \(\wedge \), \(\vee \) and \(\to \) is satisfied by the truth assignment that is constantly \(1\), and deduce that these three connectives do not suffice to express negation.

Solution â–¼

By Lemma 2.2.8, \(\varphi \vee \psi \) has the same truth table as \(\neg (\neg \varphi \wedge \neg \psi )\) and \(\varphi \to \psi \) the same as \(\neg (\varphi \wedge \neg \psi )\); so the formula of Proposition 2.2.10 can be rewritten using \(\neg \) and \(\wedge \). For the second part, argue by induction: if \(v\) is constantly \(1\), then \(\bar v\) is \(1\) on variables, and \(1 \wedge 1\), \(1 \vee 1\) and \(1 \to 1\) all have value \(1\). Negation of a variable has value \(0\) under \(v\), so it is not expressible.

006C Exercise 2.9.2

Show that \(\exists x \forall y\, \varphi \to \forall y \exists x\, \varphi \) is valid for every formula \(\varphi \), and give a formula \(\varphi \) in the language of orders and a structure in which \(\forall y \exists x\, \varphi \to \exists x \forall y\, \varphi \) is false.

Solution â–¼

Let \(\mathcal{A}\) be a structure and \(s\) an assignment with \(\mathcal{A} \models \exists x \forall y\, \varphi [s]\) (if \(x\) and \(y\) are the same variable the statement is trivial, so assume they are different). Then there is \(a \in A\) with \(\mathcal{A} \models \forall y\, \varphi [s[x \mapsto a]]\), that is, \(\mathcal{A} \models \varphi [s[x \mapsto a][y \mapsto b]]\) for every \(b \in A\). Given \(b\), the element \(a\) witnesses \(\mathcal{A} \models \exists x\, \varphi [s[y \mapsto b]]\), since \(s[y \mapsto b][x \mapsto a] = s[x \mapsto a][y \mapsto b]\). So \(\mathcal{A} \models \forall y \exists x\, \varphi [s]\). In words: one \(x\) that works for all \(y\) certainly gives, for each \(y\), an \(x\) that works. The converse fails: in \((\mathbb {N}, {\lt})\) with \(\varphi = (y {\lt} x)\), the sentence \(\forall y \exists x\, (y {\lt} x)\) is true (every number has a larger one) and \(\exists x \forall y\, (y {\lt} x)\) is false (no number is larger than all numbers, itself included).

006D Exercise 2.9.3

A well-order is a total order in which every nonempty subset has a least element. Show that there is no theory \(T\) in the language of orders whose models are exactly the well-ordered sets. (Hint: add constants \(c_0, c_1, \ldots \) and the sentences \(c_{n+1} {\lt} c_n\).)

Solution â–¼

Suppose \(T\) were such a theory, and let \(T^{\prime } = T \cup \{ c_{n+1} {\lt} c_n : n \in \mathbb {N}\} \) in the language with the new constants. A finite subset of \(T^{\prime }\) mentions only \(c_0, \ldots , c_k\) for some \(k\). The finite order \(\{ 0, 1, \ldots , k\} \) is well-ordered, hence a model of \(T\), and interpreting \(c_n\) as \(k - n\) for \(n \leq k\) and as \(0\) for \(n {\gt} k\) satisfies the sentences \(c_{n+1} {\lt} c_n\) with \(n {\lt} k\). So every finite subset of \(T^{\prime }\) is satisfiable, and by the compactness theorem (Theorem 2.7.1) \(T^{\prime }\) has a model. Its underlying order is a model of \(T\), hence well-ordered, but the set \(\{ c_n\} \) of interpretations of the constants has no least element, since \(c_{n+1} {\lt} c_n\) for all \(n\). This is a contradiction. The property “every nonempty subset has a least element” quantifies over subsets, which first-order logic cannot do.

006E Exercise 2.9.4

A group is a torsion group if every element has finite order. Show that there is no theory in the language of groups whose models are exactly the torsion groups. Show, on the other hand, that for every \(n \geq 1\) there is a single sentence whose models among groups are exactly the groups satisfying \(g^n = e\) for all \(g\).

Solution â–¼

Suppose \(T\) were such a theory. Add a constant \(c\) and let \(T^{\prime } = T \cup \{ c^n \neq e : n \geq 1\} \), where \(c^n\) is the term \(c \cdot c \cdots c\) with \(n\) factors. A finite subset of \(T^{\prime }\) involves only \(n {\lt} N\) for some \(N\), and is satisfied by the cyclic group \(\mathbb {Z}/N\mathbb {Z}\) (written multiplicatively) with \(c\) a generator: it is a torsion group, hence a model of \(T\), and \(c^n \neq e\) for \(0 {\lt} n {\lt} N\). By compactness \(T^{\prime }\) has a model, a torsion group in which \(c\) has infinite order, a contradiction. For the second statement take the sentence \(\forall x\, (x^n = e)\) together with the group axioms. So “all elements have order dividing \(n\)” is first-order for each fixed \(n\), but “all elements have finite order” would be the infinite disjunction over all \(n\), which is not a formula.

006F Exercise 2.9.5

Let \(T_0\) be the theory of fields in the language of rings, and for a prime \(p\) let \(\chi _p\) be the sentence \(\underline{p} \neq 0\), where \(\underline{p}\) is \(1 + 1 + \cdots + 1\) with \(p\) summands. The models of \(T_0 \cup \{ \chi _p : p \text{ prime}\} \) are the fields of characteristic zero. Show that there is no single sentence \(\sigma \) such that the models of \(T_0 \cup \{ \sigma \} \) are exactly the fields of characteristic zero. Deduce that a sentence true in all fields of characteristic zero is true in all fields of sufficiently large prime characteristic.

Solution â–¼

We first prove the second statement. Let \(\tau \) be true in all fields of characteristic zero, so that \(T_0 \cup \{ \chi _p : p \text{ prime}\} \cup \{ \neg \tau \} \) has no model. By the compactness theorem some finite subset has no model; enlarging it, \(T_0 \cup \{ \chi _p : p \leq N\} \cup \{ \neg \tau \} \) has no model for some \(N\). A field of prime characteristic \(q {\gt} N\) satisfies \(T_0\) and \(\chi _p\) for \(p \leq N\), so it does not satisfy \(\neg \tau \): \(\tau \) is true in it.

Now suppose the models of \(T_0 \cup \{ \sigma \} \) are the fields of characteristic zero. Then \(\sigma \) is true in all fields of characteristic zero, hence, by what we just proved, in \(\mathbb {F}_q = \mathbb {Z}/q\mathbb {Z}\) for a large prime \(q\); so \(\mathbb {F}_q\) is a model of \(T_0 \cup \{ \sigma \} \) of characteristic \(q\), a contradiction. For example, the sentence “\(1 + 1 \neq 0\)” is true in characteristic zero and fails only in characteristic \(2\), in accordance with the statement.

006G Exercise 2.9.6

Let \(T\) be a theory and \(\sigma \) a sentence with \(T \models \sigma \). Show, without using deductions, that some finite subset \(T_0 \subseteq T\) satisfies \(T_0 \models \sigma \) (for \(\mathcal{L}\) countable).

Solution â–¼

Otherwise, for every finite \(T_0 \subseteq T\) the set \(T_0 \cup \{ \neg \sigma \} \) has a model. Then every finite subset of \(T \cup \{ \neg \sigma \} \) is satisfiable, so by Theorem 2.7.1 the whole set has a model, which is a model of \(T\) in which \(\sigma \) is false, contradicting \(T \models \sigma \).
