29.8 Exercises0156

Complete. This chapter is written; its proofs await independent checking.

0157 Exercise 29.8.1

Show that \(\mathbb {D}\) and \(\mathbb {C}\) are not biholomorphic, although they are homeomorphic.

Solution â–¼

A biholomorphism \(\mathbb {C}\to \mathbb {D}\) would be a bounded entire function, hence constant (Corollary 29.4.7). They are homeomorphic by \(z \mapsto z/(1 + |z|)\) (Counterexample 18.7.9).

0158 Exercise 29.8.2

Show that every biholomorphic map \(\mathbb {C}\to \mathbb {C}\) is \(z \mapsto az + b\) with \(a \neq 0\).

Solution â–¼

Let \(f\) be such a map and consider \(g(z) = f(1/z)\) on \(\mathbb {C}^\times \). If \(0\) were an essential singularity of \(g\), then by Casorati–Weierstrass the image \(f(\{ |z| {\gt} 1\} )\) would be dense, while \(f(\mathbb {D})\) is open and disjoint from it, a contradiction. So \(g\) has a pole or removable singularity at \(0\), which means \(|f(z)| \leq C|z|^m\) for large \(|z|\); by Liouville’s theorem \(f\) is a polynomial, and it is injective only if \(\deg f = 1\).

Use Rouché’s theorem to show that \(z^5 + 3z + 1\) has exactly one root in \(\mathbb {D}\) and all five roots in \(D(0, 2)\).

Compute \(\int _0^{2\pi }\frac{dt}{a + \cos t}\) for \(a {\gt} 1\) by writing \(z = e^{it}\) and using the residue theorem.

0347 Exercise 29.8.6

Find the Möbius transformation sending \(1\), \(i\), \(-1\) to \(0\), \(1\), \(\infty \), and show that it maps \(\mathbb {D}\) onto \(\mathbb {H}\). Find a Möbius transformation mapping the half-plane \(\{ \operatorname {Re}z {\gt} 0\} \) onto \(\mathbb {D}\) with \(1 \mapsto 0\).

Solution â–¼

By Theorem 29.7.11, \(S(z) = \frac{(z - 1)(i + 1)}{(z + 1)(i - 1)}\), and \(\frac{1 + i}{i - 1} = -i\), so \(S(z) = i\frac{1 - z}{1 + z}\). It maps the unit circle, through \(1\), \(i\), \(-1\), onto \(\mathbb {R}\cup \{ \infty \} \), so it maps \(\mathbb {D}\) onto one of the two half-planes; as \(S(0) = i\), it is \(\mathbb {H}\). For the second part, \(z \mapsto iz\) maps \(\{ \operatorname {Re}z {\gt} 0\} \) onto \(\mathbb {H}\), and then the Cayley transform gives \(\frac{iz - i}{iz + i} = \frac{z - 1}{z + 1}\), which sends \(1\) to \(0\).

0348 Exercise 29.8.7

Let \(\lambda = (z, z_1, z_2, z_3)\). Show that permuting the four points changes the cross-ratio into one of \(\lambda \), \(1 - \lambda \), \(1/\lambda \), \(1/(1 - \lambda )\), \((\lambda - 1)/\lambda \), \(\lambda /(\lambda - 1)\), and that each value is obtained from four of the \(24\) permutations.

Solution â–¼

We may assume the four points are finite (move them by a Möbius map, Corollary 29.7.13(1)). The permutations \((z\, z_1)(z_2\, z_3)\), \((z\, z_2)(z_1\, z_3)\) and \((z\, z_3)(z_1\, z_2)\) leave the cross-ratio unchanged: for instance \((z_1, z, z_3, z_2) = \frac{(z_1 - z)(z_3 - z_2)}{(z_1 - z_2)(z_3 - z)}\), and numerator and denominator are those of \((z, z_1, z_2, z_3)\), each with two signs changed; the other two are similar. With the identity they form a normal subgroup \(V\) of order \(4\), and every permutation is the product of an element of \(V\) and a permutation fixing the first entry, so it suffices to permute \(z_1, z_2, z_3\). Moving them to \(0, 1, \infty \), so that \(z = \lambda \), and using the formulas of Theorem 29.7.11 for points at \(\infty \):

\[ (\lambda , 0, 1, \infty ) = \lambda , \quad (\lambda , 1, 0, \infty ) = 1 - \lambda , \quad (\lambda , 0, \infty , 1) = \frac{\lambda }{\lambda - 1}, \quad (\lambda , 1, \infty , 0) = \frac{\lambda - 1}{\lambda }, \quad (\lambda , \infty , 0, 1) = \frac{1}{1 - \lambda }, \quad (\lambda , \infty , 1, 0) = \frac1\lambda . \]

Each value is obtained from a coset of \(V\), that is, from four permutations.

0349 Exercise 29.8.8

Classify the following Möbius transformations as parabolic, elliptic, hyperbolic or loxodromic, and find their fixed points: \(z \mapsto \frac{z}{z + 1}\), \(z \mapsto \frac{2z + 1}{z + 1}\), \(z \mapsto 2iz\), \(z \mapsto -\frac{1}{z}\), \(z \mapsto \frac{z - i}{z + i}\). Show that a Möbius transformation of finite order \(n \geq 2\) is elliptic and conjugate to \(z \mapsto e^{2\pi ij/n}z\) for some \(j\) prime to \(n\).

Solution â–¼

Compute \(t^2 = (\operatorname {tr}A)^2/\det A\), which is the invariant for the normalised matrix. \(\frac{z}{z + 1}\): \(t^2 = 4\), parabolic, fixed point \(0\). \(\frac{2z + 1}{z + 1}\): \(t^2 = 9\), hyperbolic, fixed points \(z^2 - z - 1 = 0\), \(z = (1 \pm \sqrt5)/2\). \(2iz\): \(t^2 = (1 + 2i)^2/(2i) = (-3 + 4i)/(2i) = 2 + \frac32i\), loxodromic, fixed points \(0\), \(\infty \). \(-1/z\): \(t^2 = 0\), elliptic, fixed points \(\pm i\). \(\frac{z - i}{z + i}\): \(t^2 = 4/(2i) = -2i\), loxodromic, fixed points the roots of \(z^2 + (i - 1)z + i = 0\). If \(M^n = \mathrm{id}\) with \(M \neq \mathrm{id}\), then \(M\) is not parabolic (the iterates of \(z + 1\) are \(z + n\)), so it is conjugate to \(z \mapsto kz\) with \(k^n = 1\), \(k \neq 1\), which is elliptic; replacing \(n\) by the exact order, \(k\) is a primitive \(n\)-th root of unity.

034A Exercise 29.8.9

Let \(J(z) = \frac12(z + z^{-1})\). Show that \(J\) is a rational function of degree \(2\) with critical points \(\pm 1\), that it maps the circle \(|z| = r \neq 1\) onto an ellipse with foci \(\pm 1\) and the unit circle onto \([-1, 1]\), and that it maps \(\mathbb {D} \setminus \{ 0\} \) biholomorphically onto \(\mathbb {C}\setminus [-1, 1]\). (This Joukowski map was used to model the flow around aircraft wings.)

Solution â–¼

\(J = (z^2 + 1)/(2z)\) has degree \(2\), and \(J^{\prime }(z) = \frac12(1 - z^{-2})\) vanishes at \(\pm 1\). For \(z = re^{i\theta }\), \(J(z) = \frac12(r + r^{-1})\cos \theta + \frac i2(r - r^{-1})\sin \theta \), an ellipse with semi-axes \(a = \frac12(r + r^{-1})\) and \(b = \frac12|r - r^{-1}|\), so \(a^2 - b^2 = 1\) and the foci are \(\pm 1\); for \(r = 1\) it is \(\cos \theta \in [-1, 1]\). Next \(J(z) = J(w)\) if and only if \((z - w)(1 - \frac{1}{zw}) = 0\), that is, \(w = z\) or \(w = 1/z\); so \(J\) is injective on \(\mathbb {D} \setminus \{ 0\} \). Every \(w \in \mathbb {C}\) is taken twice counted with multiplicity (Proposition 29.7.6), by \(z\) and \(1/z\); if \(w \notin [-1, 1]\), neither lies on the unit circle, so exactly one lies in \(\mathbb {D} \setminus \{ 0\} \). The inverse is holomorphic, since \(J^{\prime } \neq 0\) on \(\mathbb {D} \setminus \{ 0\} \).

034B Exercise 29.8.10

Let \(a \neq b\) in \(\mathbb {C}\) and \(k {\gt} 0\). Show that \(\{ z : |z - a| = k|z - b|\} \) is a circle for \(k \neq 1\) and the perpendicular bisector of \(a\) and \(b\) for \(k = 1\) (a circle of Apollonius). Deduce that the images of the circles \(|w| = k\) under the Möbius map \(w \mapsto \frac{a - bw}{1 - w}\), inverse of \(z \mapsto \frac{z - a}{z - b}\), are these circles.

Solution â–¼

Squaring, \(|z|^2 - 2\operatorname {Re}(z\bar a) + |a|^2 = k^2(|z|^2 - 2\operatorname {Re}(z\bar b) + |b|^2)\), that is, \((1 - k^2)|z|^2 - 2\operatorname {Re}\bigl(z(\bar a - k^2\bar b)\bigr) + |a|^2 - k^2|b|^2 = 0\), which is of the form 29.1; it is a line, the bisector, if \(k = 1\). For \(k \neq 1\) the set is nonempty and not a point (it meets the line through \(a\) and \(b\) in two points, dividing the segment internally and externally in the ratio \(k\)), so it is a circle. The second statement is the first, since \(|w| = k\) means \(|z - a| = k|z - b|\) for \(z\) the preimage of \(w\).

034C Exercise 29.8.11

Compute \(\int _{|z| = 3}\frac{z^{5}\, dz}{(z - 1)(z^5 + 2)}\) using the residue at \(\infty \).

Solution â–¼

All poles lie in \(|z| {\lt} 3\). For large \(|z|\), \(\frac{z^5}{(z - 1)(z^5 + 2)} = \frac{1}{z - 1}\cdot \frac{1}{1 + 2z^{-5}} = z^{-1}(1 + z^{-1} + \cdots )(1 - 2z^{-5} + \cdots )\), whose coefficient of \(z^{-1}\) is \(1\). So \(\operatorname {Res}_\infty = -1\) and, by Proposition 29.7.7, the integral is \(2\pi i\sum _{a \in \mathbb {C}}\operatorname {Res}_a = -2\pi i\operatorname {Res}_\infty = 2\pi i\).

035Z Exercise 29.8.12

Let \(f = u + iv\) be holomorphic on a connected open set \(U\). Show that \(f\) is constant if any of the following holds: (1) \(u\) is constant; (2) \(f\) takes only real values; (3) \(|f|\) is constant; (4) \(\bar f\) is also holomorphic.

Solution â–¼

If \(f^{\prime } = 0\) on \(U\), then \(f\) is constant on every disc in \(U\) (Lemma 29.2.8, integrating along segments), so the set where \(f\) takes a given value is open, as is its complement, and \(f\) is constant since \(U\) is connected. (1) If \(u\) is constant, \(\partial _xu = \partial _yu = 0\), so \(\partial _xv = -\partial _yu = 0\) by the Cauchy–Riemann equations, and \(f^{\prime } = \partial _xu + i\partial _xv = 0\). (2) Then \(v = 0\), and \(-if = v - iu\) has constant real part; apply (1). (3) If \(|f|^2\) is constant, then \(0 = \Delta |f|^2 = 4|f^{\prime }|^2\) by Example 29.4.5(3). (4) Then \(f + \bar f = 2u\) is holomorphic and real valued; by (2) \(u\) is constant, and (1) applies.

036I Exercise 29.8.13

(Cauchy–Riemann equations in polar coordinates.) Let \(f = u + iv\) be real differentiable on an open set \(U \subseteq \mathbb {C}^\times \), and write \(z = re^{i\theta }\). Show that \(f\) is holomorphic if and only if

\[ \partial _ru = \frac1r\partial _\theta v, \qquad \partial _rv = -\frac1r\partial _\theta u, \]

and that then \(f^{\prime }(z) = e^{-i\theta }\partial _rf\). Deduce that the principal logarithm \(\operatorname {Log}z = \log r + i\theta \), \(-\pi {\lt} \theta {\lt} \pi \), is holomorphic on \(\mathbb {C}\setminus (-\infty , 0]\) with derivative \(1/z\).

Solution â–¼

By the chain rule, \(\partial _r = \cos \theta \, \partial _x + \sin \theta \, \partial _y\) and \(\partial _\theta = -r\sin \theta \, \partial _x + r\cos \theta \, \partial _y\) on functions of \((x, y) = (r\cos \theta , r\sin \theta )\). Hence

\[ \partial _\theta f - ir\, \partial _rf = r\bigl((-\sin \theta - i\cos \theta )\partial _xf + (\cos \theta - i\sin \theta )\partial _yf\bigr) = -ire^{-i\theta }\bigl(\partial _xf + i\, \partial _yf\bigr). \]

The Cauchy–Riemann equations say \(\partial _xf + i\, \partial _yf = 0\) (its real and imaginary parts are \(\partial _xu - \partial _yv\) and \(\partial _xv + \partial _yu\)). So \(f\) is holomorphic if and only if \(\partial _\theta f = ir\, \partial _rf\), whose real and imaginary parts are the stated equations. Then \(\partial _rf = \cos \theta \, f^{\prime } + \sin \theta \, if^{\prime } = e^{i\theta }f^{\prime }\). For \(\operatorname {Log}\), which is real differentiable because \((r, \theta )\) are smooth functions of \((x, y)\) on the slit plane, \(u = \log r\) and \(v = \theta \) give \(\partial _ru = \frac1r = \frac1r\partial _\theta v\) and \(\partial _rv = 0 = -\frac1r\partial _\theta u\), and \(\operatorname {Log}^{\prime }(z) = e^{-i\theta }/r = 1/z\).

036J Exercise 29.8.14

For integers \(m, n \geq 0\) compute \(\int _\gamma z^n\bar z^m\, dz\) over the unit circle \(\gamma (t) = e^{2\pi it}\). Deduce that a polynomial \(p(z, \bar z) = \sum c_{nm}z^n\bar z^m\) satisfies \(\int _\gamma p\, dz = 2\pi i\sum _nc_{n,n+1}\); in particular this integral can be nonzero only if \(p\) really involves \(\bar z\).

Solution â–¼

On the circle \(\bar z = 1/z\), so the integrand is \(z^{n-m}\), and by Lemma 29.2.8 the integral is \(2\pi i\) if \(n - m = -1\) and \(0\) otherwise. The formula for \(p\) follows by linearity, and if \(p\) does not involve \(\bar z\) then \(c_{n,n+1} = 0\) for all \(n\).
