02Z0 Exercise 10.9.1

Show that there are infinitely many primes \(p \equiv 3 \pmod4\). (Consider \(N = 4p_1 \cdots p_k - 1\).)

Solution â–¼

Let \(p_1, \ldots , p_k\) be primes \(\equiv 3 \pmod4\) and \(N = 4p_1 \cdots p_k - 1 \equiv 3 \pmod4\). \(N\) is odd, so its prime factors are \(\equiv 1\) or \(3 \pmod4\); if all were \(\equiv 1\), their product \(N\) would be \(\equiv 1 \pmod4\). So some prime \(q \equiv 3 \pmod4\) divides \(N\), and \(q \neq p_i\), since \(p_i \mid N + 1\).

02Z1 Exercise 10.9.2

Show that an integer \(n \geq 2\) is prime if and only if \((n - 1)! \equiv -1 \pmod n\).

Solution â–¼

If \(n\) is prime this is Wilson’s theorem (Corollary 7.3.5). If \(n = ab\) with \(1 {\lt} a {\lt} n\), then \(a\) divides \((n - 1)!\), so if \(n \mid (n - 1)! + 1\), then \(a\) divides \((n - 1)! + 1\) and hence \(1\), which is absurd.

02Z2 Exercise 10.9.3

Let \(p \equiv 1 \pmod4\) be prime. Show that \(x = \bigl(\frac{p-1}{2}\bigr)!\) satisfies \(x^2 \equiv -1 \pmod p\).

Solution â–¼

Let \(h = \frac{p-1}{2}\). Pairing \(k\) with \(p - k \equiv -k\), Wilson’s theorem gives \(-1 \equiv (p - 1)! = \prod _{k=1}^{h}k(p - k) \equiv \prod _{k=1}^{h}(-k^2) = (-1)^h(h!)^2 \pmod p\). As \(h\) is even, \((h!)^2 \equiv -1\).

02Z3 Exercise 10.9.4

Show that \(\varphi (n)\) is even for \(n \geq 3\), and that \(\varphi (n) \geq \sqrt{n/2}\) for all \(n \geq 1\).

Solution â–¼

For \(n \geq 3\) the map \(a \mapsto n - a\) is an involution of the set of \(1 \leq a {\lt} n\) prime to \(n\) without fixed points: \(a = n - a\) would mean \(n = 2a\), and then \(\gcd (a, n) = a = 1\) forces \(n = 2\). So the set has an even number of elements. For the inequality, by multiplicativity it suffices to note that \(\varphi (p^k) = p^{k-1}(p - 1) \geq \sqrt{p^k}\) for odd \(p\) (as \(p - 1 \geq \sqrt{p}\) for \(p \geq 3\) and \(p^{k-1} \geq p^{(k-1)/2}\)), and \(\varphi (2^k) = 2^{k-1} \geq \sqrt{2^k/2}\); multiplying over the prime powers in \(n\), with the factor \(1/\sqrt{2}\) appearing at most once, gives \(\varphi (n) \geq \sqrt{n/2}\).

02Z4 Exercise 10.9.5

Give a second proof of Theorem 10.3.3: for \(d \mid p - 1\) let \(\psi (d)\) be the number of elements of order \(d\) in \(U_p\). Show that \(\psi (d) \leq \varphi (d)\), using that \(x^d - 1\) has at most \(d\) roots in \(\mathbb {F}_p\), and deduce from Proposition 10.2.8(4) that \(\psi (d) = \varphi (d)\), in particular \(\psi (p - 1) \geq 1\).

Solution â–¼

If there is an element \(x\) of order \(d\), its powers \(1, x, \ldots , x^{d-1}\) are \(d\) distinct roots of \(x^d - 1\), hence all of its roots (Corollary 8.6.6); so every element of order \(d\) is a power of \(x\), and those of order \(d\) are the \(x^k\) with \(\gcd (k, d) = 1\) (Lemma 10.3.2(2)), \(\varphi (d)\) in number. So \(\psi (d) \in \{ 0, \varphi (d)\} \). Every element has an order dividing \(p - 1\), so \(\sum _{d \mid p-1}\psi (d) = p - 1 = \sum _{d \mid p-1}\varphi (d)\). As \(\psi (d) \leq \varphi (d)\) termwise, equality holds termwise.

02Z5 Exercise 10.9.6

Check that \(14\) is a primitive root modulo \(29\) and that \(14^{28} \equiv 1 \pmod{29^2}\). Which of \(14\) and \(43\) is a primitive root modulo \(29^2\)?

Solution â–¼

\(29 - 1 = 28 = 2^2 \cdot 7\), so by Example 10.3.4(3) it suffices to check \(14^{14} \not\equiv 1\) and \(14^4 \not\equiv 1 \pmod{29}\). Modulo \(29\): \(14^2 = 196 \equiv 22 \equiv -7\), \(14^4 \equiv 49 \equiv 20\), \(14^7 = 14^4 \cdot 14^2 \cdot 14 \equiv 20 \cdot (-7) \cdot 14 = -1960 \equiv -1960 + 68 \cdot 29 = 12\), and \(14^{14} \equiv 144 \equiv -1\). So \(14\) is a primitive root. Modulo \(841 = 29^2\): \(14^2 = 196\), \(14^4 = 38416 = 45 \cdot 841 + 571\), so \(14^4 \equiv 571\); \(14^7 = 14^4 \cdot 14^2 \cdot 14 \equiv 571 \cdot 196 \cdot 14\), and \(571 \cdot 196 = 111916 = 133 \cdot 841 + 63\), so \(14^7 \equiv 63 \cdot 14 = 882 \equiv 41\); \(14^{14} \equiv 41^2 = 1681 = 2 \cdot 841 - 1 \equiv -1\), and \(14^{28} \equiv 1 \pmod{841}\). So \(14\) is not a primitive root modulo \(841\), and by Theorem 10.3.7 \(43 = 14 + 29\) is.

02Z6 Exercise 10.9.7

Show that for \(k \geq 3\) the congruence \(x^2 \equiv 1 \pmod{2^k}\) has exactly four solutions modulo \(2^k\), namely \(\pm 1\) and \(\pm 1 + 2^{k-1}\), while for an odd prime \(p\) the congruence \(x^2 \equiv 1 \pmod{p^k}\) has only the solutions \(\pm 1\). How many solutions does \(x^2 \equiv 1 \pmod n\) have in general?

Solution â–¼

The solutions are the elements of order dividing \(2\) in \(U_{2^k}\). By Theorem 10.3.9 this group is \(\mathbb {Z}/2\mathbb {Z}\times \mathbb {Z}/2^{k-2}\mathbb {Z}\), which has four such elements; and \(\pm 1\), \(\pm 1 + 2^{k-1}\) are four distinct solutions, as \((\pm 1 + 2^{k-1})^2 = 1 \pm 2^k + 2^{2k-2} \equiv 1\) for \(k \geq 2\), so they are all. For odd \(p\), \(U_{p^k}\) is cyclic (Theorem 10.3.7) of even order, and has exactly two elements of order dividing \(2\) (Lemma 10.3.2(3)), namely \(\pm 1\). By the Chinese remainder theorem, if \(n = 2^ap_1^{k_1} \cdots p_r^{k_r}\) with distinct odd primes \(p_i\), the number of solutions is \(2^r\) times \(1\), \(2\) or \(4\) according as \(a \leq 1\), \(a = 2\) or \(a \geq 3\).

02Z7 Exercise 10.9.8

Show that for a prime \(p {\gt} 3\), \(\bigl(\frac{-3}{p}\bigr) = 1\) if and only if \(p \equiv 1 \pmod3\). Deduce that there are infinitely many primes \(p \equiv 1 \pmod3\) (consider \(N = (2p_1 \cdots p_k)^2 + 3\)).

Solution â–¼

By Euler’s criterion, Corollary 10.4.3 and reciprocity, \((\frac{-3}{p}) = (\frac{-1}{p})(\frac{3}{p}) = (-1)^{\frac{p-1}{2}} \cdot (-1)^{\frac{p-1}{2}}(\frac{p}{3}) = (\frac{p}{3})\), which is \(1\) exactly when \(p \equiv 1 \pmod3\). Given primes \(p_1, \ldots , p_k \equiv 1 \pmod3\), let \(N = (2p_1 \cdots p_k)^2 + 3\), which is odd and not divisible by \(3\) (it is \(\equiv 1 \pmod3\), as \(p_i \neq 3\) and \(4 \equiv 1\)). A prime \(q \mid N\) satisfies \(q {\gt} 3\) and \(x^2 \equiv -3 \pmod q\) with \(x = 2p_1 \cdots p_k\), so \(q \equiv 1 \pmod3\); and \(q \neq p_i\), as otherwise \(q \mid 3\).

02Z8 Exercise 10.9.9

For an odd \(n = p_1 \cdots p_r\) (primes not necessarily distinct) and any integer \(a\), the Jacobi symbol is \((\frac{a}{n}) = \prod _i(\frac{a}{p_i})\). Show that it is multiplicative in \(a\) and in \(n\), that \((\frac{-1}{n}) = (-1)^{(n-1)/2}\), \((\frac{2}{n}) = (-1)^{(n^2-1)/8}\), and \((\frac{m}{n})(\frac{n}{m}) = (-1)^{\frac{m-1}{2}\cdot \frac{n-1}{2}}\) for coprime odd positive \(m\), \(n\). Use it to compute \((\frac{1001}{9907})\) without factoring \(1001\), given that \(9907\) is prime. Show by an example that \((\frac{a}{n}) = 1\) does not imply that \(a\) is a square modulo \(n\).

Solution â–¼

Multiplicativity in \(n\) is the definition, and in \(a\) follows from Proposition 10.4.2(3). The functions \(u \mapsto (-1)^{(u-1)/2}\) and \(u \mapsto (-1)^{(u^2-1)/8}\) are multiplicative on odd integers: for odd \(u, v\), \(\frac{uv - 1}{2} - \frac{u - 1}{2} - \frac{v - 1}{2} = \frac{(u - 1)(v - 1)}{2} \equiv 0 \pmod2\), and \(\frac{u^2v^2 - 1}{8} - \frac{u^2 - 1}{8} - \frac{v^2 - 1}{8} = \frac{(u^2 - 1)(v^2 - 1)}{8} \equiv 0 \pmod2\), as \(8 \mid u^2 - 1\) (Example 10.2.2(2)). So the two supplementary laws pass from primes to products. Likewise \((m, n) \mapsto (-1)^{\frac{m-1}{2}\frac{n-1}{2}}\) is multiplicative in each variable, so reciprocity for the Jacobi symbol follows from the prime case by writing both \(m\) and \(n\) as products of primes. Now \(1001 \equiv 1 \pmod4\), so \((\frac{1001}{9907}) = (\frac{9907}{1001}) = (\frac{898}{1001}) = (\frac{2}{1001})(\frac{449}{1001})\). As \(1001 \equiv 1 \pmod8\), \((\frac{2}{1001}) = 1\), and \(449 \equiv 1 \pmod4\) gives \((\frac{449}{1001}) = (\frac{1001}{449}) = (\frac{103}{449}) = (\frac{449}{103}) = (\frac{37}{103}) = (\frac{103}{37}) = (\frac{29}{37}) = (\frac{37}{29}) = (\frac{8}{29}) = (\frac{2}{29})^3 = -1\), as \(29 \equiv 5 \pmod8\). So \((\frac{1001}{9907}) = -1\), and \(1001\) is not a square modulo \(9907\). Finally \((\frac{2}{15}) = (\frac{2}{3})(\frac{2}{5}) = (-1)(-1) = 1\), but \(2\) is not a square modulo \(15\), since it is not a square modulo \(3\).

02Z9 Exercise 10.9.10

Show that if \(2^k - 1\) is prime, then \(k\) is prime. Show that every prime divisor \(q\) of \(2^p - 1\), for \(p\) an odd prime, satisfies \(q \equiv 1 \pmod{2p}\), and use this to show that \(2^{11} - 1\) is composite and \(2^{13} - 1 = 8191\) is prime.

Solution â–¼

If \(k = ab\) with \(1 {\lt} a {\lt} k\), then \(2^a - 1\) divides \(2^{ab} - 1 = (2^a - 1)(2^{a(b-1)} + \cdots + 2^a + 1)\), and \(1 {\lt} 2^a - 1 {\lt} 2^k - 1\). If \(q \mid 2^p - 1\), then \(2^p \equiv 1 \pmod q\), so \(\operatorname {ord}_q(2)\) divides the prime \(p\) and is not \(1\); so it is \(p\), and \(p \mid q - 1\) by Lemma 10.3.2. As \(q\) is odd, \(q \equiv 1 \pmod{2p}\). For \(p = 11\) the candidates are \(23, 67, 89, \ldots \), and \(2047 = 23 \cdot 89\). For \(p = 13\) the candidates are the primes \(q \equiv 1 \pmod{26}\) with \(q \leq \sqrt{8191} {\lt} 91\), namely \(53\) and \(79\); neither divides \(8191\) (\(8191 = 154 \cdot 53 + 29 = 103 \cdot 79 + 54\)), so \(8191\) is prime.

02ZA Exercise 10.9.11

Let \(n = pq\) with \(p \neq q\) prime. Show that \(p\) and \(q\) can be computed from \(n\) and \(\varphi (n)\), as the roots of a quadratic equation. Find \(p\) and \(q\) for \(n = 2021\) and \(\varphi (n) = 1932\).

Solution â–¼

\(\varphi (n) = (p - 1)(q - 1) = n - (p + q) + 1\) gives \(p + q = n + 1 - \varphi (n)\), and \(pq = n\); so \(p\) and \(q\) are the roots of \(X^2 - (n + 1 - \varphi (n))X + n\). For \(n = 2021\): \(p + q = 90\) and \(pq = 2021\), so \(X^2 - 90X + 2021 = (X - 43)(X - 47)\), and \(2021 = 43 \cdot 47\).

02ZB Exercise 10.9.12

Show that \(\sum _{d \mid n}\mu (d)\tau (n/d) = 1\) and \(\sum _{d \mid n}\mu (d)\sigma (n/d) = n\) for all \(n\), and that \(\sum _{d \mid n}|\mu (d)| = 2^r\) if \(n\) has \(r\) distinct prime factors.

Solution â–¼

\(\mu * \tau = \mu * \mathbf{1} * \mathbf{1} = \varepsilon * \mathbf{1} = \mathbf{1}\) and \(\mu * \sigma = \mu * \mathbf{1} * \mathrm{N} = \mathrm{N}\), by Propositions 10.6.2 and 10.6.3. The function \(|\mu | * \mathbf{1}\) is multiplicative and takes the value \(1 + 1 = 2\) at every prime power \(p^k\), \(k \geq 1\); so its value at \(n\) is \(2^r\).

031H Exercise 10.9.13

Factor \(11 + 7i\) into Gaussian primes, and list all representations of \(65\) as a sum of two squares, checking the count against Theorem 10.7.3.

Solution â–¼

\(N(11 + 7i) = 170 = 2 \cdot 5 \cdot 17\). Dividing by \(1 + i\): \((11 + 7i)(1 - i)/2 = 9 - 2i\), of norm \(85\). Of the primes \(2 \pm i\) of norm \(5\), \(2 - i\) divides: \((9 - 2i)(2 + i)/5 = 4 + i\), of norm \(17\). So \(11 + 7i = (1 + i)(2 - i)(4 + i)\). For \(65 = 5 \cdot 13\), \(r_2(65) = 4(d_1 - d_3) = 4 \cdot 4 = 16\), the divisors \(1, 5, 13, 65\) all being \(\equiv 1 \pmod4\); the representations are \((\pm 1, \pm 8)\), \((\pm 8, \pm 1)\), \((\pm 4, \pm 7)\), \((\pm 7, \pm 4)\), coming from \(65 = 1 + 64 = 16 + 49\).

031I Exercise 10.9.14

Show that \(\mathbb {Z}[\sqrt{-2}]\) is a Euclidean domain for \(N(a + b\sqrt{-2}) = a^2 + 2b^2\), and deduce again that an odd prime \(p\) is of the form \(x^2 + 2y^2\) if and only if \(p \equiv 1, 3 \pmod8\). Show that \(\mathbb {Z}[\sqrt{-3}]\) is not a UFD.

Solution â–¼

For \(a/b = u + v\sqrt{-2}\) choose integers \(m, n\) with \(|u - m|, |v - n| \leq \frac12\); then \(N(a/b - (m + n\sqrt{-2})) \leq \frac14 + \frac24 {\lt} 1\). If \((\frac{-2}{p}) = 1\), which by Corollary 10.4.3 and Proposition 10.4.7 means \(p \equiv 1, 3 \pmod8\), then \(p \mid x^2 + 2 = (x + \sqrt{-2})(x - \sqrt{-2})\) without dividing either factor, so \(p\) is not prime in the UFD \(\mathbb {Z}[\sqrt{-2}]\) and \(p = N(\pi ) = a^2 + 2b^2\) as in Theorem 10.5.1. Conversely, if \(p = x^2 + 2y^2\) then \(p \nmid y\) and \((xy^{-1})^2 \equiv -2 \pmod p\). In \(\mathbb {Z}[\sqrt{-3}]\), \(4 = 2 \cdot 2 = (1 + \sqrt{-3})(1 - \sqrt{-3})\); all these factors have norm \(4\), no element has norm \(2\) (\(a^2 + 3b^2 \neq 2\)), so they are irreducible, and \(2\) is not associate to \(1 \pm \sqrt{-3}\) since the only units are \(\pm 1\). (In the larger ring \(\mathbb {Z}[\omega ] \ni \frac{1 + \sqrt{-3}}{2}\) the factorisations agree: \(1 + \sqrt{-3} = 2(1 + \omega )\), and \(1 + \omega \) is a unit.)

031J Exercise 10.9.15

Show that an odd prime \(p \neq 5\) of the form \(x^2 + 5y^2\) is \(\equiv 1, 9 \pmod{20}\), and one of the form \(2x^2 + 2xy + 3y^2\) is \(\equiv 3, 7 \pmod{20}\). Using Lemma 10.8.5, Example 10.8.4(3) and quadratic reciprocity, conclude that \(p = x^2 + 5y^2\) if and only if \(p \equiv 1, 9 \pmod{20}\).

Solution â–¼

If \(p = x^2 + 5y^2\), then \(p \equiv x^2 \equiv \pm 1 \pmod5\), and since \(p\) is odd exactly one of \(x\), \(y\) is odd, so \(p \equiv x^2 + y^2 \equiv 1 \pmod4\); hence \(p \equiv 1, 9 \pmod{20}\). If \(p = 2x^2 + 2xy + 3y^2\), then \(2p = (2x + y)^2 + 5y^2 \equiv (2x + y)^2 \pmod5\), so \(2p \equiv \pm 1\) and \(p \equiv \pm 2 \pmod5\); and \(y\) is odd (else \(p\) is even), so one of \(x\), \(x + y\) is even and \(p = 2x(x + y) + 3y^2 \equiv 3 \pmod4\); hence \(p \equiv 3, 7 \pmod{20}\). Now if \(p \equiv 1, 9 \pmod{20}\), then \((\frac{-5}{p}) = (\frac{-1}{p})(\frac{p}{5}) = 1 \cdot 1\), so \(-20\) is a square modulo \(4p\) (as in the proof of Corollary 10.8.6), and \(p\) is represented by one of the two reduced forms of discriminant \(-20\); by the congruences it is not the second.

031K Exercise 10.9.16

Find all reduced forms of discriminants \(-15\), \(-24\) and \(-56\), and check that \(h(-15) = 2\), \(h(-24) = 2\) and \(h(-56) = 4\).

Solution â–¼

\(D = -15\): \(a \leq 2\), \(b\) odd; \(b = \pm 1\), \(ac = 4\): \((1, 1, 4)\) and \((2, 1, 2)\) (for \(a = c = 2\) only \(b \geq 0\) is allowed). \(D = -24\): \(a \leq 2\), \(b\) even; \(b = 0\), \(ac = 6\): \((1, 0, 6)\) and \((2, 0, 3)\); \(b = \pm 2\) would need \(a = 2\) and \(c = 28/8\). \(D = -56\): \(a \leq 4\), \(b\) even; \(b = 0\), \(ac = 14\): \((1, 0, 14)\), \((2, 0, 7)\); \(b = \pm 2\), \(ac = 15\), \(a \geq 2\): \((3, \pm 2, 5)\); \(b = \pm 4\), \(ac = 18\), \(a = 4\): no. So the reduced forms are \((1, 0, 14)\), \((2, 0, 7)\), \((3, 2, 5)\), \((3, -2, 5)\).

031L Exercise 10.9.17

Verify condition (1) of Theorem 10.8.7 for \(p = 11\) and \(p = 17\), so that \(n^2 + n + 11\) and \(n^2 + n + 17\) are prime for \(0 \leq n \leq 9\) and \(0 \leq n \leq 15\). Show that \(n^2 + n + 13\) is not always prime for \(0 \leq n \leq 11\) and find the corresponding non-principal reduced form of discriminant \(-51\).

Solution â–¼

\(p = 11\), \(D = -43\): \(a \leq \sqrt{43/3} {\lt} 4\), \(b \in \{ \pm 1, \pm 3\} \), \(ac = 11\) or \(13\), both prime, so \(a = 1\) and the form is \((1, 1, 11)\). \(p = 17\), \(D = -67\): \(a {\lt} 5\), \(b \in \{ \pm 1, \pm 3\} \), \(ac = 17\) or \(19\), prime, so only \((1, 1, 17)\). For \(p = 13\): \(1 + 1 + 13 = 15 = 3 \cdot 5\); correspondingly \(D = -51\) has the reduced form \((3, 3, 5)\) (with \(b = 3\), \(ac = (9 + 51)/4 = 15\)).

031M Exercise 10.9.18

Let \(f\) be a positive definite form. Show that \(f(x, y) = f(-x, -y)\), so that every number represented by \(f\) is represented an even number of times; and show that \(x^2 + y^2\) represents \(n\) properly if and only if \(n\) is not divisible by \(4\) nor by any prime \(q \equiv 3 \pmod4\).

Solution â–¼

The first statement is clear. By Lemma 10.8.5 and \(h(-4) = 1\), \(n\) is properly represented by \(x^2 + y^2\) if and only if \(-4 \equiv b^2 \pmod{4n}\) for some \(b\), that is, \(b = 2b^{\prime }\) with \(b^{\prime 2} \equiv -1 \pmod n\). This congruence is solvable modulo \(q \equiv 3 \pmod4\) never, modulo \(4\) never, modulo \(2\) always, and modulo powers \(p^k\) of primes \(p \equiv 1 \pmod4\) always: the unit group \(U_{p^k}\) is cyclic of order \(p^{k-1}(p - 1)\) (Theorem 10.3.7), which is divisible by \(4\), so it has an element \(x\) of order \(4\), and \(x^2\) is the unique element of order \(2\), namely \(-1\). By the Chinese remainder theorem (Theorem 10.2.6) it is solvable modulo \(n\) exactly under the stated condition.
