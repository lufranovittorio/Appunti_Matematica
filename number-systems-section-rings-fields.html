4.3 Commutative rings and fields0092

Complete. This chapter is written; its proofs await independent checking.

0093 Definition 4.3.1

A commutative ring is a set \(R\) with elements \(0, 1 \in R\) and maps \(+, \cdot \colon R \times R \to R\), the addition \((a, b) \mapsto a + b\) and the multiplication \((a, b) \mapsto a \cdot b\), usually written \(ab\), such that for all \(a, b, c \in R\): \((a + b) + c = a + (b + c)\); \(a + b = b + a\); \(a + 0 = a\); there is \(a' \in R\) with \(a + a' = 0\); \((ab)c = a(bc)\); \(ab = ba\); \(1 \cdot a = a\); and \(a(b + c) = ab + ac\). A homomorphism of commutative rings is a map \(f\) with \(f(a + b) = f(a) + f(b)\), \(f(ab) = f(a) f(b)\) and \(f(1) = 1\). A commutative ring is an integral domain if \(1 \neq 0\) and \(ab = 0\) implies \(a = 0\) or \(b = 0\); it is a field if \(1 \neq 0\) and every \(a \neq 0\) has an element \(a^{-1}\) with \(a a^{-1} = 1\).

0094 Lemma 4.3.2

In a commutative ring \(R\): the element \(a'\) with \(a + a' = 0\) is unique, and we write it \(-a\); \(0 \cdot a = 0\); \((-a) b = -(ab)\); \((-a)(-b) = ab\). A field is an integral domain, and in a field \(a^{-1}\) is unique.

Proof â–¼

If \(a + a' = 0 = a + a''\), then \(a' = a' + (a + a'') = (a' + a) + a'' = a''\). Next \(0 \cdot a = (0 + 0) a = 0 \cdot a + 0 \cdot a\), and adding \(-(0 \cdot a)\) gives \(0 \cdot a = 0\). Then \(ab + (-a)b = (a + (-a))b = 0\), so \((-a)b = -(ab)\), and \((-a)(-b) = -(a(-b)) = -(-(ab)) = ab\). In a field, if \(ab = 0\) and \(a \neq 0\) then \(b = a^{-1}ab = 0\). Uniqueness of inverses is proved like uniqueness of \(-a\).

0095 Definition 4.3.3

An ordered ring is a commutative ring \(R\) with a total order \(\leq \) such that \(a \leq b\) implies \(a + c \leq b + c\), and \(0 \leq a\), \(0 \leq b\) imply \(0 \leq ab\). An ordered field is an ordered ring that is a field. An element \(a\) is positive if \(a {\gt} 0\). The absolute value is \(|a| = a\) if \(a \geq 0\) and \(|a| = -a\) otherwise.

0096 Lemma 4.3.4

Let \(R\) be an ordered ring with \(1 \neq 0\) and \(a, b, c \in R\).

  1. \(a {\lt} b\) if and only if \(-b {\lt} -a\); and \(a^2 \geq 0\), so \(1 {\gt} 0\).

  2. If \(a \leq b\) and \(c \geq 0\), then \(ac \leq bc\).

  3. \(|ab| = |a||b|\) and \(|a + b| \leq |a| + |b|\).

  4. The elements \(n \cdot 1 = 1 + \cdots + 1\) (\(n\) summands) are positive for \(n \geq 1\); in particular they are pairwise distinct.

  5. If \(R\) is a field and \(0 {\lt} a {\lt} b\), then \(0 {\lt} b^{-1} {\lt} a^{-1}\).

Proof â–¼

(1) Add \(-a - b\) to \(a {\lt} b\). If \(a \geq 0\) then \(a^2 \geq 0\); if \(a {\lt} 0\) then \(-a {\gt} 0\) and \(a^2 = (-a)(-a) \geq 0\). Then \(1 = 1^2 \geq 0\) and \(1 \neq 0\). (2) \(b - a \geq 0\), so \((b - a)c \geq 0\). (3) Both sides of the first equation are \(\pm ab\) with the sign making them non-negative. For the second, \(-|a| \leq a \leq |a|\) and similarly for \(b\), so \(-(|a| + |b|) \leq a + b \leq |a| + |b|\). (4) By induction, \((n + 1) \cdot 1 = n \cdot 1 + 1 {\gt} n \cdot 1\). (5) \(a^{-1} = a (a^{-1})^2 \geq 0\) and \(a^{-1} \neq 0\); similarly \(b^{-1} {\gt} 0\). Multiplying \(a {\lt} b\) by \(a^{-1} b^{-1} {\gt} 0\) gives \(b^{-1} {\lt} a^{-1}\).
