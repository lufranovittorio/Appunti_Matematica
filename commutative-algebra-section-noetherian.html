13.5 Noetherian and Artinian rings00M7

Complete. This chapter is written; its proofs await independent checking.

00M8 Definition 13.5.1

A module is Noetherian if every increasing chain of submodules is eventually constant, and Artinian if every decreasing chain is. A ring is Noetherian (Artinian) if it is so as a module over itself.

00M9 Proposition 13.5.2

  1. \(M\) is Noetherian if and only if every submodule is finitely generated, if and only if every nonempty set of submodules has a maximal element.

  2. If \(0 \to M' \to M \to M'' \to 0\) is exact, then \(M\) is Noetherian (Artinian) if and only if \(M'\) and \(M''\) are.

  3. Over a Noetherian ring, finitely generated modules are Noetherian; quotients and localisations of Noetherian rings are Noetherian.

Proof â–¼

(1) If \(N\) is not finitely generated, choose \(x_1, x_2, \ldots \in N\) with \(x_{n+1} \notin (x_1, \ldots , x_n)\), a strictly increasing chain (using dependent choice). If every submodule is finitely generated, the union of a chain is generated by finitely many elements, which lie in one member. A nonempty set without maximal element contains a strictly increasing chain, and conversely a strictly increasing chain has no maximal element. (2) A chain in \(M\) gives chains in \(M'\) and \(M''\); if both stabilise, so does the original, because \(N_1 \subseteq N_2\) with \(N_1 \cap M' = N_2 \cap M'\) and equal images in \(M''\) implies \(N_1 = N_2\). The converse is clear. (3) \(R^n\) is Noetherian by (2) and induction, and finitely generated modules are its quotients. Ideals of \(S^{-1}R\) are of the form \(S^{-1}I\) (by the argument of Proposition 13.3.2(3)), so they are finitely generated.

00MA Theorem 13.5.3 Hilbert’s basis theorem

If \(R\) is Noetherian, so is \(R[x]\). Consequently every finitely generated \(R\)-algebra is Noetherian; in particular \(k[x_1, \ldots , x_n]\) and \(\mathbb {Z}[x_1, \ldots , x_n]\) are Noetherian.

Proof â–¼

Let \(I \subseteq R[x]\) be an ideal and \(L_d \subseteq R\) the set of leading coefficients of elements of \(I\) of degree \(d\), together with \(0\). These are ideals with \(L_d \subseteq L_{d+1}\) (multiply by \(x\)), so \(L_d = L_{d_0}\) for \(d \geq d_0\). For each \(d \leq d_0\) choose finitely many \(f_{d,j} \in I\) of degree \(d\) whose leading coefficients generate \(L_d\). Let \(I'\) be the ideal they generate. If \(f \in I\) has degree \(d\), some combination \(g = \sum _j c_jx^{d - \min (d, d_0)}f_{\min (d,d_0), j}\) has the same degree and leading coefficient, so \(f - g \in I\) has smaller degree; by induction on the degree \(f \in I'\). So \(I = I'\). The last statement follows from quotients (Proposition 13.5.2).

00MB Counterexample 13.5.4

The polynomial ring \(k[x_1, x_2, \ldots ]\) in infinitely many variables is not Noetherian: \((x_1) \subsetneq (x_1, x_2) \subsetneq \cdots \). It is a subring of its fraction field, which is Noetherian; so subrings of Noetherian rings need not be Noetherian.

00MC Lemma 13.5.5

Let \(R\) be a ring and \(\mathfrak {m}_1, \ldots , \mathfrak {m}_n\) maximal ideals (not necessarily distinct) with \(\mathfrak {m}_1 \cdots \mathfrak {m}_n = 0\). Then \(R\) is Noetherian if and only if it is Artinian.

Proof â–¼

Consider the chain \(R \supseteq \mathfrak {m}_1 \supseteq \mathfrak {m}_1\mathfrak {m}_2 \supseteq \cdots \supseteq \mathfrak {m}_1 \cdots \mathfrak {m}_n = 0\). Each quotient is a vector space over the field \(R/\mathfrak {m}_i\), and for a vector space the ascending and the descending chain conditions are both equivalent to finite dimension. By Proposition 13.5.2(2) applied along the chain, \(R\) satisfies ACC iff all quotients are finite-dimensional iff \(R\) satisfies DCC.

00MD Theorem 13.5.6

An Artinian ring \(R\) is Noetherian, every prime ideal of \(R\) is maximal, \(R\) has finitely many maximal ideals, its nilradical is nilpotent, and \(R\) is a finite product of local Artinian rings. (For the converse see Corollary 13.8.5.)

Proof â–¼

Let \(R\) be Artinian. If \(\mathfrak {p}\) is prime, \(R/\mathfrak {p}\) is an Artinian domain; for \(x \neq 0\) the chain \((x) \supseteq (x^2) \supseteq \cdots \) stabilises, \(x^n = x^{n+1}y\), so \(xy = 1\); hence \(\mathfrak {p}\) is maximal. Among finite intersections of maximal ideals choose a minimal one, \(\mathfrak {m}_1 \cap \cdots \cap \mathfrak {m}_n\); every maximal \(\mathfrak {m}\) contains it, hence contains \(\mathfrak {m}_1 \cdots \mathfrak {m}_n\) and so some \(\mathfrak {m}_i\), and \(\mathfrak {m} = \mathfrak {m}_i\). The nilradical \(N = \mathfrak {m}_1 \cap \cdots \cap \mathfrak {m}_n\) satisfies \(N^k = N^{k+1} = \cdots =: I\) for some \(k\). If \(I \neq 0\), choose an ideal \(J\) minimal with \(IJ \neq 0\); there is \(x \in J\) with \(xI \neq 0\), so \(J = (x)\) by minimality, and \((xI)I = xI \neq 0\) with \(xI \subseteq (x)\) gives \(xI = (x)\), so \(x = xy\) with \(y \in I\), hence \(x = xy^m = 0\) as \(y\) is nilpotent; contradiction. So \(N\) is nilpotent, \((\mathfrak {m}_1 \cdots \mathfrak {m}_n)^k \subseteq N^k = 0\), and \(R\) is Noetherian by Lemma 13.5.5.

Finally, the ideals \(\mathfrak {m}_i^k\) are pairwise comaximal and their product is \(0\), so \(R \cong \prod _i R/\mathfrak {m}_i^k\) by Theorem 8.3.3, and \(R/\mathfrak {m}_i^k\) is local with maximal ideal \(\mathfrak {m}_i/\mathfrak {m}_i^k\).
