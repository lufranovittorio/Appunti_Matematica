7.6 Group actions00CR

Complete. This chapter is written; its proofs await independent checking.

00CS Definition 7.6.1

An action of a group \(G\) on a set \(X\) is a map \(G \times X \to X\), \((g, x) \mapsto gx\), with \(ex = x\) and \(g(hx) = (gh)x\); equivalently a homomorphism \(G \to \mathrm{Sym}(X)\). The orbit of \(x\) is \(Gx = \{ gx : g \in G\} \), its stabiliser is \(G_x = \{ g : gx = x\} \), and \(X^G = \{ x : gx = x \text{ for all } g\} \) is the set of fixed points. The action is transitive if there is only one orbit, and free if all stabilisers are trivial.

00CT Theorem 7.6.2 Orbit–stabiliser

For an action of \(G\) on \(X\) and \(x \in X\), the stabiliser \(G_x\) is a subgroup and \(gG_x \mapsto gx\) is a bijection \(G/G_x \to Gx\). In particular \(|Gx| = [G : G_x]\), and the orbits partition \(X\).

Proof â–¼

\(gG_x = hG_x\) iff \(h^{-1}g \in G_x\) iff \(gx = hx\), so the map is well defined and injective; it is surjective by definition. The relation “\(y \in Gx\)” is an equivalence relation since \(G\) is a group.

00CU Example 7.6.3

  1. \(G\) acts on itself by left multiplication, freely and transitively. This gives an injective homomorphism \(G \to \mathrm{Sym}(G)\) (Cayley’s theorem): every group is isomorphic to a group of permutations.

  2. \(G\) acts on itself by conjugation; the orbits are the conjugacy classes and \(G_x = C_G(x)\).

  3. \(G\) acts on the set of its subgroups by conjugation, with stabiliser \(N_G(H)\); so the number of conjugates of \(H\) is \([G : N_G(H)]\).

  4. If \(H \leq G\), then \(G\) acts transitively on \(G/H\) by \(g(aH) = gaH\).

00CV Corollary 7.6.4 Class equation

Let \(G\) be finite and let \(x_1, \ldots , x_r\) represent the conjugacy classes with more than one element. Then \(|G| = |Z(G)| + \sum _{i=1}^r [G : C_G(x_i)]\).

Proof â–¼

The conjugacy classes partition \(G\); the one-element classes are the elements of \(Z(G)\), and the class of \(x_i\) has \([G : C_G(x_i)]\) elements by Theorem 7.6.2.

00CW Definition 7.6.5

Let \(p\) be a prime. A \(p\)-group is a finite group whose order is a power of \(p\).

00CX Lemma 7.6.6

Let a \(p\)-group \(P\) act on a finite set \(X\). Then \(|X| \equiv |X^P| \pmod p\).

Proof â–¼

Each orbit that is not a fixed point has size \([P : P_x] {\gt} 1\), a divisor of \(|P|\), hence divisible by \(p\).

00CY Proposition 7.6.7

A nontrivial \(p\)-group has nontrivial center. Every group of order \(p^2\) is abelian.

Proof â–¼

Apply Lemma 7.6.6 to the conjugation action: \(|Z(G)| \equiv |G| \equiv 0 \pmod p\) and \(e \in Z(G)\), so \(|Z(G)| \geq p\). If \(|G| = p^2\), then \(|G/Z(G)| \in \{ 1, p\} \), so \(G/Z(G)\) is cyclic (Corollary 7.3.4), and \(G\) is abelian by Lemma 7.4.7.

00CZ Theorem 7.6.8 Cauchy

If a prime \(p\) divides the order of a finite group \(G\), then \(G\) has an element of order \(p\).

Proof â–¼

Let \(X = \{ (g_1, \ldots , g_p) \in G^p : g_1 g_2 \cdots g_p = e\} \). Since \(g_p\) is determined by the others, \(|X| = |G|^{p-1} \equiv 0 \pmod p\). The group \(\mathbb {Z}/p\mathbb {Z}\) acts on \(X\) by cyclic rotation: if \(g_1 \cdots g_p = e\) then \(g_2 \cdots g_p g_1 = g_1^{-1}(g_1 \cdots g_p)g_1 = e\). The fixed points are the tuples \((g, \ldots , g)\) with \(g^p = e\). By Lemma 7.6.6 their number is divisible by \(p\), and \((e, \ldots , e)\) is one of them, so there is a fixed point with \(g \neq e\).
