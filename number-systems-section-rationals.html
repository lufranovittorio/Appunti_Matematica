4.6 The rational numbers009K

Complete. This chapter is written; its proofs await independent checking.

009L Definition 4.6.1

Let \(P = \{ (a, b) \in \mathbb {Z}\times \mathbb {Z}: b {\gt} 0\} \) and \((a, b) \sim (c, d)\) if \(ad = bc\). This is an equivalence relation (for transitivity, \(ad = bc\) and \(cf = de\) give \(adf = bcf = bde\), and we cancel \(d \neq 0\) in the integral domain \(\mathbb {Z}\)). The set of rational numbers is \(\mathbb {Q}= P/{\sim }\), and \(a/b\) denotes the class of \((a, b)\). Define

\[ \frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}, \qquad \frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}, \qquad \frac{a}{b} \leq \frac{c}{d} \iff ad \leq bc. \]
009M Theorem 4.6.2

The operations and the order on \(\mathbb {Q}\) are well defined and make \(\mathbb {Q}\) an ordered field. The map \(\mathbb {Z}\to \mathbb {Q}\), \(a \mapsto a/1\), is an injective ring homomorphism preserving the order, and \(\mathbb {Q}\) is Archimedean: for every \(x \in \mathbb {Q}\) there is \(n \in \mathbb {N}\) with \(x {\lt} n\).

Proof â–¼

Well-definedness: if \(ab' = a'b\), then \((ad + bc)(b'd) = (a'd + b'c)(bd)\) and \((ac)(b'd) = (a'c)(bd)\), and \(ad \leq bc\) is equivalent to \(ab'd \leq bb'c\) (multiply by \(b' {\gt} 0\)), that is to \(a'bd \leq bb'c\), that is to \(a'd \leq b'c\) (cancel \(b {\gt} 0\)). The field axioms are identities in \(\mathbb {Z}\) as in Theorem 4.4.2; the zero is \(0/1\), the unit \(1/1\), \(-(a/b) = (-a)/b\), and for \(a \neq 0\) the inverse of \(a/b\) is \(b/a\) if \(a {\gt} 0\) and \((-b)/(-a)\) if \(a {\lt} 0\). The order is total, and compatible with the operations: \(a/b \geq 0\) means \(a \geq 0\), and a product or sum of such fractions again has non-negative numerator. The map \(a \mapsto a/1\) is clearly an injective order-preserving homomorphism. Finally, for \(x = a/b\) we have \(x \leq |a| {\lt} |a| + 1\) because \(b \geq 1\).

009N Proposition 4.6.3

Let \(K\) be an ordered field. There is a unique ring homomorphism \(\mathbb {Q}\to K\); it is injective and order-preserving. We use it to regard \(\mathbb {Q}\) as a subfield of \(K\).

Proof â–¼

By Lemma 4.3.4(4) the map \(\mathbb {N}\to K\), \(n \mapsto n \cdot 1\), is injective, and it preserves sums and products (by induction). Extend it to \(\mathbb {Z}\) by \(-n \mapsto -(n \cdot 1)\); this is an injective order-preserving ring homomorphism \(j\). Define \(f(a/b) = j(a) j(b)^{-1}\); this is well defined since \(ad = bc\) gives \(j(a)j(d) = j(b)j(c)\), and it is a ring homomorphism by the formulas of Definition 4.6.1. It preserves order: for \(b, d {\gt} 0\), \(a/b \leq c/d\) iff \(ad \leq bc\) iff \(j(a)j(d) \leq j(b)j(c)\) iff \(j(a)j(b)^{-1} \leq j(c)j(d)^{-1}\), by Lemma 4.3.4(5). Hence it is injective. Uniqueness: a ring homomorphism \(g\) satisfies \(g(1) = 1\), hence \(g(n) = n \cdot 1\) and \(g(-n) = -g(n)\), and \(g(b) g(a/b) = g(a)\), so \(g(a/b) = j(a) j(b)^{-1}\).

009O Proposition 4.6.4

There is no \(x \in \mathbb {Q}\) with \(x^2 = 2\).

Proof â–¼

Suppose \((a/b)^2 = 2\) with \(a, b {\gt} 0\), so \(a^2 = 2b^2\). In the factorisations of Theorem 4.5.5, the prime \(2\) occurs an even number of times in \(a^2\) and an odd number of times in \(2b^2\), contradicting uniqueness.

009P Counterexample 4.6.5

The set \(A = \{ x \in \mathbb {Q}: x \leq 0 \text{ or } x^2 {\lt} 2\} \) is nonempty and bounded above (by \(2\)), but has no least upper bound in \(\mathbb {Q}\). Indeed, for \(p \in \mathbb {Q}\) with \(p {\gt} 0\) put \(q = p - \frac{p^2 - 2}{p + 2} = \frac{2p + 2}{p + 2}\); then \(q^2 - 2 = \frac{2(p^2 - 2)}{(p + 2)^2}\). If \(p \in A\) and \(p {\gt} 0\), then \(p^2 {\lt} 2\), so \(q {\gt} p\) and \(q^2 {\lt} 2\): \(A\) has no largest element. If \(p {\gt} 0\) is an upper bound of \(A\), then \(p^2 {\gt} 2\) by Proposition 4.6.4 (and \(p^2 {\lt} 2\) is impossible since then \(p \in A\) is largest), so \(q {\lt} p\) and \(q^2 {\gt} 2\), and \(q\) is a smaller upper bound. Hence no upper bound is least.
