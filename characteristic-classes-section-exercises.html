38.7 Exercises01C2

Complete. This chapter is written; its proofs await independent checking.

01C3 Exercise 38.7.1

Using the Euler sequence, compute \(c(T\mathbb {C}\mathbb {P}^2)\) and \(\int _{\mathbb {C}\mathbb {P}^2}c_2(T\mathbb {C}\mathbb {P}^2)\), and check that the latter is \(\chi (\mathbb {C}\mathbb {P}^2) = 3\).

Solution â–¼

\(c(T\mathbb {C}\mathbb {P}^2) = (1 + h)^3 = 1 + 3h + 3h^2\), so \(c_2 = 3h^2\) and \(\int _{\mathbb {C}\mathbb {P}^2}c_2 = 3\) since \(\int h^2 = 1\). By Theorem 38.5.1, \(c_2(T\mathbb {C}\mathbb {P}^2) = e(T\mathbb {C}\mathbb {P}^2)\) integrates to \(\chi (\mathbb {C}\mathbb {P}^2) = 3\) (Example 20.7.8).

01C4 Exercise 38.7.2

Show that a bundle with a flat connection has vanishing Chern classes in de Rham cohomology, and give an example where the integral Chern classes are nonzero.

Solution â–¼

Chern–Weil forms are computed from the curvature, which is zero. A flat line bundle on a space with torsion in \(H^2(M; \mathbb {Z})\), for instance a nontrivial real line bundle on \(\mathbb {R}\mathbb {P}^2\) complexified, has torsion \(c_1 \neq 0\) mapping to zero in de Rham cohomology.

01C5 Exercise 38.7.3

Show that \(\mathrm{ch}(L) = e^{c_1(L)}\) for a line bundle, and compute \(\mathrm{ch}\) and \(\mathrm{td}\) of \(T\mathbb {C}\mathbb {P}^1\).

01C6 Exercise 38.7.4

Show that \(S^4\) admits no almost complex structure, using that \(c_1\) would lie in \(H^2(S^4) = 0\) and \(c_2 = e(TS^4)\) would have to satisfy \(\int _{S^4}c_2 = \chi (S^4) = 2\) while also \(c_1^2 = p_1 + 2c_2\) with \(p_1(TS^4) = 0\).

02MW Exercise 38.7.5

On \(\mathbb {C}\mathbb {P}^1\) compute the total Chern class of \(\mathcal{O}(a) \oplus \mathcal{O}(b)\), and show that \(\mathcal{O}(1) \oplus \mathcal{O}(-1)\) and \(\mathcal{O} \oplus \mathcal{O}\) have the same Chern classes.

Solution â–¼

By the Whitney formula \(c = (1 + ah)(1 + bh) = 1 + (a + b)h\), as \(h^2 = 0\). For \(a = 1\), \(b = -1\) this is \(1\), the total Chern class of the trivial bundle. (The two bundles are in fact isomorphic as smooth bundles, but not as holomorphic ones: the first has a holomorphic section vanishing at one point and the second does not.)

02MX Exercise 38.7.6

Show that \(c_1(E) = c_1(\det E)\) for every complex vector bundle \(E\), using the connection induced on \(\det E\) (Proposition 37.3.6(5)).

Solution â–¼

If \(\nabla \) has connection form \(\theta \) in a frame \(e\), the induced connection on \(\det E\) has connection form \(\operatorname {tr}\theta \) in the frame \(e_1 \wedge \cdots \wedge e_r\), so its curvature is \(d\operatorname {tr}\theta = \operatorname {tr}(d\theta ) = \operatorname {tr}(d\theta + \theta \wedge \theta ) = \operatorname {tr}F\), using \(\operatorname {tr}(\theta \wedge \theta ) = 0\). Hence \(c_1(\det E, \nabla ^{\det }) = \frac{i}{2\pi }\operatorname {tr}F = c_1(E, \nabla )\).

02MY Exercise 38.7.7

Let \(f \colon \mathbb {C}\mathbb {P}^1 \to \mathbb {C}\mathbb {P}^1\) be \(z \mapsto z^k\) (\(k \geq 1\)) and \(\nabla \) the projection connection on \(\mathcal{O}(-1)\). Show that \(\int _{\mathbb {C}\mathbb {P}^1}c_1(f^*\mathcal{O}(-1), f^*\nabla ) = -k\), by computing the integral of \(f^*c_1(\mathcal{O}(-1), \nabla )\), and compare with Exercise 34.5.6.

Solution â–¼

The curvature of \(f^*\nabla \) is \(f^*F\) (Proposition 37.4.5(1)), so the Chern form is \(f^*\omega \) with \(\omega = c_1(\mathcal{O}(-1), \nabla )\). On \(\mathbb {C}^\times \), \(f\) is a \(k\)-sheeted covering and a local diffeomorphism preserving the orientation (it is holomorphic). Cut \(\mathbb {C}^\times \) into the \(k\) open sectors \(\{ 2\pi j/k {\lt} \arg z {\lt} 2\pi (j + 1)/k\} \); each is mapped diffeomorphically, preserving orientation, onto \(\mathbb {C}\) minus a ray, and the rays and the points \(0\), \(\infty \) have measure zero. By Proposition 35.4.3 each sector contributes \(\int _{\mathbb {C}\mathbb {P}^1}\omega = -1\), so the total is \(-k\), in accordance with \(f^*\mathcal{O}(-1) \cong \mathcal{O}(-k)\).

02MZ Exercise 38.7.8

Verify the formula \(c_2 = \frac{1}{8\pi ^2}(\operatorname {tr}(F \wedge F) - \operatorname {tr}F \wedge \operatorname {tr}F)\) for a direct sum of two line bundles with curvatures \(F_1\), \(F_2\), and check that it equals \(c_1(L_1) \wedge c_1(L_2)\).

Solution â–¼

Here \(F = \mathrm{diag}(F_1, F_2)\), \(\operatorname {tr}(F \wedge F) = F_1 \wedge F_1 + F_2 \wedge F_2\) and \(\operatorname {tr}F \wedge \operatorname {tr}F = (F_1 + F_2) \wedge (F_1 + F_2)\), so the difference is \(-2F_1 \wedge F_2\) (the \(2\)-forms commute) and \(c_2 = -\frac{1}{4\pi ^2}F_1 \wedge F_2 = \frac{i}{2\pi }F_1 \wedge \frac{i}{2\pi }F_2\), as predicted by the Whitney formula.
