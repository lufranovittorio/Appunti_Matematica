2.3 First-order languages004Q

Complete. This chapter is written; its proofs await independent checking.

004R Definition 2.3.1

A first-order language \(\mathcal{L}\) consists of a set of constant symbols, and for each \(n \geq 1\) a set of \(n\)-ary function symbols and a set of \(n\)-ary relation symbols, all these sets being pairwise disjoint. The language is countable if the union of these sets is countable. Every language also has the logical symbols: a countably infinite set of variables \(v_0, v_1, v_2, \ldots \), disjoint from the other symbols, and the symbols \(=\), \(\neg \), \(\to \), \(\forall \).

004S Definition 2.3.2

Let \(\mathcal{L}\) be a language. The set of terms is the smallest set that contains the variables and the constant symbols and contains the tuple \((f, t_1, \ldots , t_n)\) whenever \(f\) is an \(n\)-ary function symbol and \(t_1, \ldots , t_n\) are terms. We write \(f(t_1, \ldots , t_n)\) for this tuple.

The atomic formulas are the tuples \((=, t_1, t_2)\) and \((R, t_1, \ldots , t_n)\), where the \(t_i\) are terms and \(R\) is an \(n\)-ary relation symbol; we write \(t_1 = t_2\) and \(R(t_1, \ldots , t_n)\). The set of formulas is the smallest set that contains the atomic formulas and contains \((\neg , \varphi )\), \((\to , \varphi , \psi )\) and \((\forall , x, \varphi )\) whenever \(\varphi \), \(\psi \) are formulas and \(x\) is a variable. We write \(\neg \varphi \), \((\varphi \to \psi )\) and \(\forall x\, \varphi \) for these tuples.

004T Remark 2.3.3

We assume, as we may, that no symbol is itself a finite tuple of the above shapes. Since two tuples are equal only if they have the same length and the same entries, every term and every formula decomposes uniquely into its immediate constituents. This is the analogue of Theorem 2.2.5, obtained here for free: we have defined formulas as trees rather than strings. As in Remark 2.2.2, we can prove statements by induction on terms and formulas, and define functions on them by recursion. The complexity \(c(\varphi )\) of a formula is the number of occurrences of \(\neg \), \(\to \) and \(\forall \) in it: \(c = 0\) on atomic formulas, \(c(\neg \varphi ) = c(\varphi ) + 1\), \(c(\varphi \to \psi ) = c(\varphi ) + c(\psi ) + 1\) and \(c(\forall x\, \varphi ) = c(\varphi ) + 1\).

In practice we write formulas as usual, for instance \(x \cdot y = y \cdot x\) instead of \((=, (\cdot , x, y), (\cdot , y, x))\), and we use variables named \(x, y, z, \ldots \) for arbitrary distinct variables.

004U Notation 2.3.4

Besides the abbreviations of Notation 2.2.3, we write \(\exists x\, \varphi \) for \(\neg \forall x\, \neg \varphi \) and \(t \neq s\) for \(\neg (t = s)\).

004V Example 2.3.5

  1. The language of groups has a constant symbol \(e\), a unary function symbol \({}^{-1}\) and a binary function symbol \(\cdot \).

  2. The language of rings has constant symbols \(0, 1\) and binary function symbols \(+\), \(\cdot \) and a unary function symbol \(-\).

  3. The language of orders has a single binary relation symbol \({\lt}\).

  4. The language of set theory has a single binary relation symbol \(\in \).

  5. The language of arithmetic \(\mathcal{L}_A\) has a constant symbol \(0\), a unary function symbol \(S\) and binary function symbols \(+\) and \(\cdot \).

All these languages are countable.

004W Definition 2.3.6

The set \(\mathrm{Var}(t)\) of variables of a term \(t\) is defined as usual. The set \(\mathrm{FV}(\varphi )\) of free variables of a formula is defined by recursion: \(\mathrm{FV}(t_1 = t_2) = \mathrm{Var}(t_1) \cup \mathrm{Var}(t_2)\), \(\mathrm{FV}(R(t_1, \ldots , t_n)) = \bigcup _i \mathrm{Var}(t_i)\), \(\mathrm{FV}(\neg \varphi ) = \mathrm{FV}(\varphi )\), \(\mathrm{FV}(\varphi \to \psi ) = \mathrm{FV}(\varphi ) \cup \mathrm{FV}(\psi )\) and \(\mathrm{FV}(\forall x\, \varphi ) = \mathrm{FV}(\varphi ) \setminus \{ x\} \). A sentence is a formula without free variables. A variable occurs in \(\varphi \) if it appears anywhere in the tree \(\varphi \), free or not.

004X Definition 2.3.7

Let \(x\) be a variable and \(t\) a term. For a term \(u\), the term \(u[t/x]\) is obtained by replacing every occurrence of \(x\) in \(u\) by \(t\). For formulas, \(\varphi [t/x]\) is defined by recursion: \((t_1 = t_2)[t/x] = (t_1[t/x] = t_2[t/x])\) and similarly for \(R(t_1, \ldots , t_n)\); \((\neg \varphi )[t/x] = \neg (\varphi [t/x])\); \((\varphi \to \psi )[t/x] = (\varphi [t/x] \to \psi [t/x])\); \((\forall y\, \varphi )[t/x] = \forall y\, \varphi \) if \(y = x\), and \((\forall y\, \varphi )[t/x] = \forall y\, (\varphi [t/x])\) if \(y \neq x\).

The term \(t\) is substitutable for \(x\) in \(\varphi \) if: \(\varphi \) is atomic; or \(\varphi = \neg \psi \) and \(t\) is substitutable for \(x\) in \(\psi \); or \(\varphi = (\psi \to \chi )\) and \(t\) is substitutable for \(x\) in \(\psi \) and in \(\chi \); or \(\varphi = \forall y\, \psi \) and either \(x \notin \mathrm{FV}(\varphi )\), or \(y\) does not occur in \(t\) and \(t\) is substitutable for \(x\) in \(\psi \).

004Y Remark 2.3.8

Two facts follow at once by induction: if \(x \notin \mathrm{FV}(\varphi )\) then \(\varphi [t/x] = \varphi \); and substitution does not change the complexity, \(c(\varphi [t/x]) = c(\varphi )\). A constant symbol, or more generally a term without variables, is substitutable for every variable in every formula.

004Z Lemma 2.3.9

Let \(x\) and \(y\) be variables, and suppose \(y\) does not occur in the formula \(\varphi \). Then \(y\) is substitutable for \(x\) in \(\varphi \), \(x\) is substitutable for \(y\) in \(\varphi [y/x]\), and \(\varphi [y/x][x/y] = \varphi \).

Proof â–¼

For terms \(u\) not containing \(y\), clearly \(u[y/x][x/y] = u\). This gives the claims for atomic formulas, and the cases \(\neg \) and \(\to \) follow by induction. Let \(\varphi = \forall z\, \psi \); then \(z \neq y\) and \(y\) does not occur in \(\psi \). The variable \(z\) does not occur in the term \(y\), so by induction \(y\) is substitutable for \(x\) in \(\varphi \). If \(z = x\), then \(\varphi [y/x] = \varphi \), in which \(y\) is not free, so \(x\) is substitutable for \(y\) in it and \(\varphi [x/y] = \varphi \). If \(z \neq x\), then \(\varphi [y/x] = \forall z\, \psi [y/x]\); since \(z\) does not occur in the term \(x\), the induction hypothesis shows that \(x\) is substitutable for \(y\) in \(\varphi [y/x]\), and \(\varphi [y/x][x/y] = \forall z\, \psi [y/x][x/y] = \forall z\, \psi \).
