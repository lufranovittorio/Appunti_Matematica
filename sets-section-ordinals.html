3.5 Ordinals007A

Complete. This chapter is written; its proofs await independent checking.

007B Definition 3.5.1

A set \(x\) is transitive if every element of \(x\) is a subset of \(x\). An ordinal is a transitive set \(\alpha \) such that the relation \(\{ (\beta , \gamma ) \in \alpha \times \alpha : \beta \in \gamma \} \) is a strict well-order on \(\alpha \): it is transitive, for all \(\beta , \gamma \in \alpha \) exactly one of \(\beta \in \gamma \), \(\beta = \gamma \), \(\gamma \in \beta \) holds, and every nonempty subset of \(\alpha \) has an \(\in \)-least element. For ordinals we write \(\beta {\lt} \gamma \) for \(\beta \in \gamma \). The class of ordinals is denoted \(\mathrm{Ord}\).

007C Lemma 3.5.2

Every element of an ordinal is an ordinal, and \(\alpha \notin \alpha \) for every ordinal \(\alpha \).

Proof â–¼

Let \(\beta \in \alpha \). Then \(\beta \subseteq \alpha \), so \(\in \) is a strict well-order on \(\beta \). If \(\delta \in \gamma \in \beta \), then \(\gamma \) and \(\delta \) lie in \(\alpha \), and transitivity of the order on \(\alpha \) gives \(\delta \in \beta \); so \(\beta \) is transitive. The last statement is Lemma 3.2.6.

007D Lemma 3.5.3

If \(\alpha \) and \(\beta \) are ordinals with \(\alpha \subsetneq \beta \), then \(\alpha \in \beta \).

Proof â–¼

Let \(\gamma \) be the least element of \(\beta \setminus \alpha \). If \(\delta \in \gamma \), then \(\delta \in \beta \) and \(\delta {\lt} \gamma \), so \(\delta \in \alpha \) by minimality; hence \(\gamma \subseteq \alpha \). If \(\delta \in \alpha \), then \(\delta \in \beta \); \(\delta = \gamma \) is impossible since \(\gamma \notin \alpha \), and \(\gamma \in \delta \) is impossible since it would give \(\gamma \in \alpha \) by transitivity of \(\alpha \); so \(\delta \in \gamma \). Hence \(\alpha = \gamma \in \beta \).

007E Theorem 3.5.4

For all ordinals \(\alpha , \beta \), exactly one of \(\alpha {\lt} \beta \), \(\alpha = \beta \), \(\beta {\lt} \alpha \) holds. Every nonempty set \(X\) of ordinals has a least element, namely \(\bigcap X\), and \(\sup X = \bigcup X\) is an ordinal which is the least ordinal \(\geq \) every element of \(X\).

Proof â–¼

The set \(\gamma = \alpha \cap \beta \) is transitive and a subset of \(\alpha \), hence an ordinal. By Lemma 3.5.3, \(\gamma = \alpha \) or \(\gamma \in \alpha \), and \(\gamma = \beta \) or \(\gamma \in \beta \). If \(\gamma \in \alpha \) and \(\gamma \in \beta \), then \(\gamma \in \gamma \), contradicting Lemma 3.5.2. So \(\alpha \subseteq \beta \) or \(\beta \subseteq \alpha \), and the first claim follows from Lemma 3.5.3; at most one of the three holds by Lemma 3.2.6.

Let \(\alpha \in X\). If no element of \(X\) is smaller than \(\alpha \), then \(\alpha \) is least. Otherwise \(\alpha \cap X\) is a nonempty subset of \(\alpha \) and has a least element, which is least in \(X\). By the first part, the least element is contained in every element of \(X\), so it equals \(\bigcap X\). Finally \(\bigcup X\) is a transitive set of ordinals; by the first part \(\in \) is a strict total order on it, and every nonempty subset has a least element; so it is an ordinal. It contains each \(\alpha \in X\) as a subset, and any ordinal containing all \(\alpha \in X\) as subsets contains \(\bigcup X\).

007F Proposition 3.5.5 Burali-Forti

There is no set containing all ordinals.

Proof â–¼

If \(X\) were such a set, \(\Omega = \{ x \in X : x \text{ is an ordinal}\} \) would be a transitive set (Lemma 3.5.2) well-ordered by \(\in \) (Theorem 3.5.4), hence an ordinal, so \(\Omega \in \Omega \).

007G Definition 3.5.6

For an ordinal \(\alpha \), the set \(\alpha + 1 = S(\alpha )\) is an ordinal, the least ordinal greater than \(\alpha \). An ordinal is a successor ordinal if it is of the form \(\alpha + 1\), and a limit ordinal if it is neither \(0\) nor a successor ordinal.

007H Proposition 3.5.7

Every natural number is an ordinal, \(\omega \) is an ordinal, and \(\omega \) is the least limit ordinal. On \(\omega \) the order \(m {\lt} n\) (that is, \(m \in n\)) is a well-order.

Proof â–¼

\(\emptyset \) is an ordinal, and if \(\alpha \) is an ordinal so is \(S(\alpha )\) (it is transitive, and its elements are the ordinals in \(\alpha \) together with \(\alpha \)). By induction every natural number is an ordinal. By Lemma 3.4.3, \(\omega \) is a transitive set of ordinals, hence an ordinal by Theorem 3.5.4. It is not \(0\), and not a successor, since \(S(n) \in \omega \) for \(n \in \omega \). If \(\lambda \) is a limit ordinal, then \(0 \in \lambda \), and for \(n \in \lambda \) we have \(S(n) \leq \lambda \) and \(S(n) \neq \lambda \), so \(S(n) \in \lambda \); thus \(\lambda \) is inductive and \(\omega \subseteq \lambda \).

007I Theorem 3.5.8 Transfinite induction

Let \(C\) be a class. Suppose that for every ordinal \(\alpha \), if all ordinals \(\beta {\lt} \alpha \) belong to \(C\), then \(\alpha \) belongs to \(C\). Then every ordinal belongs to \(C\).

Proof â–¼

Otherwise let \(\alpha \) be an ordinal not in \(C\). The set \(\{ \beta \in \alpha + 1 : \beta \notin C\} \) is nonempty, and its least element \(\beta \) satisfies the hypothesis, so \(\beta \in C\); contradiction.

007J Theorem 3.5.9 Transfinite recursion

Let \(G\) be a class function, that is, a formula \(\psi (x, y)\) such that for every \(x\) there is exactly one \(y\) with \(\psi (x, y)\), written \(y = G(x)\). There is a unique class function \(F\) defined on all ordinals such that \(F(\alpha ) = G(F|_\alpha )\) for every ordinal \(\alpha \), where \(F|_\alpha = \{ (\beta , F(\beta )) : \beta {\lt} \alpha \} \).

Proof â–¼

As usual for class functions, the theorem is a schema: for each \(\psi \) we write down a formula defining \(F\) and prove its properties. Call a function \(f\) an \(\alpha \)-attempt if its domain is the ordinal \(\alpha \) and \(f(\beta ) = G(f|_\beta )\) for all \(\beta {\lt} \alpha \). By transfinite induction on \(\beta \), two attempts agree on the intersection of their domains.

We show by transfinite induction that an \(\alpha \)-attempt exists for every \(\alpha \). Suppose that for each \(\beta {\lt} \alpha \) there is a \(\beta \)-attempt \(f_\beta \), which is unique. By replacement, \(\{ f_\beta : \beta {\lt} \alpha \} \) is a set. If \(\alpha = \beta + 1\), then \(f_\beta \cup \{ (\beta , G(f_\beta ))\} \) is an \(\alpha \)-attempt. If \(\alpha \) is \(0\) or a limit ordinal, then \(\bigcup _{\beta {\lt} \alpha } f_\beta \) is a function (the \(f_\beta \) agree on common domains) with domain \(\bigcup _{\beta {\lt} \alpha } \beta = \alpha \), and it is an \(\alpha \)-attempt.

Define \(F(\alpha ) = G(f)\), where \(f\) is the \(\alpha \)-attempt; then \(F|_\alpha = f\) and \(F(\alpha ) = G(F|_\alpha )\). Uniqueness of \(F\) follows by transfinite induction.

007K Theorem 3.5.10

Every well-ordered set \((W, {\lt})\) is isomorphic to a unique ordinal, by a unique isomorphism.

Proof â–¼

Uniqueness follows from Lemma 3.3.12: two isomorphic ordinals are equal, since otherwise one is an initial segment of the other. Let \(A\) be the set of \(w \in W\) such that \(W_{{\lt}w}\) is isomorphic to some ordinal, necessarily unique, which we call \(\alpha _w\). By replacement, \(\alpha = \{ \alpha _w : w \in A\} \) is a set. If \(v {\lt} w \in A\), the isomorphism \(W_{{\lt}w} \to \alpha _w\) restricts to an isomorphism from \(W_{{\lt}v}\) to an initial segment of \(\alpha _w\), which is an ordinal; so \(v \in A\) and \(\alpha _v {\lt} \alpha _w\). Hence \(A\) is an initial segment of \(W\) or equal to \(W\), \(\alpha \) is a transitive set of ordinals, hence an ordinal, and \(w \mapsto \alpha _w\) is an isomorphism \(A \to \alpha \). If \(A \neq W\), let \(w\) be the least element of \(W \setminus A\); then \(A = W_{{\lt}w}\), so \(w \in A\), a contradiction.

007L Definition 3.5.11

By transfinite recursion, define sets \(V_\alpha \) for all ordinals by \(V_0 = \emptyset \), \(V_{\alpha + 1} = \mathcal{P}(V_\alpha )\) and \(V_\lambda = \bigcup _{\alpha {\lt} \lambda } V_\alpha \) for limit ordinals \(\lambda \).

007M Lemma 3.5.12

Every \(V_\alpha \) is transitive, and \(V_\beta \subseteq V_\alpha \) for \(\beta \leq \alpha \). A set \(x\) lies in \(V_{\alpha + 1}\) if and only if \(x \subseteq V_\alpha \).

Proof â–¼

The last statement is the definition. We prove the first two statements together by transfinite induction on \(\alpha \). For \(\alpha = 0\) they are clear, and for limit \(\alpha \) they follow from the induction hypothesis. Let \(\alpha = \gamma + 1\). If \(x \in V_\alpha \) and \(y \in x\), then \(y \in V_\gamma \), so \(y \subseteq V_\gamma \) by transitivity of \(V_\gamma \), that is, \(y \in V_\alpha \). Also \(V_\gamma \subseteq V_\alpha \), because each element of \(V_\gamma \) is a subset of \(V_\gamma \); combined with the induction hypothesis this gives \(V_\beta \subseteq V_\alpha \) for all \(\beta \leq \alpha \).

007N Lemma 3.5.13

Every set \(x\) is a subset of a transitive set.

Proof â–¼

Apply Theorem 3.5.9 to the class function \(G\) with \(G(f) = \bigcup f(n)\) if \(f\) is a function whose domain is \(S(n)\) for some \(n \in \omega \), and \(G(f) = x\) otherwise. The resulting \(F\) satisfies \(F(0) = x\) and \(F(n + 1) = \bigcup F(n)\) for \(n \in \omega \). By replacement, \(\{ F(n) : n \in \omega \} \) is a set; let \(T\) be its union. Then \(x \subseteq T\), and if \(z \in y \in T\), say \(y \in F(n)\), then \(z \in F(n+1) \subseteq T\).

007O Theorem 3.5.14

Every set belongs to \(V_\alpha \) for some ordinal \(\alpha \).

Proof â–¼

Suppose \(x\) belongs to no \(V_\alpha \). Let \(T\) be a transitive set containing \(\{ x\} \) as a subset (Lemma 3.5.13) and let \(Y = \{ y \in T : y \notin V_\alpha \text{ for all } \alpha \} \); then \(x \in Y\). By foundation there is \(y \in Y\) with \(y \cap Y = \emptyset \). Each \(z \in y\) lies in \(T\) but not in \(Y\), so there is a least ordinal \(\alpha _z\) with \(z \in V_{\alpha _z}\). By replacement, \(\{ \alpha _z : z \in y\} \) is a set; let \(\alpha \) be its supremum. Then \(y \subseteq V_\alpha \) by Lemma 3.5.12, so \(y \in V_{\alpha + 1}\), a contradiction.

007P Definition 3.5.15

The rank \(\operatorname {rk}(x)\) of a set \(x\) is the least ordinal \(\alpha \) with \(x \subseteq V_\alpha \).
