17.3 Metric spaces00R8

Complete. This chapter is written; its proofs await independent checking.

00R9 Definition 17.3.1

A metric on a set \(X\) is a map \(d \colon X \times X \to \mathbb {R}\) such that for all \(x, y, z \in X\): \(d(x, y) \geq 0\) with equality if and only if \(x = y\); \(d(x, y) = d(y, x)\); and \(d(x, z) \leq d(x, y) + d(y, z)\) (the triangle inequality). The open ball of radius \(r {\gt} 0\) around \(x\) is \(B(x, r) = \{ y : d(x, y) {\lt} r\} \). A set \(A\) is bounded if \(A \subseteq B(x, r)\) for some \(x\) and \(r\).

00RA Lemma 17.3.2

The open balls of a metric space form a basis of a topology, the metric topology: \(U\) is open if and only if for every \(x \in U\) there is \(\varepsilon {\gt} 0\) with \(B(x, \varepsilon ) \subseteq U\). It is Hausdorff. A space whose topology is the metric topology of some metric is metrisable.

Proof â–¼

If \(x \in B(a, r) \cap B(b, s)\), let \(\varepsilon = \min (r - d(a, x), s - d(b, x)) {\gt} 0\). By the triangle inequality \(B(x, \varepsilon )\) is contained in both balls, so Lemma 17.2.6 applies; the description of open sets follows. If \(x \neq y\) and \(r = d(x, y)\), the balls \(B(x, r/2)\) and \(B(y, r/2)\) are disjoint by the triangle inequality.

00RB Definition 17.3.3

Let \(\mathbb {K} = \mathbb {R}\) or \(\mathbb {C}\), with absolute value \(|\cdot |\). A norm on a \(\mathbb {K}\)-vector space \(V\) is a map \(\| \cdot \| \colon V \to \mathbb {R}\) such that \(\| v\| = 0\) only for \(v = 0\), \(\| \lambda v\| = |\lambda |\, \| v\| \) and \(\| v + w\| \leq \| v\| + \| w\| \) (so \(\| v\| \geq 0\)). Then \(d(v, w) = \| v - w\| \) is a metric. On \(\mathbb {K}^n\) we use the Euclidean norm \(\| x\| _2 = (\sum _i |x_i|^2)^{1/2}\), the norm of the standard inner product (a norm by Proposition 10.9.2), and the maximum norm \(\| x\| _\infty = \max _i |x_i|\).

00RC Lemma 17.3.4

If \(d, d'\) are metrics on \(X\) with \(c\, d \leq d' \leq C\, d\) for constants \(c, C {\gt} 0\), they define the same topology. In particular, since \(\| x\| _\infty \leq \| x\| _2 \leq \sqrt{n}\, \| x\| _\infty \), the two norms on \(\mathbb {K}^n\) define the same topology. On \(\mathbb {R}\) it is the topology with basis the open intervals, the standard topology.

Proof â–¼

\(B_{d'}(x, c\varepsilon ) \subseteq B_d(x, \varepsilon )\) and \(B_d(x, \varepsilon /C) \subseteq B_{d'}(x, \varepsilon )\), so the criterion of Lemma 17.3.2 gives the same open sets. The norm inequalities hold because \(\max _i |x_i|^2 \leq \sum _i |x_i|^2 \leq n \max _i |x_i|^2\). On \(\mathbb {R}\) the balls are the bounded open intervals \((a - r, a + r)\), and every bounded open interval is such a ball.

00RD Proposition 17.3.5

Let \(f \colon X \to Y\) be a map of metric spaces.

  1. \(f\) is continuous if and only if for every \(x\) and \(\varepsilon {\gt} 0\) there is \(\delta {\gt} 0\) with \(d(f(x), f(x')) {\lt} \varepsilon \) whenever \(d(x, x') {\lt} \delta \).

  2. For \(A \subseteq X\), a point \(x\) lies in \(\overline{A}\) if and only if it is the limit of a sequence in \(A\).

  3. \(f\) is continuous if and only if \(f(x_n) \to f(x)\) whenever \(x_n \to x\).

Proof â–¼

(1) is Proposition 17.2.8(4) with balls. (2) If \(x \in \overline{A}\), choose \(a_n \in A \cap B(x, 1/(n+1))\) by Lemma 17.2.4; then \(a_n \to x\). Conversely, if \(a_n \to x\), every open set containing \(x\) contains some \(a_n\). (3) If \(f\) is continuous and \(x_n \to x\), every open \(V \ni f(x)\) has open preimage containing \(x\), hence containing \(x_n\) for large \(n\). If \(f\) is not continuous at \(x\), there are \(\varepsilon {\gt} 0\) and \(x_n\) with \(d(x, x_n) {\lt} 1/(n+1)\) and \(d(f(x), f(x_n)) \geq \varepsilon \); then \(x_n \to x\) but \(f(x_n) \not\to f(x)\).

00RE Counterexample 17.3.6

In general spaces sequences do not detect closures. Give \(\mathbb {R}\) the cocountable topology. If \(x_n \to x\), the set \(C = \{ x_n : x_n \neq x\} \) is countable, so \(\mathbb {R}\setminus C\) is an open set containing \(x\), and hence \(x_n = x\) for large \(n\). Now \(A = \mathbb {R}\setminus \{ 0\} \) is uncountable (Proposition 4.8.6), so the only closed set containing it is \(\mathbb {R}\) and \(0 \in \overline{A}\); but no sequence in \(A\) converges to \(0\). (Nets or filters replace sequences in general [Eng89, Chapter 1].)

00RF Proposition 17.3.7

Addition and multiplication \(\mathbb {K} \times \mathbb {K} \to \mathbb {K}\) are continuous for the metric \(\| (x, y) - (a, b)\| _\infty \), and so is \(x \mapsto 1/x\) on \(\mathbb {K} \setminus \{ 0\} \).

Proof â–¼

We have \(|(x + y) - (a + b)| \leq |x - a| + |y - b|\), and if \(|x - a|, |y - b| {\lt} \delta \leq 1\) then \(|xy - ab| \leq |x|\, |y - b| + |b|\, |x - a| \leq (|a| + 1 + |b|)\delta \). If \(|x - a| {\lt} |a|/2\) then \(|x| {\gt} |a|/2\) and \(|1/x - 1/a| = |x - a|/(|x|\, |a|) \leq 2|x - a|/|a|^2\). In each case the criterion of Proposition 17.3.5(1) holds.

00RG Proposition 17.3.8

Let \(X\) be a space, \((Y, d)\) a metric space and \(f_n \colon X \to Y\) continuous maps converging uniformly to \(f\): for every \(\varepsilon {\gt} 0\) there is \(N\) with \(d(f_n(x), f(x)) {\lt} \varepsilon \) for all \(n \geq N\) and all \(x\). Then \(f\) is continuous.

Proof â–¼

Let \(x \in X\) and \(\varepsilon {\gt} 0\). Choose \(n\) with \(d(f_n, f) {\lt} \varepsilon /3\) everywhere, and an open \(U \ni x\) with \(d(f_n(x), f_n(x')) {\lt} \varepsilon /3\) for \(x' \in U\). Then \(d(f(x), f(x')) {\lt} \varepsilon \) for \(x' \in U\), and Proposition 17.2.8(4) applies.

00RH Definition 17.3.9

A space is first countable if every point \(x\) has countably many open neighbourhoods such that every open set containing \(x\) contains one of them; second countable if its topology has a countable basis; separable if it has a countable dense subset; and Lindelöf if every open cover has a countable subcover.

00RI Proposition 17.3.10

Metric spaces are first countable. Second countable spaces are separable and Lindelöf. A separable metric space is second countable. In particular \(\mathbb {R}^n\) and \(\mathbb {C}^n\) are second countable.

Proof â–¼

The balls \(B(x, 1/(n+1))\) show first countability. Let \(\mathcal{B}\) be a countable basis. Choosing a point in each nonempty member gives a countable set meeting every nonempty open set, hence dense by Lemma 17.2.4. Given an open cover \(\mathcal{U}\), for each \(B \in \mathcal{B}\) contained in some member of \(\mathcal{U}\) choose one such member \(U_B\); these countably many sets cover, because a point \(x \in U \in \mathcal{U}\) lies in some \(B \in \mathcal{B}\) with \(B \subseteq U\), and then \(x \in U_B\). If \(D\) is a countable dense subset of a metric space, the balls \(B(q, 1/n)\) with \(q \in D\), \(n \geq 1\) form a basis: if \(x \in U\) with \(U\) open, choose \(n\) with \(B(x, 2/n) \subseteq U\) and \(q \in D \cap B(x, 1/n)\); then \(x \in B(q, 1/n) \subseteq B(x, 2/n) \subseteq U\). Finally \(\mathbb {Q}^n\) and \((\mathbb {Q}+ i\mathbb {Q})^n\) are countable (Corollary 3.6.13) and dense, by density of \(\mathbb {Q}\) in \(\mathbb {R}\) (Proposition 4.7.3).

029B Counterexample 17.3.11 The Sorgenfrey line

The half-open intervals \([a, b)\) form a basis of a topology on \(\mathbb {R}\), the Sorgenfrey line, finer than the Euclidean topology. It is first countable (the sets \([x, x + 1/n)\) form a neighbourhood basis at \(x\)) and separable (\(\mathbb {Q}\) is dense, as every \([a, b)\) contains a rational number). It is not second countable: if \(\mathcal{B}\) is a basis, then for each \(x\) some \(B_x \in \mathcal{B}\) satisfies \(x \in B_x \subseteq [x, x + 1)\), so \(x = \min B_x\), and \(x \mapsto B_x\) is injective from the uncountable set \(\mathbb {R}\) to \(\mathcal{B}\). By Proposition 17.3.10, it is therefore not metrisable: separable metric spaces are second countable.
