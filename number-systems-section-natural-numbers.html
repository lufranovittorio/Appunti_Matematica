4.2 Arithmetic of the natural numbers008X

Complete. This chapter is written; its proofs await independent checking.

Recall from Example 3.4.7 that addition and multiplication on \(\mathbb {N}= \omega \) are defined by \(m + 0 = m\), \(m + S(n) = S(m + n)\), \(m \cdot 0 = 0\) and \(m \cdot S(n) = m \cdot n + m\). We have \(m + 1 = S(m)\), since \(m + S(0) = S(m + 0)\). All inductions below are instances of Theorem 3.4.2.

008Y Proposition 4.2.1

For all \(m, n, k \in \mathbb {N}\):

  1. \((m + n) + k = m + (n + k)\);

  2. \(m + n = n + m\);

  3. if \(m + k = n + k\), then \(m = n\);

  4. if \(m + n = 0\), then \(m = n = 0\).

Proof â–¼

(1) By induction on \(k\): for \(k = 0\) both sides are \(m + n\), and \((m + n) + S(k) = S((m + n) + k) = S(m + (n + k)) = m + S(n + k) = m + (n + S(k))\).

(2) First, \(0 + n = n\) by induction on \(n\). Next, \(S(m) + n = S(m + n)\) by induction on \(n\): \(S(m) + 0 = S(m) = S(m + 0)\) and \(S(m) + S(n) = S(S(m) + n) = S(S(m + n)) = S(m + S(n))\). Now induct on \(n\): \(m + 0 = m = 0 + m\), and \(m + S(n) = S(m + n) = S(n + m) = S(n) + m\).

(3) By induction on \(k\), using that \(S\) is injective (Proposition 3.4.5): \(m + S(k) = n + S(k)\) means \(S(m + k) = S(n + k)\).

(4) If \(n = S(n')\) then \(m + n = S(m + n') \neq 0\). So \(n = 0\), and then \(m = 0\).

008Z Proposition 4.2.2

For all \(m, n, k \in \mathbb {N}\):

  1. \(m \cdot (n + k) = m \cdot n + m \cdot k\);

  2. \((m \cdot n) \cdot k = m \cdot (n \cdot k)\);

  3. \(m \cdot n = n \cdot m\) and \(1 \cdot n = n\);

  4. if \(m \cdot n = 0\), then \(m = 0\) or \(n = 0\).

Proof â–¼

(1) By induction on \(k\): \(m(n + 0) = mn = mn + 0\), and \(m(n + S(k)) = m \cdot S(n + k) = m(n + k) + m = (mn + mk) + m = mn + m \cdot S(k)\).

(2) By induction on \(k\): \((mn) \cdot 0 = 0 = m(n \cdot 0)\), and, using (1), \((mn) \cdot S(k) = (mn)k + mn = m(nk) + mn = m(nk + n) = m(n \cdot S(k))\).

(3) By induction, \(0 \cdot n = 0\) and \(S(m) \cdot n = mn + n\); for the second, \(S(m) \cdot S(n) = S(m) n + S(m) = (mn + n) + S(m)\) and \(m \cdot S(n) + S(n) = (mn + m) + S(n)\), and both equal \(S(mn + m + n)\) by Proposition 4.2.1. Then \(mn = nm\) follows by induction on \(n\), and \(1 \cdot n = 0 \cdot n + n = n\).

(4) If \(m = S(m')\) and \(n = S(n')\), then \(mn = mn' + m = S(mn' + m')\), which is not \(0\).

0090 Proposition 4.2.3

For \(m, n \in \mathbb {N}\), the following are equivalent: \(m \leq n\) in the order of ordinals (Proposition 3.5.7); there is \(k \in \mathbb {N}\) with \(m + k = n\). This \(k\) is unique. Moreover, for all \(m, n, k \in \mathbb {N}\): if \(m \leq n\) then \(m + k \leq n + k\) and \(mk \leq nk\); and if \(mk = nk\) with \(k \neq 0\) then \(m = n\).

Proof â–¼

By induction on \(k\), \(m \leq m + k\): indeed \(m + S(k) = S(m + k)\) contains \(m + k\). Conversely we show by induction on \(n\) that \(m \leq n\) implies \(m + k = n\) for some \(k\). For \(n = 0\), \(m = 0\) and \(k = 0\). If \(m \leq S(n)\), then \(m = S(n)\) (take \(k = 0\)) or \(m \leq n\), in which case \(m + k = n\) for some \(k\) and \(m + S(k) = S(n)\). Uniqueness of \(k\) is Proposition 4.2.1(3).

If \(m + j = n\), then \((m + k) + j = n + k\) and \(mk + jk = nk\), which gives the monotonicity statements. If \(mk = nk\) with \(k \neq 0\) and, say, \(m {\lt} n\), write \(n = m + j\) with \(j \neq 0\); then \(mk + jk = mk + 0\), so \(jk = 0\), contradicting Proposition 4.2.2(4).

0091 Proposition 4.2.4 Division with remainder

Let \(m, n \in \mathbb {N}\) with \(n \geq 1\). There are unique \(q, r \in \mathbb {N}\) with \(m = qn + r\) and \(r {\lt} n\).

Proof â–¼

Existence, by induction on \(m\): for \(m = 0\) take \(q = r = 0\). If \(m = qn + r\) with \(r {\lt} n\), then \(m + 1 = qn + (r + 1)\), and either \(r + 1 {\lt} n\), or \(r + 1 = n\) and \(m + 1 = (q + 1)n + 0\). Uniqueness: if \(qn + r = q'n + r'\) with \(r, r' {\lt} n\) and \(q {\lt} q'\), then \(q'n + r' \geq (q + 1)n = qn + n {\gt} qn + r\), a contradiction; so \(q = q'\), and \(r = r'\) by cancellation.
