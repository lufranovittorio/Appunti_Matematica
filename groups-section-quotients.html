6.4 Normal subgroups and quotients00CE

Complete. This chapter is written; its proofs await independent checking.

00CF Definition 6.4.1

A subgroup \(N \leq G\) is normal, written \(N \trianglelefteq G\), if \(gNg^{-1} = N\) for all \(g \in G\), equivalently \(gN = Ng\) for all \(g\). A group \(G \neq \{ e\} \) is simple if its only normal subgroups are \(\{ e\} \) and \(G\).

00CG Lemma 6.4.2

Kernels of homomorphisms are normal. Every subgroup of an abelian group is normal. A subgroup of index \(2\) is normal.

Proof â–¼

If \(f(n) = e\) then \(f(gng^{-1}) = f(g)f(g)^{-1} = e\). The second claim is clear. If \([G:H] = 2\), then for \(g \notin H\) both \(gH\) and \(Hg\) are the complement of \(H\).

00CH Theorem 6.4.3

Let \(N \trianglelefteq G\). The rule \((aN)(bN) = abN\) is a well-defined operation making \(G/N\) a group, the quotient group, and the projection \(\pi \colon G \to G/N\) is a surjective homomorphism with kernel \(N\). If \(f \colon G \to H\) is a homomorphism with \(N \subseteq \ker f\), there is a unique homomorphism \(\bar f \colon G/N \to H\) with \(\bar f \circ \pi = f\).

Proof â–¼

If \(aN = a'N\) and \(bN = b'N\), write \(a' = an\), \(b' = bm\). Then \(a'b' = anbm = ab(b^{-1}nb)m \in abN\) since \(N\) is normal. The group axioms follow from those of \(G\), with neutral element \(N\) and \((aN)^{-1} = a^{-1}N\). Clearly \(\pi \) is a surjective homomorphism, and \(\pi (a) = N\) iff \(a \in N\). If \(N \subseteq \ker f\) then \(f\) is constant on cosets, and \(\bar f\) exists and is unique by Proposition 3.3.9; it is a homomorphism because \(\pi \) is surjective.

00CI Theorem 6.4.4 Isomorphism theorems

  1. If \(f \colon G \to H\) is a homomorphism, \(\bar f \colon G/\ker f \to \operatorname {im}f\) is an isomorphism.

  2. If \(H \leq G\) and \(N \trianglelefteq G\), then \(HN\) is a subgroup, \(N \trianglelefteq HN\), \(H \cap N \trianglelefteq H\), and \(H/(H \cap N) \cong HN/N\).

  3. If \(N \leq M\) are normal subgroups of \(G\), then \(M/N \trianglelefteq G/N\) and \((G/N)/(M/N) \cong G/M\).

  4. (Correspondence theorem) If \(N \trianglelefteq G\), then \(K \mapsto K/N\) is a bijection from the set of subgroups of \(G\) containing \(N\) to the set of subgroups of \(G/N\), preserving inclusions, normality and indices.

Proof â–¼

(1) \(\bar f\) is surjective onto \(\operatorname {im}f\) and has trivial kernel. (2) \(HN = NH\) because \(hN = Nh\), so \(HN\) is closed under products and inverses. The composite \(H \to HN \to HN/N\) is surjective, since \(hnN = hN\), with kernel \(H \cap N\); apply (1). (3) The map \(G/N \to G/M\), \(gN \mapsto gM\), is a well-defined surjective homomorphism (Theorem 6.4.3) with kernel \(M/N\); apply (1). (4) The inverse map sends \(\bar K \leq G/N\) to \(\pi ^{-1}[\bar K]\); since \(\pi \) is surjective, \(\pi [\pi ^{-1}[\bar K]] = \bar K\), and \(\pi ^{-1}[\pi [K]] = KN = K\) when \(N \subseteq K\). Normality is preserved because \(\pi \) is surjective, and \(gK \mapsto (gN)(K/N)\) is a bijection \(G/K \to (G/N)/(K/N)\).

00CJ Example 6.4.5

For \(n \geq 1\), the quotient \(\mathbb {Z}/n\mathbb {Z}\) is a cyclic group of order \(n\), with elements the classes of \(0, 1, \ldots , n-1\). If \(G = \langle g \rangle \) is cyclic, the homomorphism \(\mathbb {Z}\to G\), \(k \mapsto g^k\) is surjective with kernel \(\operatorname {ord}(g)\mathbb {Z}\), so \(G \cong \mathbb {Z}\) if \(g\) has infinite order and \(G \cong \mathbb {Z}/n\mathbb {Z}\) if \(\operatorname {ord}(g) = n\). Thus a cyclic group is determined up to isomorphism by its order. By the correspondence theorem the subgroups of \(\mathbb {Z}/n\mathbb {Z}\) are the \(d\mathbb {Z}/n\mathbb {Z}\) for \(d \mid n\), one for each divisor.

00CK Definition 6.4.6

The center of \(G\) is \(Z(G) = \{ z \in G : zg = gz \text{ for all } g\} \). For \(g \in G\), conjugation \(c_g(x) = gxg^{-1}\) is an automorphism; automorphisms of this form are inner. The centraliser of \(x\) is \(C_G(x) = \{ g : gx = xg\} \) and the normaliser of \(H \leq G\) is \(N_G(H) = \{ g : gHg^{-1} = H\} \).

00CL Lemma 6.4.7

\(Z(G)\) is a normal subgroup, and \(g \mapsto c_g\) is a homomorphism \(G \to \operatorname {Aut}(G)\) with kernel \(Z(G)\). If \(G/Z(G)\) is cyclic, then \(G\) is abelian.

Proof â–¼

\(c_{gh} = c_g \circ c_h\), and \(c_g = \mathrm{id}\) iff \(g \in Z(G)\). If \(G/Z(G)\) is generated by \(gZ(G)\), every element of \(G\) is \(g^k z\) with \(z \in Z(G)\), and such elements commute with each other.
