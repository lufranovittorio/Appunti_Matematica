10.8 Binary quadratic forms0316

Complete. This chapter is written; its proofs await independent checking.

Fermat’s theorem says which primes are \(x^2 + y^2\), and Corollary 10.7.6 which are \(x^2 + xy + y^2\) and \(x^2 + 3y^2\). What about \(x^2 + 5y^2\)? The primes \(29 = 3^2 + 5 \cdot 2^2\) and \(41 = 6^2 + 5 \cdot 1^2\) are of this form, but \(3\) and \(7\) are not, although \(-20\) is a square modulo \(3\) and \(7\). They are represented instead by the form \(2x^2 + 2xy + 3y^2\), at \((x, y) = (0, 1)\) and \((1, 1)\). Lagrange and Gauss understood that one should study all forms of a given discriminant at once, up to changes of variables. This theory, reduction of forms and the class number, explains the examples, and leads to Euler’s famous prime-producing polynomial \(n^2 + n + 41\) and to the Heegner numbers.

0317 Definition 10.8.1

A binary quadratic form is \(f(x, y) = ax^2 + bxy + cy^2\) with \(a, b, c \in \mathbb {Z}\), written \(f = (a, b, c)\). Its discriminant is \(D = b^2 - 4ac\). The form is positive definite if \(f(x, y) {\gt} 0\) for all \((x, y) \in \mathbb {R}^2 \setminus \{ 0\} \). An integer \(m\) is represented by \(f\) if \(m = f(x, y)\) with \(x, y \in \mathbb {Z}\), and properly represented if moreover \(\gcd (x, y) = 1\). Two forms \(f\) and \(g\) are equivalent if \(g(x, y) = f(px + qy, rx + sy)\) for some integers \(p, q, r, s\) with \(ps - qr = 1\), that is, for a matrix in \(\mathrm{SL}_2(\mathbb {Z})\).

The discriminant satisfies \(D \equiv b^2 \equiv 0\) or \(1 \pmod4\). Completing the square, \(4af(x, y) = (2ax + by)^2 - Dy^2\); so \(f\) is positive definite if and only if \(D {\lt} 0\) and \(a {\gt} 0\), and then \(c {\gt} 0\) as well. Equivalence is an equivalence relation, because \(\mathrm{SL}_2(\mathbb {Z})\) is a group; it preserves the discriminant, and equivalent forms represent the same integers, properly or not, since a matrix in \(\mathrm{SL}_2(\mathbb {Z})\) permutes \(\mathbb {Z}^2\) and the primitive vectors. In matrix terms, \(f(x, y) = (x\ y)\, M_f\, (x\ y)^T\) with \(M_f = \bigl(\begin{smallmatrix} a & b/2 \\ b/2 & c \end{smallmatrix}\bigr)\), \(D = -4\det M_f\), and substituting \((x, y)^T \mapsto P(x, y)^T\) replaces \(M_f\) by \(P^TM_fP\), which has the same determinant. Two substitutions are used constantly:

\[ (a, b, c) \sim (a, b + 2at, at^2 + bt + c) \quad \bigl(x \mapsto x + ty\bigr), \qquad (a, b, c) \sim (c, -b, a) \quad \bigl((x, y) \mapsto (-y, x)\bigr). \]
0318 Definition 10.8.2

A positive definite form \((a, b, c)\) is reduced if \(|b| \leq a \leq c\), and \(b \geq 0\) whenever \(|b| = a\) or \(a = c\).

0319 Theorem 10.8.3 Lagrange, Gauss

Every positive definite form is equivalent to exactly one reduced form. If \((a, b, c)\) is reduced of discriminant \(D\), then \(a \leq \sqrt{|D|/3}\); hence there are only finitely many reduced forms of a given discriminant.

Proof â–¼

Existence. Let \(f = (a, b, c)\) be positive definite. Using the first substitution with a suitable \(t\) we can achieve \(|b| \leq a\), since \(b + 2at\) runs through a residue class modulo \(2a\). If then \(a {\gt} c\), the second substitution replaces \(a\) by the smaller positive integer \(c\). Alternate these two steps; since \(a\) decreases strictly at each use of the second step, after finitely many steps \(|b| \leq a \leq c\). Finally, if \(b = -a\), the first substitution with \(t = 1\) gives \((a, a, c)\) (as \(a - a + c = c\)); and if \(a = c\) and \(b {\lt} 0\), the second gives \((a, -b, a)\). The result is reduced.

The bound. If \(|b| \leq a \leq c\), then \(|D| = 4ac - b^2 \geq 4a^2 - a^2 = 3a^2\).

Uniqueness. Let \(f = (a, b, c)\) satisfy \(|b| \leq a \leq c\). For integers \(x\), \(y\): if \(|x| \geq |y|\), then \(f(x, y) \geq ax^2 - |b||x||y| + cy^2 \geq (a - |b|)x^2 + cy^2\), and if \(|y| \geq |x|\), similarly \(f(x, y) \geq ax^2 + (c - |b|)y^2\). Hence \(f(x, y) \geq a\) if \((x, y) \neq 0\), \(f(x, y) \geq c\) if \(y \neq 0\) (for \(x = 0\) this is \(cy^2 \geq c\), and for \(xy \neq 0\) both bounds give at least \(a - |b| + c \geq c\)), and, when \(|b| {\lt} a {\lt} c\), \(f(x, y) {\gt} a\) for all \((x, y) \neq (\pm 1, 0)\), the bound for \(xy \neq 0\) then being \(a - |b| + c {\gt} c {\gt} a\).

Consequently \(a\) is the smallest nonzero value of \(f\) on \(\mathbb {Z}^2\), and \(c\) is the smallest value \(f(w)\) for \(w\) linearly independent of a vector \(v\) with \(f(v) = a\). (For \(v = (1, 0)\) the vectors \(w\) independent of \(v\) have \(y \neq 0\), so \(f(w) \geq c = f(0, 1)\). If \(f(v) = a\) with \(v = (x, y)\), \(y \neq 0\), then \(a = f(v) \geq c\), so \(a = c\), every \(w\) has \(f(w) \geq a = c\), and \(w = (1, 0)\) is independent of \(v\) with \(f(w) = c\).) These two numbers are unchanged by an equivalence, which maps \(\mathbb {Z}^2\) bijectively to itself and preserves linear independence. So equivalent reduced forms have the same \(a\) and \(c\), hence the same \(|b| = \sqrt{D + 4ac}\).

It remains to exclude that \((a, b, c)\) and \((a, -b, c)\), with \(b {\gt} 0\), are both reduced and equivalent. If \((a, -b, c)\) is reduced, then \(|b| {\lt} a {\lt} c\) by the sign condition. Suppose \((a, b, c)(x, y) = g(px + qy, rx + sy)\) with \(g = (a, -b, c)\) and \(ps - qr = 1\). Taking \((x, y) = (1, 0)\) gives \(g(p, r) = a\), so \((p, r) = \pm (1, 0)\) by the strict inequality above, applied to \(g\). Then \(ps = 1\) gives \(s = p = \pm 1\), and the substitution is \(\pm (x + q^{\prime }y, y)\) with \(q^{\prime } = \pm q\); as \(g(-v) = g(v)\), \((a, b, c)\) is obtained from \(g\) by the first substitution with \(t = q^{\prime }\), so \(b = -b + 2aq^{\prime }\). Then \(2|b| = 2a|q^{\prime }|\) with \(0 {\lt} |b| {\lt} a\), which is impossible.

The number of reduced forms of discriminant \(D\) is called the class number \(h(D)\) (often one counts only primitive forms, with \(\gcd (a, b, c) = 1\); for the discriminants below the two counts agree unless noted). The reduced forms are found by a finite search: \(b \equiv D \pmod2\), \(|b| \leq a \leq \sqrt{|D|/3}\), and \(c = (b^2 - D)/4a\) must be an integer with \(c \geq a\).

031A Example 10.8.4

  1. \(D = -4\): \(a \leq 1\), so \((a, b, c) = (1, 0, 1)\), and \(h(-4) = 1\). \(D = -3\): \((1, 1, 1)\). \(D = -8\): \(a \leq 1\), \(b = 0\), \((1, 0, 2)\). \(D = -7\): \((1, 1, 2)\). So each of these discriminants has the single reduced form \(x^2 + y^2\), \(x^2 + xy + y^2\), \(x^2 + 2y^2\), \(x^2 + xy + 2y^2\) respectively.

  2. \(D = -12\): \(a \leq 2\); \(a = 1\) gives \((1, 0, 3)\); \(a = 2\) requires \(b \in \{ 0, 2\} \) and \(c = (b^2 + 12)/8\), which gives \((2, 2, 2)\). This form is not primitive and represents only even numbers; the primitive class number is \(h(-12) = 1\).

  3. \(D = -20\): \(a \leq 2\); \((1, 0, 5)\), and for \(a = 2\), \(b \in \{ 0, 2\} \) with \(c = (b^2 + 20)/8\), giving \((2, 2, 3)\). So \(h(-20) = 2\), with the forms \(x^2 + 5y^2\) and \(2x^2 + 2xy + 3y^2\), matching the class number \(2\) of \(\mathbb {Z}[\sqrt{-5}]\) in Example 10.7.7.

  4. \(D = -23\): \(a \leq 2\), \(b\) odd; \(b = \pm 1\), \(ac = 6\): \((1, 1, 6)\), \((2, 1, 3)\), \((2, -1, 3)\), all reduced (for \(a = 2\) we have \(|b| {\lt} a {\lt} c\), so both signs are allowed). So \(h(-23) = 3\): the forms \(2x^2 \pm xy + 3y^2\) are improperly equivalent (by \((x, y) \mapsto (x, -y)\)) but not equivalent under \(\mathrm{SL}_2(\mathbb {Z})\).

To connect forms with primes we need to know which forms represent a given number.

031B Lemma 10.8.5

Let \(D {\lt} 0\) and \(m \geq 1\). Then \(m\) is properly represented by some form of discriminant \(D\) if and only if \(D \equiv b^2 \pmod{4m}\) for some integer \(b\). More precisely, if \(D = b^2 - 4mc\), then \(m\) is properly represented by \((m, b, c)\); and if \(f(x_0, y_0) = m\) with \(\gcd (x_0, y_0) = 1\), then \(f\) is equivalent to a form \((m, b, c)\).

Proof â–¼

If \(D = b^2 - 4mc\), then \((m, b, c)\) has discriminant \(D\) and \(m = f(1, 0)\). Conversely let \(f(x_0, y_0) = m\) with \(\gcd (x_0, y_0) = 1\). By Bézout’s identity choose \(q\), \(s\) with \(x_0s - qy_0 = 1\); the substitution \((x, y) \mapsto (x_0x + qy, y_0x + sy)\) lies in \(\mathrm{SL}_2(\mathbb {Z})\) and transforms \(f\) into a form \(g\) with \(g(1, 0) = f(x_0, y_0) = m\), that is, \(g = (m, b, c)\), and \(D = b^2 - 4mc \equiv b^2 \pmod{4m}\).

031C Corollary 10.8.6

Let \(D {\lt} 0\) be a discriminant such that the only reduced form of discriminant \(D\) is \(f_0\). Then a prime \(p\) is represented by \(f_0\) if and only if \(D\) is a square modulo \(4p\). In particular:

  1. (Fermat) an odd prime \(p\) is \(x^2 + y^2\) if and only if \(p \equiv 1 \pmod4\);

  2. an odd prime \(p\) is \(x^2 + 2y^2\) if and only if \(p \equiv 1, 3 \pmod8\);

  3. a prime \(p \neq 7\) is \(x^2 + xy + 2y^2\), equivalently \(x^2 + 7y^2\) when \(p\) is odd, if and only if \((\frac{p}{7}) = 1\), that is, \(p \equiv 1, 2, 4 \pmod7\).

Proof â–¼

A prime is properly represented whenever it is represented, since \(f(x, y) = p\) forces \(\gcd (x, y)^2 \mid p\). So by Lemma 10.8.5, \(p\) is represented by some form of discriminant \(D\) if and only if \(D\) is a square modulo \(4p\); and every such form is equivalent to its reduced form \(f_0\) (Theorem 10.8.3), which represents the same numbers.

For odd \(p\), \(D \equiv b^2 \pmod{4p}\) has a solution if and only if \(D\) is a square modulo \(p\): given \(D \equiv b^2 \pmod p\) we may change \(b\) by \(p\) to make \(b \equiv D \pmod2\), and then \(b^2 \equiv D \pmod4\) as well (both sides are \(\equiv 0\) or \(\equiv 1 \pmod4\) according to their parity), so \(b^2 \equiv D \pmod{4p}\) by the Chinese remainder theorem. Now (1) is \(D = -4\), where \(-4\) is a square modulo \(p\) if and only if \(-1\) is (Corollary 10.4.3). For (2), \(D = -8\) and \((\frac{-2}{p}) = (\frac{-1}{p})(\frac{2}{p})\) equals \(1\) exactly for \(p \equiv 1, 3 \pmod8\), by Corollary 10.4.3 and Proposition 10.4.7. For (3), \(D = -7\); for odd \(p \neq 7\), reciprocity gives \((\frac{-7}{p}) = (-1)^{\frac{p-1}{2}}(\frac{7}{p}) = (-1)^{\frac{p-1}{2}}(-1)^{\frac{p-1}{2}\cdot 3}(\frac{p}{7}) = (\frac{p}{7})\), and the squares modulo \(7\) are \(1, 2, 4\). For \(p = 2\), \(-7 \equiv 1 = 1^2 \pmod8\) and \(2 = x^2 + xy + 2y^2\) with \((x, y) = (0, 1)\), consistent with \(2 \equiv 2 \pmod7\). Finally, for odd values, \(4(x^2 + xy + 2y^2) = (2x + y)^2 + 7y^2\), and \(p = x^2 + xy + 2y^2\) odd forces \(y\) even (if \(y\) were odd, \(x^2 + xy = x(x + y)\) would be even and the value even), so \(p = (x + y/2)^2 + 7(y/2)^2\); conversely \(x^2 + 7y^2 = (x - y)^2 + (x - y)(2y) + 2(2y)^2\).

When \(h(D) {\gt} 1\) the corollary only says that \(p\) is represented by one of the reduced forms. For \(D = -20\), an odd prime \(p \neq 5\) is represented by \(x^2 + 5y^2\) or by \(2x^2 + 2xy + 3y^2\) exactly when \((\frac{-5}{p}) = 1\), that is (by reciprocity) when \(p \equiv 1, 3, 7, 9 \pmod{20}\). Congruences separate the two forms: \(x^2 + 5y^2\) takes odd prime values only \(\equiv 1, 9 \pmod{20}\), and \(2x^2 + 2xy + 3y^2\) only \(\equiv 3, 7 \pmod{20}\) (Exercise 10.9.15). So \(p = x^2 + 5y^2\) if and only if \(p \equiv 1, 9 \pmod{20}\), as Euler conjectured. For \(D = -23\) no such congruence description exists for \(x^2 + xy + 6y^2\); the answer requires class field theory [Cox89].

10.8.1 Euler’s polynomial and the Heegner numbers031D

Euler observed in 1772 that \(n^2 + n + 41\) is prime for \(n = 0, 1, \ldots , 39\): the values are \(41, 43, 47, 53, 61, 71, \ldots , 1601\). (For \(n = 40\) the value is \(41^2\).) The explanation is that \(-163\), the discriminant of \(x^2 + xy + 41y^2\), has class number one.

031E Theorem 10.8.7 Rabinowitsch

Let \(p\) be a prime and \(D = 1 - 4p\). The following are equivalent:

  1. the only reduced form of discriminant \(D\) is \(x^2 + xy + py^2\);

  2. \(n^2 + n + p\) is prime for \(n = 0, 1, \ldots , p - 2\).

Proof â–¼

Note \(4(n^2 + n + p) = (2n + 1)^2 - D\).

(1) \(\Rightarrow \) (2). Let \(0 \leq n \leq p - 2\) and \(N = n^2 + n + p\), and suppose \(N\) is not prime. Then it has a prime factor \(q \leq \sqrt N\), and \(N \leq (p - 2)^2 + (p - 2) + p = p^2 - 2p + 2 {\lt} p^2\), so \(q {\lt} p\). Since \(q \mid N\), \((2n + 1)^2 - D = 4N\) is divisible by \(4q\), and \((q, 2n + 1, N/q)\) is a form of discriminant \(D\) representing \(q\). By (1) and Theorem 10.8.3 it is equivalent to \(x^2 + xy + py^2\), so \(q = x^2 + xy + py^2\) for some integers \(x\), \(y\). If \(y = 0\), \(q = x^2\) is not prime. If \(y \neq 0\),

\[ q = \Bigl(x + \frac y2\Bigr)^2 + \frac{4p - 1}{4}y^2 \geq \frac{4p - 1}{4} {\gt} p - 1, \]

so \(q \geq p\), a contradiction.

(2) \(\Rightarrow \) (1). Let \((a, b, c)\) be reduced of discriminant \(D\). Then \(b\) is odd, \(b = \pm (2n + 1)\) with \(n \geq 0\), and \(ac = (b^2 - D)/4 = n^2 + n + p\). By Theorem 10.8.3, \(2n + 1 = |b| \leq a \leq \sqrt{(4p - 1)/3}\), so \(n {\lt} \sqrt{p/3} \leq p - 2\) for \(p \geq 3\), while for \(p = 2\) the bound gives \(n = 0\). So \(ac\) is prime by (2), and \(a \leq c\) forces \(a = 1\), hence \(|b| \leq 1\), \(b = 1\) (the sign condition for \(|b| = a\)), and \(c = p\).

031F Corollary 10.8.8

\(n^2 + n + 41\) is prime for \(n = 0, 1, \ldots , 39\).

Proof â–¼

We check condition (1) of Theorem 10.8.7 for \(D = -163\). A reduced form \((a, b, c)\) has \(b\) odd, \(|b| \leq a \leq \sqrt{163/3} {\lt} 8\), and \(ac = (b^2 + 163)/4\). For \(b = \pm 1, \pm 3, \pm 5, \pm 7\) this is \(41\), \(43\), \(47\), \(53\), all prime; as \(a \leq c\), \(a = 1\), and then \(|b| \leq 1\) and \(b = 1\). So \((1, 1, 41)\) is the only reduced form.

Forty values were checked by an argument involving eight. The same computation applies to \(p = 2, 3, 5, 11, 17, 41\), with \(D = -7, -11, -19, -43, -67, -163\) (Exercise 10.9.17).

031G Remark 10.8.9

  1. The Heegner numbers. The negative discriminants \(D\) for which every primitive positive definite form is equivalent to the principal one, \(x^2 - \frac D4y^2\) or \(x^2 + xy + \frac{1 - D}4y^2\), are exactly

    \[ D = -3, -4, -7, -8, -11, -12, -16, -19, -27, -28, -43, -67, -163 . \]

    Equivalently, the imaginary quadratic fields \(\mathbb {Q}(\sqrt{-d})\), \(d {\gt} 0\) squarefree, whose ring of integers is a UFD are those with \(d \in \{ 1, 2, 3, 7, 11, 19, 43, 67, 163\} \), the Heegner numbers. Gauss conjectured that the list is complete; it was proved by Heegner in 1952, whose argument was long considered incomplete, and by Baker and Stark in 1966–1967 [Cox89]. Combined with Theorem 10.8.7, it determines the primes \(p\) for which \(n^2 + n + p\) is prime for \(0 \leq n \leq p - 2\): \(1 - 4p\) must be one of the odd discriminants in the list, which gives \(p \in \{ 2, 3, 5, 7, 11, 17, 41\} \), and \(p = 7\) fails because of the non-primitive reduced form \((3, 3, 3)\) of discriminant \(-27\) (indeed \(1 + 1 + 7 = 9\)). So the primes are \(2, 3, 5, 11, 17, 41\), and Euler’s \(41\) is the largest.

  2. An almost integer. The number \(e^{\pi \sqrt{163}} = 262537412640768743.99999999999925\ldots \) is extraordinarily close to the integer \(640320^3 + 744\). The reason is again \(h(-163) = 1\): the \(j\)-invariant of the elliptic curve \(\mathbb {C}/\mathbb {Z}[\frac{1 + \sqrt{-163}}{2}]\) is then an integer, equal to \(-640320^3\), and the expansion \(j(\tau ) = e^{-2\pi i\tau } + 744 + 196884e^{2\pi i\tau } + \cdots \) at \(\tau = \frac{1 + \sqrt{-163}}{2}\), where \(e^{2\pi i\tau } = -e^{-\pi \sqrt{163}}\) is tiny, gives \(-e^{\pi \sqrt{163}} + 744 \approx -640320^3\) [Cox89]. This is the theory of complex multiplication, which connects class numbers with elliptic curves (Chapter 61).

  3. Class numbers grow. Although \(h(D) = 1\) only finitely often, \(h(D) \to \infty \) as \(D \to -\infty \) (Heilbronn, 1934); roughly, \(h(D)\) is of size \(\sqrt{|D|}\). The class number is also given by Dirichlet’s class number formula, which for \(D {\lt} -4\) fundamental reads \(h(D) = -\frac1{|D|}\sum _{m=1}^{|D|}\bigl(\frac{D}{m}\bigr)m\) with the Kronecker symbol [Cox89]; for \(D = -23\) it gives \(3\).
