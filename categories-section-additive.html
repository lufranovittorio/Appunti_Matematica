5.12 Additive categories00BJ

Complete. This chapter is written; its proofs await independent checking.

00BK Definition 5.12.1

A category \(\mathcal{A}\) is preadditive if every set \(\operatorname {Hom}(X, Y)\) has the structure of an abelian group, written additively, such that composition is bilinear: \((f + f') \circ g = f \circ g + f' \circ g\) and \(h \circ (f + f') = h \circ f + h \circ f'\). A zero object is an object that is both initial and terminal. A preadditive category is additive if it has a zero object and binary products. A functor between preadditive categories is additive if the maps \(\operatorname {Hom}(X, Y) \to \operatorname {Hom}(F(X), F(Y))\) are group homomorphisms.

00BL Lemma 5.12.2

Let \(\mathcal{A}\) be preadditive and \(X_1, X_2, P\) objects with morphisms \(i_m \colon X_m \to P\) and \(p_m \colon P \to X_m\) such that

\[ p_1 i_1 = \mathrm{id}_{X_1}, \quad p_2 i_2 = \mathrm{id}_{X_2}, \quad p_2 i_1 = 0, \quad p_1 i_2 = 0, \quad i_1 p_1 + i_2 p_2 = \mathrm{id}_P. \]

Then \((P, p_1, p_2)\) is a product and \((P, i_1, i_2)\) is a coproduct of \(X_1\) and \(X_2\). Conversely, if \(\mathcal{A}\) has a zero object and \((P, p_1, p_2)\) is a product of \(X_1\) and \(X_2\), there are unique \(i_1, i_2\) satisfying these equations.

Proof â–¼

Given \(f_m \colon Y \to X_m\), the morphism \(f = i_1 f_1 + i_2 f_2\) satisfies \(p_m f = f_m\). If \(g\) also does, then \(g = (i_1 p_1 + i_2 p_2) g = i_1 f_1 + i_2 f_2\). So \(P\) is a product; the coproduct statement is dual. Conversely, let \(i_1 \colon X_1 \to P\) be the unique morphism with \(p_1 i_1 = \mathrm{id}\) and \(p_2 i_1 = 0\), and similarly \(i_2\) (the zero morphism \(0 \in \operatorname {Hom}(X, Y)\) exists since Hom sets are groups). Then \(p_m (i_1 p_1 + i_2 p_2) = p_m\) for \(m = 1, 2\), so \(i_1 p_1 + i_2 p_2 = \mathrm{id}_P\) by the uniqueness in the universal property of the product.

00BM Definition 5.12.3

An object \(P\) with morphisms as in Lemma 5.12.2 is a biproduct or direct sum of \(X_1\) and \(X_2\), written \(X_1 \oplus X_2\). In a preadditive category with a zero object, the kernel of \(f \colon X \to Y\) is an equaliser of \(f\) and \(0\), and its cokernel is a coequaliser of \(f\) and \(0\).

00BN Proposition 5.12.4

Additive functors preserve biproducts and zero objects.

Proof â–¼

The equations of Lemma 5.12.2 involve only composition, sums, identities and zero morphisms, all preserved by an additive functor \(F\), so \(F\) sends a biproduct to a biproduct. An object \(Z\) is a zero object if and only if \(\mathrm{id}_Z = 0\) (then every \(\operatorname {Hom}(Z, Y)\) and \(\operatorname {Hom}(Y, Z)\) is the zero group), and this is preserved by \(F\).

00BO Example 5.12.5

The categories of abelian groups, of modules over a ring and of vector spaces over a field are additive, with the direct sum as biproduct (Chapter 7).

00BP Counterexample 5.12.6

The category \(\mathsf{Set}\) admits no preadditive structure: in a preadditive category every \(\operatorname {Hom}(X, Y)\) is nonempty, since it contains \(0\), but \(\operatorname {Hom}_{\mathsf{Set}}(\{ 0\} , \emptyset ) = \emptyset \).
