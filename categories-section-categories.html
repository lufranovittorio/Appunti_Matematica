5.2 Categories000M

Complete. This chapter is written; its proofs await independent checking.

000N Definition 5.2.1

A category \(\mathcal{C}\) consists of

  1. a set \(\operatorname {Ob}(\mathcal{C})\), whose elements are called the objects of \(\mathcal{C}\);

  2. for all objects \(X, Y\), a set \(\operatorname {Hom}_{\mathcal{C}}(X, Y)\), whose elements are called morphisms from \(X\) to \(Y\);

  3. for every object \(X\), an element \(\mathrm{id}_X \in \operatorname {Hom}_{\mathcal{C}}(X, X)\), the identity of \(X\);

  4. for all objects \(X, Y, Z\), a map

    \[ \operatorname {Hom}_{\mathcal{C}}(Y, Z) \times \operatorname {Hom}_{\mathcal{C}}(X, Y) \longrightarrow \operatorname {Hom}_{\mathcal{C}}(X, Z), \qquad (g, f) \longmapsto g \circ f, \]

    called composition,

such that the following hold:

  1. (associativity) \(h \circ (g \circ f) = (h \circ g) \circ f\) for all \(f \in \operatorname {Hom}_{\mathcal{C}}(X, Y)\), \(g \in \operatorname {Hom}_{\mathcal{C}}(Y, Z)\) and \(h \in \operatorname {Hom}_{\mathcal{C}}(Z, W)\);

  2. (identities) \(f \circ \mathrm{id}_X = f = \mathrm{id}_Y \circ f\) for all \(f \in \operatorname {Hom}_{\mathcal{C}}(X, Y)\);

  3. the sets \(\operatorname {Hom}_{\mathcal{C}}(X, Y)\) are pairwise disjoint.

000O Notation 5.2.2

We write \(X \in \mathcal{C}\) instead of \(X \in \operatorname {Ob}(\mathcal{C})\), and \(f \colon X \to Y\) instead of \(f \in \operatorname {Hom}_{\mathcal{C}}(X, Y)\). By the last axiom of Definition 5.2.1, a morphism \(f\) determines its source \(X\) and its target \(Y\). We often write \(gf\) for \(g \circ f\), and \(\operatorname {Hom}(X, Y)\) when the category is clear.

000P Definition 5.2.3

A category \(\mathcal{C}\) is locally small if \(\operatorname {Hom}_{\mathcal{C}}(X, Y)\) is a small set for all \(X, Y \in \mathcal{C}\). It is small if it is locally small and \(\operatorname {Ob}(\mathcal{C})\) is a small set.

000Q Remark 5.2.4

There is no set of all sets, so “the category of all sets” cannot be a category in the sense of Definition 5.2.1. The universe \(\mathcal{U}\) solves this problem: it is a set, it is closed under all the usual constructions of set theory (pairs, products, power sets, sets of maps, unions indexed by small sets), and it contains every set that appears in ordinary mathematics. So we can form the category of all small sets without leaving ZFC.

000R Example 5.2.5

The category \(\mathsf{Set}\) has as objects the small sets, that is, \(\operatorname {Ob}(\mathsf{Set}) = \mathcal{U}\). For small sets \(X\) and \(Y\), the set \(\operatorname {Hom}_{\mathsf{Set}}(X, Y)\) is the set of maps from \(X\) to \(Y\), composition is composition of maps, and \(\mathrm{id}_X\) is the identity map. Since \(\mathcal{U}\) is closed under forming sets of maps, \(\mathsf{Set}\) is locally small. It is not small, because \(\mathcal{U} \notin \mathcal{U}\).

(Strictly speaking, a map \(f \colon X \to Y\) should be recorded together with its target \(Y\), so that the last axiom of Definition 5.2.1 holds. We do this silently here and in similar examples.)

000S Example 5.2.6

In the same way there are locally small categories of small groups \(\mathsf{Grp}\), of small abelian groups \(\mathsf{Ab}\), of small rings \(\mathsf{Ring}\), of small vector spaces over a field \(k\), written \(\mathsf{Vect}_k\), and of small topological spaces \(\mathsf{Top}\). In each case the morphisms are the maps that preserve the relevant structure (group homomorphisms, ring homomorphisms, linear maps, continuous maps), and composition is composition of maps. These notions are defined in later chapters.

000T Definition 5.2.7

A monoid is a set \(M\) with a map \(M \times M \to M\), written \((a, b) \mapsto a \cdot b\) or simply \(ab\), which is associative, together with an element \(e \in M\) such that \(ea = a = ae\) for all \(a \in M\). (For a monoid given by addition, such as \((\mathbb {N}, +)\), we write \(a + b\) and \(0\) instead.) A homomorphism of monoids \(\varphi \colon M \to N\) is a map with \(\varphi (ab) = \varphi (a)\varphi (b)\) for all \(a, b \in M\) and \(\varphi (e) = e\). The small monoids and their homomorphisms form a locally small category \(\mathsf{Mon}\).

000U Example 5.2.8

Let \(M\) be a monoid. There is a category \(BM\) with a single object \(\ast \), with \(\operatorname {Hom}_{BM}(\ast , \ast ) = M\), with composition given by the multiplication of \(M\) and with \(\mathrm{id}_\ast = e\). The axioms of a category are exactly the axioms of a monoid. Conversely, if \(\mathcal{C}\) is a category and \(X \in \mathcal{C}\), then \(\operatorname {End}(X) = \operatorname {Hom}_{\mathcal{C}}(X, X)\) is a monoid under composition.

000V Example 5.2.9

Let \(P\) be a set with a relation \(\leq \) that is reflexive and transitive (a preorder). There is a category, also written \(P\), whose objects are the elements of \(P\), with \(\operatorname {Hom}_P(x, y) = \{ (x, y)\} \) if \(x \leq y\) and \(\operatorname {Hom}_P(x, y) = \emptyset \) otherwise. Composition is forced, because every set of morphisms has at most one element; it exists by transitivity, and the identities exist by reflexivity.

000W Example 5.2.10

Let \(S\) be a set. The discrete category on \(S\) has objects the elements of \(S\), with \(\operatorname {Hom}(s, s) = \{ \mathrm{id}_s\} \) and \(\operatorname {Hom}(s, t) = \emptyset \) for \(s \neq t\). It is the category associated with the preorder “\(s \leq t\) if and only if \(s = t\)”.

000X Definition 5.2.11

Let \(\mathcal{C}\) be a category. The opposite category \(\mathcal{C}^{\mathrm{op}}\) has the same objects as \(\mathcal{C}\) and \(\operatorname {Hom}_{\mathcal{C}^{\mathrm{op}}}(X, Y) = \operatorname {Hom}_{\mathcal{C}}(Y, X)\), with the same identities and with composition \(g \circ _{\mathrm{op}} f = f \circ g\).

000Y Remark 5.2.12

The axioms of a category are symmetric under reversing all morphisms, and \((\mathcal{C}^{\mathrm{op}})^{\mathrm{op}} = \mathcal{C}\). So every statement proved for all categories implies a dual statement, obtained by applying it to opposite categories.

000Z Definition 5.2.13

A subcategory \(\mathcal{D}\) of a category \(\mathcal{C}\) consists of a subset \(\operatorname {Ob}(\mathcal{D}) \subseteq \operatorname {Ob}(\mathcal{C})\) and subsets \(\operatorname {Hom}_{\mathcal{D}}(X, Y) \subseteq \operatorname {Hom}_{\mathcal{C}}(X, Y)\) for \(X, Y \in \mathcal{D}\), which contain the identities and are closed under composition. It is a full subcategory if \(\operatorname {Hom}_{\mathcal{D}}(X, Y) = \operatorname {Hom}_{\mathcal{C}}(X, Y)\) for all \(X, Y \in \mathcal{D}\).

0010 Example 5.2.14

The category \(\mathsf{Ab}\) is a full subcategory of \(\mathsf{Grp}\). The category whose objects are small sets and whose morphisms are the bijections is a subcategory of \(\mathsf{Set}\) that is not full.
