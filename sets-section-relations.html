3.3 Relations and functions006Q

Complete. This chapter is written; its proofs await independent checking.

006R Definition 3.3.1

The ordered pair of \(a\) and \(b\) is \((a, b) = \{ \{ a\} , \{ a, b\} \} \).

006S Lemma 3.3.2

\((a, b) = (c, d)\) if and only if \(a = c\) and \(b = d\).

Proof â–¼

Suppose \((a, b) = (c, d)\). If \(a = b\), then \((a, b) = \{ \{ a\} \} \), so \(\{ c\} = \{ c, d\} = \{ a\} \) and \(a = b = c = d\). Similarly if \(c = d\). Assume \(a \neq b\) and \(c \neq d\). Then \(\{ a\} \) is the only one-element set in \((a, b)\), and \(\{ c\} \) the only one in \((c, d)\), so \(\{ a\} = \{ c\} \) and \(a = c\). The two-element sets \(\{ a, b\} \) and \(\{ c, d\} = \{ a, d\} \) are then equal, and since \(b \neq a\) we get \(b = d\). The converse is clear.

006T Definition 3.3.3

The cartesian product of sets \(A\) and \(B\) is \(A \times B = \{ p \in \mathcal{P}(\mathcal{P}(A \cup B)) : \exists a \in A\, \exists b \in B\, p = (a, b)\} \). It is a set by separation, and its elements are exactly the pairs \((a, b)\) with \(a \in A\), \(b \in B\), because \(\{ a\} \) and \(\{ a, b\} \) are subsets of \(A \cup B\).

006U Definition 3.3.4

A relation from \(A\) to \(B\) is a subset \(R \subseteq A \times B\); we write \(a R b\) for \((a, b) \in R\). A function (or map) \(f \colon A \to B\) is a relation \(f \subseteq A \times B\) such that for every \(a \in A\) there is exactly one \(b \in B\) with \((a, b) \in f\), written \(b = f(a)\). (Formally, a function records its target: it is the triple \((A, B, f)\); we shall not insist on this.) For \(X \subseteq A\) and \(Y \subseteq B\), the image is \(f[X] = \{ f(a) : a \in X\} \) and the preimage is \(f^{-1}[Y] = \{ a \in A : f(a) \in Y\} \). The function is injective, surjective or bijective if it is so as a map in the usual sense. The composition \(g \circ f\) of \(f \colon A \to B\) and \(g \colon B \to C\) is \(\{ (a, c) \in A \times C : \exists b\, ((a, b) \in f \wedge (b, c) \in g)\} \). The set of all functions from \(A\) to \(B\) is \(B^A = \{ f \in \mathcal{P}(A \times B) : f \text{ is a function } A \to B\} \).

006V Definition 3.3.5

A family \((x_i)_{i \in I}\) is a function \(i \mapsto x_i\) with domain \(I\). Its union is \(\bigcup _{i \in I} x_i = \bigcup \{ x_i : i \in I\} \), which is a set: the image of \(I\) under the family is a set by replacement and separation. Its product is the set \(\prod _{i \in I} x_i = \{ f \in (\bigcup _{i \in I} x_i)^I : f(i) \in x_i \text{ for all } i \in I\} \).

006W Lemma 3.3.6

A function \(f \colon A \to B\) is bijective if and only if there is a function \(g \colon B \to A\) with \(g \circ f = \mathrm{id}_A\) and \(f \circ g = \mathrm{id}_B\); such a \(g\) is unique.

Proof â–¼

If \(f\) is bijective, \(g = \{ (b, a) : (a, b) \in f\} \) is a function \(B \to A\) with the two properties. Conversely, \(g \circ f = \mathrm{id}_A\) implies that \(f\) is injective and \(f \circ g = \mathrm{id}_B\) that \(f\) is surjective. If \(g'\) also has the properties, then \(g' = g' \circ f \circ g = g\).

006X Definition 3.3.7

An equivalence relation on \(A\) is a relation \(\sim \) from \(A\) to \(A\) that is reflexive, symmetric and transitive. The class of \(a \in A\) is \([a] = \{ x \in A : x \sim a\} \), and the quotient is the set \(A/{\sim } = \{ X \in \mathcal{P}(A) : \exists a \in A\, X = [a]\} \), with the projection \(\pi \colon A \to A/{\sim }\), \(a \mapsto [a]\). A partition of \(A\) is a set of nonempty, pairwise disjoint subsets of \(A\) whose union is \(A\).

006Y Proposition 3.3.8

Let \(A\) be a set. The map \({\sim } \mapsto A/{\sim }\) is a bijection from the set of equivalence relations on \(A\) to the set of partitions of \(A\). Its inverse sends a partition \(\Pi \) to the relation “\(x\) and \(y\) lie in the same element of \(\Pi \)”.

Proof â–¼

If \(\sim \) is an equivalence relation, the classes are nonempty (\(a \in [a]\)) and cover \(A\). If \(z \in [a] \cap [b]\), then \(z \sim a\) and \(z \sim b\), so \(a \sim b\) by symmetry and transitivity, and then \([a] = [b]\). So \(A/{\sim }\) is a partition. Conversely, the relation defined by a partition \(\Pi \) is clearly an equivalence relation whose classes are the elements of \(\Pi \), and \(x \sim y\) if and only if \(x\) and \(y\) lie in the same class of \(\sim \). So the two constructions are inverse to each other.

006Z Proposition 3.3.9

Let \(\sim \) be an equivalence relation on \(A\) and \(f \colon A \to B\) a map such that \(a \sim a'\) implies \(f(a) = f(a')\). There is a unique map \(\bar f \colon A/{\sim } \to B\) with \(\bar f \circ \pi = f\).

Proof â–¼

Uniqueness holds because \(\pi \) is surjective. Put \(\bar f = \{ (X, b) \in (A/{\sim }) \times B : \exists a \in X\, f(a) = b\} \). Every class \(X\) is nonempty, and all its elements have the same image under \(f\), so \(\bar f\) is a function, and \(\bar f([a]) = f(a)\).

0070 Definition 3.3.10

A partial order on \(A\) is a relation \(\leq \) that is reflexive, antisymmetric and transitive; it is total if \(x \leq y\) or \(y \leq x\) for all \(x, y\). We write \(x {\lt} y\) for \(x \leq y \wedge x \neq y\). A chain is a totally ordered subset. For \(X \subseteq A\), an upper bound of \(X\) is an \(a \in A\) with \(x \leq a\) for all \(x \in X\); a least upper bound or supremum is an upper bound below all upper bounds. An element \(m\) is maximal if there is no \(x\) with \(m {\lt} x\), and greatest if \(x \leq m\) for all \(x\). A well-order is a total order in which every nonempty subset has a least element. An isomorphism of ordered sets is a bijection \(f\) with \(x \leq y \iff f(x) \leq f(y)\). For \(a \in A\), the initial segment determined by \(a\) is \(A_{{\lt}a} = \{ x \in A : x {\lt} a\} \).

0071 Counterexample 3.3.11

A maximal element need not be greatest, and a greatest element need not exist. In \(\{ \{ 0\} , \{ 1\} \} \), ordered by inclusion, both elements are maximal and there is no greatest element.

0072 Lemma 3.3.12

Let \(W\) be a well-ordered set and \(f \colon W \to W\) a strictly increasing map. Then \(f(w) \geq w\) for all \(w \in W\). Consequently, \(W\) is not isomorphic to any initial segment \(W_{{\lt}a}\), and the only isomorphism \(W \to W\) is the identity. If two well-ordered sets are isomorphic, the isomorphism is unique.

Proof â–¼

If \(\{ w : f(w) {\lt} w\} \) is nonempty, let \(w\) be its least element. Then \(f(w) {\lt} w\), so \(f(f(w)) {\lt} f(w)\), and \(f(w)\) is a smaller element of the same set; contradiction. An isomorphism \(f \colon W \to W_{{\lt}a}\) would give a strictly increasing \(W \to W\) with \(f(a) {\lt} a\). If \(f, g \colon W \to W'\) are isomorphisms, \(g^{-1} \circ f\) and \(f^{-1} \circ g\) are strictly increasing, so \(f(w) \geq g(w)\) and \(g(w) \geq f(w)\) for all \(w\).
