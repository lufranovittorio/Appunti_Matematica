10.4 Quadratic residues and quadratic reciprocity02Y6

Complete. This chapter is written; its proofs await independent checking.

Which numbers are squares modulo a prime \(p\)? Modulo \(p = 2\) every number is a square, so let \(p\) be odd. The squares of \(1, 2, \ldots , 10\) modulo \(11\) are \(1, 4, 9, 5, 3, 3, 5, 9, 4, 1\): exactly half of the nonzero residues, \(1, 3, 4, 5, 9\), are squares, each twice, as \(x^2 = (-x)^2\). The question has a surprisingly deep answer, the law of quadratic reciprocity, which Euler conjectured and Gauss first proved in 1796.

02Y7 Definition 10.4.1

Let \(p\) be an odd prime. An integer \(a\) with \(p \nmid a\) is a quadratic residue modulo \(p\) if \(x^2 \equiv a \pmod p\) has a solution, and a quadratic nonresidue otherwise. The Legendre symbol is

\[ \Bigl(\frac{a}{p}\Bigr) = \begin{cases} 1 & \text{if } p \nmid a \text{ and } a \text{ is a quadratic residue modulo } p, \\ -1 & \text{if } a \text{ is a quadratic nonresidue modulo } p, \\ 0 & \text{if } p \mid a. \end{cases} \]

By definition \((\frac{a}{p})\) depends only on \(a\) modulo \(p\). The following criterion of Euler reduces its computation to a power, and shows that it is multiplicative in \(a\).

02Y8 Proposition 10.4.2 Euler’s criterion

Let \(p\) be an odd prime.

  1. For every integer \(a\), \(\bigl(\frac{a}{p}\bigr) \equiv a^{(p-1)/2} \pmod p\).

  2. There are exactly \(\frac{p-1}{2}\) quadratic residues and \(\frac{p-1}{2}\) quadratic nonresidues among \(1, \ldots , p - 1\).

  3. \(\bigl(\frac{ab}{p}\bigr) = \bigl(\frac{a}{p}\bigr)\bigl(\frac{b}{p}\bigr)\) for all integers \(a, b\). So the product of two residues or of two nonresidues is a residue, and the product of a residue and a nonresidue is a nonresidue.

Proof â–¼

(1) If \(p \mid a\) both sides are \(\equiv 0\). Otherwise let \(y = a^{(p-1)/2}\). Then \(y^2 = a^{p-1} \equiv 1\) by Fermat’s theorem, so \(y \equiv \pm 1\), because \(y^2 - 1 = (y - 1)(y + 1)\) and \(\mathbb {F}_p\) is a field. By Proposition 10.3.11 with \(k = 2\) and \(d = \gcd (2, p - 1) = 2\), \(a\) is a quadratic residue if and only if \(y \equiv 1\). So \(y \equiv 1\) when \((\frac{a}{p}) = 1\) and \(y \equiv -1\) when \((\frac{a}{p}) = -1\).

(2) The squares form a subgroup of index \(d = 2\) of \(U_p\), by Proposition 10.3.11.

(3) By (1), both sides are congruent to \((ab)^{(p-1)/2} = a^{(p-1)/2}b^{(p-1)/2}\) modulo \(p\). Both sides lie in \(\{ -1, 0, 1\} \), and distinct elements of this set are not congruent modulo \(p \geq 3\); so they are equal.

By (3), to compute \((\frac{a}{p})\) it suffices to factor \(a\) and know \((\frac{-1}{p})\), \((\frac{2}{p})\) and \((\frac{q}{p})\) for odd primes \(q\). The first is immediate.

02Y9 Corollary 10.4.3

For an odd prime \(p\), \(\bigl(\frac{-1}{p}\bigr) = (-1)^{(p-1)/2}\): the congruence \(x^2 \equiv -1 \pmod p\) is solvable if and only if \(p \equiv 1 \pmod4\).

Proof â–¼

By Euler’s criterion \((\frac{-1}{p}) \equiv (-1)^{(p-1)/2} \pmod p\), and both sides are \(\pm 1\). The exponent \((p - 1)/2\) is even exactly when \(p \equiv 1 \pmod4\).

For \(p \equiv 1 \pmod4\) an explicit square root of \(-1\) is \(\bigl(\frac{p-1}{2}\bigr)!\) (Exercise 10.9.3); for instance modulo \(13\), \(6! = 720 \equiv 5\) and \(5^2 = 25 \equiv -1\). The corollary already has a pleasant consequence, an analogue of Euclid’s theorem for a single residue class.

02YA Proposition 10.4.4

There are infinitely many primes \(p \equiv 1 \pmod4\).

Proof â–¼

Let \(p_1, \ldots , p_k\) be primes and \(N = (2p_1 \cdots p_k)^2 + 1\). Let \(q\) be a prime dividing \(N\) (Theorem 4.5.5). Then \(q\) is odd, as \(N\) is odd, and \(x = 2p_1 \cdots p_k\) satisfies \(x^2 \equiv -1 \pmod q\); by Corollary 10.4.3, \(q \equiv 1 \pmod4\). And \(q \neq p_i\), since \(p_i \mid N - 1\). So no finite list contains all primes \(\equiv 1 \pmod4\).

More generally, Dirichlet’s theorem says that every residue class \(a \bmod n\) with \(\gcd (a, n) = 1\) contains infinitely many primes; its proof requires analysis [Ser73]. For the class of \(3\) modulo \(4\) see Exercise 10.9.1.

To compute \((\frac{2}{p})\) and \((\frac{q}{p})\) we use a lemma of Gauss, which counts signs in the proof of Euler’s criterion.

02YB Lemma 10.4.5 Gauss’s lemma

Let \(p\) be an odd prime, \(h = \frac{p-1}{2}\), and \(p \nmid a\). Let \(\mu \) be the number of \(k \in \{ 1, \ldots , h\} \) for which the least non-negative residue of \(ka\) modulo \(p\) is greater than \(\frac{p}{2}\). Then \(\bigl(\frac{a}{p}\bigr) = (-1)^\mu \).

Proof â–¼

For \(1 \leq k \leq h\), let \(t_k\) be the least non-negative residue of \(ka\); it is not \(0\), as \(p \nmid ka\). Put \(r_k = t_k\) and \(\varepsilon _k = 1\) if \(t_k {\lt} p/2\), and \(r_k = p - t_k\) and \(\varepsilon _k = -1\) if \(t_k {\gt} p/2\). Then \(ka \equiv \varepsilon _kr_k \pmod p\) with \(r_k \in \{ 1, \ldots , h\} \), and exactly \(\mu \) of the signs \(\varepsilon _k\) are \(-1\). The \(r_k\) are distinct: if \(r_k = r_l\), then \(ka \equiv \pm la\), so \(k \equiv \pm l \pmod p\) (cancel the unit \(a\)); since \(1 \leq k, l \leq h\) we have \(0 {\lt} k + l {\lt} p\) and \(|k - l| {\lt} p\), so \(k \equiv -l\) is impossible and \(k = l\). Hence \(\{ r_1, \ldots , r_h\} = \{ 1, \ldots , h\} \), and multiplying the congruences \(ka \equiv \varepsilon _kr_k\) for \(k = 1, \ldots , h\) gives

\[ a^h\, h! \equiv (-1)^\mu \, h! \pmod p . \]

Since \(h!\) is prime to \(p\), \(a^h \equiv (-1)^\mu \), and Euler’s criterion gives \((\frac{a}{p}) \equiv (-1)^\mu \); both sides are \(\pm 1\), so they are equal.

02YC Example 10.4.6

For \(p = 11\), \(h = 5\) and \(a = 3\): the residues of \(3, 6, 9, 12, 15\) are \(3, 6, 9, 1, 4\), of which \(6\) and \(9\) exceed \(5.5\). So \(\mu = 2\) and \((\frac{3}{11}) = 1\); indeed \(5^2 = 25 \equiv 3\). For \(a = 2\): the residues \(2, 4, 6, 8, 10\) include \(6, 8, 10\) above \(5.5\), so \(\mu = 3\) and \((\frac{2}{11}) = -1\), in agreement with the list of squares modulo \(11\) above.

02YD Proposition 10.4.7 The second supplementary law

For an odd prime \(p\), \(\bigl(\frac{2}{p}\bigr) = (-1)^{(p^2-1)/8}\): the number \(2\) is a quadratic residue modulo \(p\) if and only if \(p \equiv \pm 1 \pmod8\).

Proof â–¼

For \(a = 2\) the numbers \(2k\), \(1 \leq k \leq h\), already lie in \(\{ 1, \ldots , p - 1\} \), and \(2k {\gt} p/2\) exactly when \(k {\gt} p/4\). So \(\mu = h - \lfloor p/4\rfloor \). Writing \(p = 8m + r\) with \(r \in \{ 1, 3, 5, 7\} \):

\[ \begin{aligned} r = 1 & : \quad h = 4m, \ \lfloor p/4\rfloor = 2m, \ \mu = 2m; \qquad & r = 3 & : \quad h = 4m + 1, \ \lfloor p/4\rfloor = 2m, \ \mu = 2m + 1; \\ r = 5 & : \quad h = 4m + 2, \ \lfloor p/4\rfloor = 2m + 1, \ \mu = 2m + 1; \qquad & r = 7 & : \quad h = 4m + 3, \ \lfloor p/4\rfloor = 2m + 1, \ \mu = 2m + 2. \end{aligned} \]

So \(\mu \) is even exactly for \(p \equiv \pm 1 \pmod8\), and Gauss’s lemma gives the first assertion in the form “\((\frac{2}{p}) = 1\) if and only if \(p \equiv \pm 1 \pmod8\)”. Finally \((p^2 - 1)/8\) is even for \(p = 8m \pm 1\), where it equals \(8m^2 \pm 2m\), and odd for \(p = 8m \pm 3\), where it equals \(8m^2 \pm 6m + 1\).

For odd \(a\) the count \(\mu \) in Gauss’s lemma can be expressed through integer parts, which is the key to the reciprocity law.

02YE Lemma 10.4.8 Eisenstein

Let \(p\) be an odd prime, \(h = \frac{p-1}{2}\), and \(a\) an odd integer with \(p \nmid a\). Then, with \(\mu \) as in Gauss’s lemma,

\[ \mu \equiv \sum _{k=1}^{h}\Bigl\lfloor \frac{ka}{p}\Bigr\rfloor \pmod2, \qquad \text{so}\qquad \Bigl(\frac{a}{p}\Bigr) = (-1)^{\sum _{k=1}^{h}\lfloor ka/p\rfloor } . \]
Proof â–¼

Divide: \(ka = p\lfloor ka/p\rfloor + t_k\) with \(t_k\) the least non-negative residue. Let \(b_1, \ldots , b_\mu \) be the \(t_k\) greater than \(p/2\) and \(c_1, \ldots , c_\lambda \) the others (\(\lambda + \mu = h\)). In the proof of Gauss’s lemma we saw that the numbers \(c_1, \ldots , c_\lambda , p - b_1, \ldots , p - b_\mu \) are \(1, \ldots , h\) in some order. Summing the divisions and this rearrangement,

\[ a\sum _{k=1}^{h}k = p\sum _{k=1}^{h}\Bigl\lfloor \frac{ka}{p}\Bigr\rfloor + \sum _ib_i + \sum _ic_i, \qquad \sum _{k=1}^{h}k = \sum _ic_i + \mu p - \sum _ib_i . \]

Subtracting, \((a - 1)\sum _kk = p\sum _k\lfloor ka/p\rfloor - \mu p + 2\sum _ib_i\). Modulo \(2\), the left side is \(0\) because \(a\) is odd, and \(p \equiv 1\); so \(0 \equiv \sum _k\lfloor ka/p\rfloor - \mu \). The formula for the symbol is Gauss’s lemma.

02YF Theorem 10.4.9 Law of quadratic reciprocity

Let \(p \neq q\) be odd primes. Then

\[ \Bigl(\frac{p}{q}\Bigr)\Bigl(\frac{q}{p}\Bigr) = (-1)^{\frac{p-1}{2}\cdot \frac{q-1}{2}} . \]

That is, \((\frac{p}{q}) = (\frac{q}{p})\) unless \(p \equiv q \equiv 3 \pmod4\), in which case \((\frac{p}{q}) = -(\frac{q}{p})\).

Proof â–¼

Let \(h = \frac{p-1}{2}\) and \(h^{\prime } = \frac{q-1}{2}\), and count the points with integer coordinates in the rectangle \(R = \{ (x, y) : 1 \leq x \leq h, \ 1 \leq y \leq h^{\prime }\} \); there are \(hh^{\prime }\) of them. None lies on the line \(py = qx\): if \(py = qx\) with \(1 \leq x \leq h\), then \(p \mid qx\), so \(p \mid x\) by Euclid’s lemma, which is impossible for \(0 {\lt} x {\lt} p\).

The points of \(R\) with \(py {\lt} qx\), that is, below the line: for fixed \(x \in \{ 1, \ldots , h\} \) these are the \(y\) with \(1 \leq y {\lt} qx/p\), and all such \(y\) satisfy \(y \leq h^{\prime }\), since \(qx/p {\lt} q/2\) and so \(y {\lt} q/2\), that is \(y \leq (q - 1)/2\). Their number is \(\lfloor qx/p\rfloor \) (as \(qx/p\) is not an integer). So there are \(\sum _{x=1}^{h}\lfloor qx/p\rfloor \) points below the line, and symmetrically \(\sum _{y=1}^{h^{\prime }}\lfloor py/q\rfloor \) points above it. Hence

\[ \sum _{x=1}^{h}\Bigl\lfloor \frac{qx}{p}\Bigr\rfloor + \sum _{y=1}^{h^{\prime }}\Bigl\lfloor \frac{py}{q}\Bigr\rfloor = hh^{\prime } . \]

By Eisenstein’s lemma (Lemma 10.4.8), applied to the odd number \(q\) modulo \(p\) and to \(p\) modulo \(q\), the left side is the sum of the exponents in \((\frac{q}{p}) = (-1)^{\sum \lfloor qx/p\rfloor }\) and \((\frac{p}{q}) = (-1)^{\sum \lfloor py/q\rfloor }\). So \((\frac{p}{q})(\frac{q}{p}) = (-1)^{hh^{\prime }}\). Finally \(hh^{\prime }\) is odd if and only if both \(h\) and \(h^{\prime }\) are odd, that is, \(p \equiv q \equiv 3 \pmod4\).

To see the proof at work, take \(p = 11\) and \(q = 7\), so \(h = 5\) and \(h^{\prime } = 3\). The rectangle contains the \(15\) points \((x, y)\) with \(1 \leq x \leq 5\) and \(1 \leq y \leq 3\). Below the line \(11y = 7x\) lie, for \(x = 1, \ldots , 5\), respectively \(\lfloor 7/11\rfloor , \lfloor 14/11\rfloor , \ldots = 0, 1, 1, 2, 3\) points, \(7\) in all; to the left of it lie, for \(y = 1, 2, 3\), respectively \(\lfloor 11/7\rfloor , \lfloor 22/7\rfloor , \lfloor 33/7\rfloor = 1, 3, 4\) points, \(8\) in all. So \((\frac{7}{11}) = (-1)^7 = -1\) and \((\frac{11}{7}) = (-1)^8 = 1\), and their product is \(-1 = (-1)^{15}\). Directly: \((\frac{11}{7}) = (\frac{4}{7}) = 1\), and the squares modulo \(11\) are \(1, 3, 4, 5, 9\), which do not include \(7\).

Together with Euler’s criterion and the two supplementary laws, Corollary 10.4.3 and Proposition 10.4.7, reciprocity computes every Legendre symbol quickly, by repeatedly reducing the top modulo the bottom, factoring, and flipping.

02YG Example 10.4.10

  1. Is \(30\) a square modulo the prime \(103\)? \((\frac{30}{103}) = (\frac{2}{103})(\frac{3}{103})(\frac{5}{103})\). As \(103 \equiv 7 \pmod8\), \((\frac{2}{103}) = 1\). As \(103 \equiv 3 \pmod4\) and \(3 \equiv 3 \pmod4\), \((\frac{3}{103}) = -(\frac{103}{3}) = -(\frac{1}{3}) = -1\). As \(5 \equiv 1 \pmod4\), \((\frac{5}{103}) = (\frac{103}{5}) = (\frac{3}{5}) = -1\), the squares modulo \(5\) being \(1\) and \(4\). So \((\frac{30}{103}) = 1 \cdot (-1) \cdot (-1) = 1\): \(30\) is a square modulo \(103\). Indeed \(37^2 = 1369 = 13 \cdot 103 + 30\). Note that reciprocity decides the question without finding the square root.

  2. For which primes is \(3\) a square? For \(p {\gt} 3\), \((\frac{3}{p}) = (-1)^{(p-1)/2}(\frac{p}{3})\), and \((\frac{p}{3}) = 1\) if and only if \(p \equiv 1 \pmod3\). So \((\frac{3}{p}) = 1\) if and only if \(p \equiv 1 \pmod4\) and \(p \equiv 1 \pmod3\), or \(p \equiv 3 \pmod4\) and \(p \equiv 2 \pmod3\); that is, by the Chinese remainder theorem, if and only if \(p \equiv \pm 1 \pmod{12}\).

  3. For which primes is \(5\) a square? For \(p \neq 2, 5\), \((\frac{5}{p}) = (\frac{p}{5})\), which is \(1\) if and only if \(p \equiv \pm 1 \pmod5\). This is the remarkable feature of the law: whether \(q\) is a square modulo \(p\) depends only on \(p\) modulo \(4q\), although the squares modulo \(p\) seem to have nothing to do with \(q\).

02YH Remark 10.4.11

Gauss called the law the theorema aureum and gave several proofs of it; the one above, by counting lattice points, is due to Eisenstein. Another proof uses Gauss sums: the sum \(g = \sum _{a=1}^{q-1}(\frac{a}{q})\zeta ^a\), with \(\zeta \) a primitive \(q\)-th root of unity, satisfies \(g^2 = (-1)^{(q-1)/2}q\), so the cyclotomic field \(\mathbb {Q}(\zeta )\) of Theorem 9.8.2 contains a square root of \(\pm q\), and comparing \(g^p\) with \(g\) modulo \(p\) gives the law [IR90]. This is the beginning of a Galois theoretic explanation, in which \((\frac{p}{q})\) describes how the automorphism \(\zeta \mapsto \zeta ^p\) acts on that square root; its generalisation to all abelian extensions of number fields is class field theory.
