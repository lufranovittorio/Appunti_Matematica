50.2 Affine algebraic sets and the Zariski topology01JG

Complete. This chapter is written; its proofs await independent checking.

01JH Definition 50.2.1

Affine \(n\)-space is \(\mathbb {A}^n = k^n\). For a subset \(T \subseteq A = k[x_1, \ldots , x_n]\) put \(Z(T) = \{ a \in \mathbb {A}^n : f(a) = 0 \text{ for all } f \in T\} \), and for \(Y \subseteq \mathbb {A}^n\) put \(I(Y) = \{ f \in A : f(a) = 0 \text{ for all } a \in Y\} \). The sets \(Z(T)\) are the algebraic sets.

01JI Proposition 50.2.2

  1. \(Z(0) = \mathbb {A}^n\), \(Z(1) = \emptyset \), \(Z(T) = Z((T))\), and \(Z(I) \cup Z(J) = Z(IJ) = Z(I \cap J)\) and \(\bigcap _\alpha Z(I_\alpha ) = Z(\sum _\alpha I_\alpha )\) for ideals. So the algebraic sets are the closed sets of a topology on \(\mathbb {A}^n\), the Zariski topology.

  2. \(I(Y)\) is a radical ideal, \(Z(I(Y)) = \overline Y\), and \(I(Z(J)) = \sqrt J\) for every ideal \(J\).

  3. \(Y \mapsto I(Y)\) and \(J \mapsto Z(J)\) are mutually inverse inclusion-reversing bijections between closed subsets of \(\mathbb {A}^n\) and radical ideals of \(A\). Under them, points correspond to maximal ideals.

Proof â–¼

(1) If \(a \notin Z(I) \cup Z(J)\), pick \(f \in I\), \(g \in J\) with \(f(a) \neq 0 \neq g(a)\); then \(fg \in IJ\) does not vanish at \(a\). So \(Z(IJ) \subseteq Z(I) \cup Z(J) \subseteq Z(I \cap J) \subseteq Z(IJ)\). The rest is immediate. (2) If \(f^m\) vanishes on \(Y\), so does \(f\), so \(I(Y)\) is radical. \(Z(I(Y))\) is a closed set containing \(Y\), and if \(Z(J) \supseteq Y\) then \(J \subseteq I(Y)\), so \(Z(J) \supseteq Z(I(Y))\); hence \(Z(I(Y)) = \overline Y\). The equality \(I(Z(J)) = \sqrt J\) is the Nullstellensatz (Theorem 13.7.2(3)), the inclusion \(\supseteq \) being clear. (3) follows from (2), and points correspond to maximal ideals by Theorem 13.7.2(1).

01JJ Definition 50.2.3

A topological space \(Y\) is irreducible if it is nonempty and not the union of two proper closed subsets; equivalently, every nonempty open subset is dense. It is Noetherian if every descending chain of closed subsets is eventually constant.

01JK Proposition 50.2.4

  1. A closed set \(Y \subseteq \mathbb {A}^n\) is irreducible if and only if \(I(Y)\) is prime.

  2. \(\mathbb {A}^n\), and every subspace of it, is Noetherian.

  3. Every Noetherian space \(Y\) is a finite union \(Y = Y_1 \cup \cdots \cup Y_r\) of irreducible closed subsets, unique up to order if \(Y_i \not\subseteq Y_j\) for \(i \neq j\); the \(Y_i\) are the irreducible components.

Proof â–¼

(1) If \(Y = Y_1 \cup Y_2\) with \(Y_i\) proper closed, pick \(f_i \in I(Y_i) \setminus I(Y)\) by Proposition 50.2.2(3). Then \(f_1f_2 \in I(Y)\), so \(I(Y)\) is not prime. Conversely, if \(fg \in I(Y)\), then \(Y = (Y \cap Z(f)) \cup (Y \cap Z(g))\), so \(Y \subseteq Z(f)\) or \(Y \subseteq Z(g)\) by irreducibility. (Also \(Y \neq \emptyset \) if and only if \(I(Y) \neq A\).) (2) A descending chain of closed sets gives an ascending chain of ideals, which stabilises because \(A\) is Noetherian (Theorem 13.5.3). For a subspace, its closed sets are traces of closed sets of \(\mathbb {A}^n\). (3) If some closed subset is not such a finite union, choose a minimal one \(Y'\), which exists by the Noetherian property. It is not irreducible, so \(Y' = Y'_1 \cup Y'_2\) with smaller closed sets, which are finite unions, a contradiction. For uniqueness, if \(Y_1 \cup \cdots \cup Y_r = Y'_1 \cup \cdots \cup Y'_s\) are irredundant, then \(Y'_1 = \bigcup _i(Y'_1 \cap Y_i)\) forces \(Y'_1 \subseteq Y_i\) for some \(i\), and similarly \(Y_i \subseteq Y'_j\), so \(j = 1\) and \(Y'_1 = Y_i\); induct.

01JL Definition 50.2.5

An affine variety is an irreducible closed subset \(Y \subseteq \mathbb {A}^n\) with the induced topology. Its coordinate ring is \(A(Y) = k[x_1, \ldots , x_n]/I(Y)\), a finitely generated \(k\)-algebra that is a domain. A quasi-affine variety is a nonempty open subset of an affine variety.

01JM Example 50.2.6

  1. \(\mathbb {A}^n\) is an affine variety, since \(I(\mathbb {A}^n) = 0\) is prime (\(k\) is infinite, so a polynomial vanishing everywhere is \(0\)).

  2. If \(f\) is irreducible, then \((f)\) is prime because \(k[x_1, \ldots , x_n]\) is a unique factorisation domain (Theorem 8.6.11), so the hypersurface \(Z(f)\) is an affine variety with \(I(Z(f)) = (f)\).

  3. The closed subsets of \(\mathbb {A}^1\) are \(\mathbb {A}^1\) and the finite sets, since \(k[x]\) is a principal ideal domain. So the Zariski topology is not Hausdorff: any two nonempty open sets meet.

  4. The Zariski topology on \(\mathbb {A}^2\) is not the product topology on \(\mathbb {A}^1 \times \mathbb {A}^1\). The closed sets of the product topology are the finite unions of points, horizontal and vertical lines and \(\mathbb {A}^2\), whereas the parabola \(Z(y - x^2)\) is also Zariski closed.

  5. The twisted cubic \(Y = \{ (t, t^2, t^3)\} = Z(y - x^2, z - x^3) \subseteq \mathbb {A}^3\) is an affine variety with \(A(Y) \cong k[x, y, z]/(y - x^2, z - x^3) \cong k[t]\), a domain.
