28.7 Independence and the Borel–Cantelli lemmas0360

Complete. This chapter is written; its proofs await independent checking.

Measure theory is also the language of probability. A probability space is a measure space \((\Omega , \mathcal{F}, P)\) with \(P(\Omega ) = 1\); its measurable sets are called events, measurable functions are random variables, and “almost everywhere” becomes almost surely. A typical question asks whether infinitely many of a sequence of events happen. For events \(A_1, A_2, \ldots \) the event “\(A_k\) happens for infinitely many \(k\)” is

\[ \limsup _kA_k = \bigcap _{n \geq 1}\bigcup _{k \geq n}A_k = \{ \omega : \omega \in A_k \text{ for infinitely many } k\} , \]

and its complement is \(\liminf _kA_k^c = \bigcup _n\bigcap _{k \geq n}A_k^c\), “from some index on, no \(A_k\) happens”. The two Borel–Cantelli lemmas decide, in many cases, whether \(\limsup _kA_k\) has probability \(0\) or \(1\). The first needs nothing; the second needs independence, which we now define.

0361 Definition 28.7.1

Events \(A_1, A_2, \ldots \) (finitely or countably many) in a probability space are independent if

\[ P(A_{k_1} \cap A_{k_2} \cap \cdots \cap A_{k_m}) = P(A_{k_1})P(A_{k_2}) \cdots P(A_{k_m}) \]

for all \(m\) and all distinct indices \(k_1, \ldots , k_m\).

The condition must be imposed on all subfamilies, not only on pairs.

0362 Example 28.7.2

Toss two fair coins: \(\Omega = \{ HH, HT, TH, TT\} \), each point with probability \(\frac14\). Let \(A\) = “the first coin shows heads”, \(B\) = “the second coin shows heads”, \(C\) = “the two coins agree”. Each event has probability \(\frac12\), and each intersection of two of them has probability \(\frac14\); so they are pairwise independent. But \(A \cap B \cap C = \{ HH\} \) has probability \(\frac14 \neq \frac18\): if two of the events happen, so does the third.

0363 Lemma 28.7.3

If \(A_1, A_2, \ldots \) are independent, so are the events obtained by replacing any of the \(A_k\) by their complements.

Proof â–¼

It suffices to replace one event, say \(A_1\), by \(A_1^c\); replacing several is done one at a time. Let \(k_2, \ldots , k_m\) be distinct indices different from \(1\) and \(B = A_{k_2} \cap \cdots \cap A_{k_m}\) (with \(B = \Omega \) if \(m = 1\)). Then \(P(A_1^c \cap B) = P(B) - P(A_1 \cap B) = P(B) - P(A_1)P(B) = P(A_1^c)P(B)\), and \(P(B)\) is the product of the \(P(A_{k_j})\). Intersections not involving \(A_1^c\) are unchanged.

The basic example of independence lives on \([0, 1)\) with Lebesgue measure: the binary digits of a number chosen at random behave like independent tosses of a fair coin. For \(x \in [0, 1)\) and \(k \geq 1\) let

\[ d_k(x) = \lfloor 2^kx\rfloor - 2\lfloor 2^{k-1}x\rfloor \in \{ 0, 1\} , \]

the \(k\)-th digit of the binary expansion \(x = \sum _kd_k(x)2^{-k}\) that does not end with infinitely many \(1\)s. For \(K \geq 1\) the integer \(\lfloor 2^Kx\rfloor \) has binary digits \(d_1(x), \ldots , d_K(x)\), so \(d_1(x) = \delta _1, \ldots , d_K(x) = \delta _K\) holds exactly on the interval \([N2^{-K}, (N + 1)2^{-K})\) with \(N = \sum _{k \leq K}\delta _k2^{K-k}\), of length \(2^{-K}\). Call a set \(E \subseteq [0, 1)\) determined by a finite set \(S\) of positions if whether \(x \in E\) depends only on the digits \(d_k(x)\), \(k \in S\).

0364 Lemma 28.7.4

  1. For a finite set \(S\) of positions and prescribed digits \(\delta _k \in \{ 0, 1\} \), \(k \in S\), the set \(\{ x : d_k(x) = \delta _k \text{ for } k \in S\} \) has measure \(2^{-|S|}\).

  2. If \(E_1, \ldots , E_m\) are determined by pairwise disjoint finite sets of positions \(S_1, \ldots , S_m\), then \(\lambda (E_1 \cap \cdots \cap E_m) = \lambda (E_1) \cdots \lambda (E_m)\). Consequently, events \(E_1, E_2, \ldots \) determined by pairwise disjoint finite sets of positions are independent; in particular the events \(\{ d_k = 1\} \), \(k \geq 1\), are independent of probability \(\frac12\).

  3. If \(g_i = G_i\bigl((d_k)_{k \in S_i}\bigr)\) for functions \(G_i\) of finitely many digits and pairwise disjoint \(S_1, \ldots , S_m\), then \(\int _0^1g_1 \cdots g_m\, d\lambda = \prod _i\int _0^1g_i\, d\lambda \).

Proof â–¼

(1) Let \(K = \max S\) (the case \(S = \emptyset \) is trivial). The set is the disjoint union, over the \(2^{K - |S|}\) choices of the digits at the positions in \(\{ 1, \ldots , K\} \setminus S\), of intervals of length \(2^{-K}\), so its measure is \(2^{K - |S|}2^{-K}\).

(2) A set determined by \(S_i\) is a disjoint union of \(n_i\) sets as in (1), one for each admissible pattern of digits on \(S_i\), so \(\lambda (E_i) = n_i2^{-|S_i|}\). With \(S = S_1 \cup \cdots \cup S_m\), the intersection \(E_1 \cap \cdots \cap E_m\) is the disjoint union of the sets of (1) for the patterns on \(S\) whose restriction to each \(S_i\) is admissible for \(E_i\); there are \(n_1 \cdots n_m\) of them, so its measure is \(n_1 \cdots n_m2^{-|S|} = \prod _in_i2^{-|S_i|}\). A subfamily of the \(E_k\) is again determined by disjoint sets of positions, which gives independence.

(3) Each \(g_i\) is a finite linear combination of indicator functions of sets determined by \(S_i\); expand the product and apply (2) to each term.

0365Lean Theorem 28.7.5 Borel–Cantelli lemmas

Let \(A_1, A_2, \ldots \) be events in a probability space.

  1. If \(\sum _kP(A_k) {\lt} \infty \), then \(P(\limsup _kA_k) = 0\): almost surely only finitely many \(A_k\) happen.

  2. If the \(A_k\) are independent and \(\sum _kP(A_k) = \infty \), then \(P(\limsup _kA_k) = 1\): almost surely infinitely many \(A_k\) happen.

Proof â–¼

(1) For every \(n\), \(\limsup _kA_k \subseteq \bigcup _{k \geq n}A_k\), so \(P(\limsup _kA_k) \leq \sum _{k \geq n}P(A_k)\), the tail of a convergent series, which tends to \(0\) as \(n \to \infty \).

(2) We show that the complement \(\bigcup _n\bigcap _{k \geq n}A_k^c\) is null; it suffices to show \(P(\bigcap _{k \geq n}A_k^c) = 0\) for each \(n\). For \(N \geq n\), the events \(A_k^c\) are independent (Lemma 28.7.3), and \(1 - t \leq e^{-t}\) for real \(t\) (the exponential lies above its tangent line at \(0\)), so

\[ P\Bigl(\bigcap _{k = n}^NA_k^c\Bigr) = \prod _{k = n}^N\bigl(1 - P(A_k)\bigr) \leq \exp \Bigl(-\sum _{k = n}^NP(A_k)\Bigr) \longrightarrow 0 \qquad (N \to \infty ). \]

These sets decrease in \(N\) to \(\bigcap _{k \geq n}A_k^c\), so by continuity of measures (Proposition 28.2.4) its probability is \(0\).

For independent events \(\limsup _kA_k\) therefore has probability \(0\) or \(1\), never anything in between: a first instance of a zero-one law. The first lemma was already used, without the name, in the proof of Proposition 28.6.3(2).

0366 Counterexample 28.7.6

Independence cannot be dropped in (2). On \([0, 1)\) let \(A_k = [0, 1/k)\). Then \(\sum _k\lambda (A_k) = \sum _k1/k = \infty \), but the sets decrease, so \(\limsup _kA_k = \bigcap _kA_k = \{ 0\} \), a null set. The events are far from independent: \(\lambda (A_j \cap A_k) = 1/\max (j, k)\), not \(1/(jk)\). Even more simply, \(A_k = A\) for all \(k\) with \(\lambda (A) = \frac12\) gives \(\limsup _kA_k = A\), of probability \(\frac12\).

0367 Example 28.7.7

Every pattern appears infinitely often. Fix a block \(\beta = (\beta _1, \ldots , \beta _m)\) of binary digits. For \(j \geq 0\) let \(B_j\) be the event that the digits at positions \(jm + 1, \ldots , jm + m\) form the block \(\beta \). These events are determined by the disjoint sets of positions \(\{ jm + 1, \ldots , jm + m\} \), so they are independent, each of probability \(2^{-m}\) (Lemma 28.7.4). Since \(\sum _j2^{-m} = \infty \), almost every \(x \in [0, 1)\) lies in infinitely many \(B_j\). There are countably many blocks, so for almost every \(x\) every finite block of digits occurs infinitely often in the binary expansion of \(x\). (Encoding letters by blocks of digits, this is the “infinite monkey theorem”: a random infinite text contains every book infinitely often.)

The probability of a long block is small, and this limits how long the runs of \(1\)s in a random expansion can be. Let \(R_n(x)\) be the length of the run of \(1\)s starting at position \(n\): the largest \(r \geq 0\) with \(d_n(x) = \cdots = d_{n+r-1}(x) = 1\), which is finite because the expansion does not end with infinitely many \(1\)s.

0368 Proposition 28.7.8 Long runs

For almost every \(x \in [0, 1)\), \(\displaystyle \limsup _{n \to \infty }\frac{R_n(x)}{\log _2n} = 1\).

Proof â–¼

Upper bound. For \(r {\gt} 0\), \(R_n \geq r\) means that the \(\lceil r\rceil \) digits from position \(n\) on are \(1\), so \(\lambda (R_n \geq r) = 2^{-\lceil r\rceil } \leq 2^{-r}\) by Lemma 28.7.4(1). For \(\varepsilon {\gt} 0\) and \(r = (1 + \varepsilon )\log _2n\) this is at most \(n^{-1-\varepsilon }\), which is summable. By Theorem 28.7.5(1), for almost every \(x\) we have \(R_n(x) {\lt} (1 + \varepsilon )\log _2n\) for all large \(n\), so the \(\limsup \) is at most \(1 + \varepsilon \). Let \(\varepsilon = 1/m\), \(m = 1, 2, \ldots \), and discard countably many null sets.

Lower bound. We need independent events, so we use disjoint windows. For \(j \geq 2\) let \(L_j = \lfloor \log _2j\rfloor \geq 1\), \(s_2 = 1\) and \(s_{j+1} = s_j + L_j\), so that the windows \(W_j = \{ s_j, \ldots , s_j + L_j - 1\} \) are disjoint. Let \(E_j\) be the event that all digits in \(W_j\) are \(1\); then \(E_j \subseteq \{ R_{s_j} \geq L_j\} \), and \(\lambda (E_j) = 2^{-L_j} \geq 1/j\). The \(E_j\) are independent (Lemma 28.7.4(2)) and \(\sum _j1/j = \infty \), so by Theorem 28.7.5(2) almost every \(x\) lies in infinitely many \(E_j\). Now \(s_j = 1 + \sum _{2 \leq i {\lt} j}L_i \leq j\log _2j\), so \(\log _2s_j \leq \log _2j + \log _2\log _2j\), while \(L_j \geq \log _2j - 1\). Hence for such \(x\),

\[ \frac{R_{s_j}(x)}{\log _2s_j} \geq \frac{\log _2j - 1}{\log _2j + \log _2\log _2j} \]

for infinitely many \(j\), and the right side tends to \(1\). So the \(\limsup \) is at least \(1\).

So among the first \(n\) tosses of a fair coin one should expect a run of heads of length about \(\log _2n\), and no essentially longer one: about \(10\) in a thousand tosses, \(20\) in a million. This is a form of the Erdős–Rényi law of long runs; people asked to write down “random” sequences typically avoid such long runs, which is a simple way to detect fake randomness.

The most famous application of the first lemma is Borel’s theorem that almost every number is normal: its digits appear with the frequencies one expects. We prove the simplest case.

0369 Theorem 28.7.9 Borel’s normal number theorem

For almost every \(x \in [0, 1)\),

\[ \lim _{n \to \infty }\frac{d_1(x) + d_2(x) + \cdots + d_n(x)}{n} = \frac12 . \]
Proof â–¼

Let \(\rho _k = 2d_k - 1 \in \{ -1, 1\} \) and \(S_n = \rho _1 + \cdots + \rho _n\); the claim is \(S_n/n \to 0\) almost everywhere.

Step 1: the fourth moment. Expanding, \(\int _0^1S_n^4 = \sum _{i, j, k, l \leq n}\int _0^1\rho _i\rho _j\rho _k\rho _l\). Since \(\rho ^2 = 1\), a product \(\rho _i\rho _j\rho _k\rho _l\) in which some index occurs an odd number of times reduces to a product \(\rho _a\) or \(\rho _a\rho _b\) (\(a \neq b\)), whose integral is \(\int \rho _a \cdot \int \rho _b = 0\) by Lemma 28.7.4(3), because \(\int _0^1\rho _a = \frac12 - \frac12 = 0\). The remaining terms equal \(1\): either all four indices are equal (\(n\) terms), or they take two different values, each twice (\(3n(n - 1)\) terms: choose which of the three pairings of the four places carry equal indices, then the two values in order). So \(\int _0^1S_n^4 = n + 3n(n - 1) \leq 3n^2\).

Step 2: Borel–Cantelli. Let \(\varepsilon {\gt} 0\). By Markov’s inequality (Corollary 28.4.4(4)) applied to \(S_n^4\),

\[ \lambda \bigl(|S_n| \geq \varepsilon n\bigr) \leq \frac{1}{\varepsilon ^4n^4}\int _0^1S_n^4 \leq \frac{3}{\varepsilon ^4n^2}, \]

which is summable in \(n\). By Theorem 28.7.5(1), for almost every \(x\) we have \(|S_n(x)| {\lt} \varepsilon n\) for all large \(n\). Taking \(\varepsilon = 1/m\) for all \(m\) and discarding countably many null sets, \(S_n/n \to 0\) almost everywhere. Since \(d_k = (1 + \rho _k)/2\), the average of the first \(n\) digits is \(\frac12 + S_n/(2n) \to \frac12\).

036A Remark 28.7.10

The same argument, applied to the blocks of Example 28.7.7 and to expansions in any base \(b \geq 2\), shows that almost every real number is normal in every base: in base \(b\), each block of \(m\) digits occurs with limiting frequency \(b^{-m}\) [Bor09]. The theorem is the strong law of large numbers for fair coin tosses. It is a striking example of an existence proof by measure: almost all numbers are normal, yet it is not known whether \(\sqrt2\), \(e\) or \(\pi \) is normal in any base. Explicit normal numbers can be constructed, such as Champernowne’s number \(0.123456789101112\ldots \), obtained by writing the positive integers one after another, which is normal in base \(10\) [Cha33].

036B Example 28.7.11

Almost no number is very well approximable. By Dirichlet’s approximation theorem (Exercise 28.23.24), every irrational \(x\) has infinitely many approximations \(p/q\) with \(|x - p/q| {\lt} 1/q^2\). The exponent \(2\) cannot be improved for almost all \(x\). Fix \(\varepsilon {\gt} 0\) and for \(q \geq 1\) let \(A_q\) be the set of \(x \in [0, 1]\) for which some integer \(p\) satisfies \(|x - p/q| {\lt} q^{-2-\varepsilon }\). Only \(p = -1, 0, \ldots , q + 1\) can occur, so \(A_q\) is covered by \(q + 3\) intervals of length \(2q^{-2-\varepsilon }\), and \(\lambda (A_q) \leq 2(q + 3)q^{-2-\varepsilon } \leq 8q^{-1-\varepsilon }\), which is summable. By Theorem 28.7.5(1), almost every \(x\) lies in only finitely many \(A_q\), and hence has only finitely many approximations with \(|x - p/q| {\lt} q^{-2-\varepsilon }\). In particular the Liouville numbers, the irrational \(x\) that for every \(n\) have an approximation \(p/q\) with \(q \geq 2\) and \(|x - p/q| {\lt} q^{-n}\), form a null set. An example is \(\sum _{k \geq 1}10^{-k!}\): cutting the series after the term \(k = m\) gives \(p/q\) with \(q = 10^{m!}\) and error less than \(2 \cdot 10^{-(m+1)!} = 2q^{-(m+1)}\).
