43.4 Hermitian metrics and the Chern connection01ES

Complete. This chapter is written; its proofs await independent checking.

01ET Theorem 43.4.1

Let \(E\) be a holomorphic vector bundle with a Hermitian metric \(h\). There is a unique connection \(\nabla \) on \(E\), the Chern connection, that is metric and satisfies \(\nabla ^{0,1} = \bar\partial \). In a holomorphic frame with \(H_{ij} = h(e_i, e_j)\) one has \(\theta = \overline{H}^{-1}\partial \overline{H}\) and curvature \(F = \bar\partial \theta \), a \((1,1)\)-form with values in \(\operatorname {End}E\). For a line bundle with local weight \(h = e^{-\varphi }\) in a holomorphic frame, \(F = \partial \bar\partial \varphi \) and

\[ c_1(L) = \left[\frac{i}{2\pi }F\right] = \left[\frac{i}{2\pi }\partial \bar\partial \varphi \right] \in H^2(X; \mathbb {R}), \]

a class of type \((1,1)\).

Proof â–¼

Write \(\nabla = \nabla ^{1,0} + \nabla ^{0,1}\). The condition \(\nabla ^{0,1} = \bar\partial \) fixes the \((0,1)\)-part, and the metric condition \(d\, h(s, t) = h(\nabla s, t) + h(s, \nabla t)\) splits into its \((1,0)\)- and \((0,1)\)-parts, the first of which reads \(\partial h(s, t) = h(\nabla ^{1,0}s, t) + h(s, \bar\partial t)\) and determines \(\nabla ^{1,0}\); this proves uniqueness, and the resulting formula in a holomorphic frame, \(\theta = \overline{H}^{-1}\partial \overline{H}\), defines a connection with the two properties, which proves existence. Then \(F = d\theta + \theta \wedge \theta \) has no \((0,2)\)-part because \(\bar\partial ^2 = 0\) and \(\nabla ^{0,1} = \bar\partial \), and no \((2,0)\)-part by the metric condition; the formula \(F = \bar\partial \theta \) follows. For a line bundle \(H = e^{-\varphi }\) is real, so \(\theta = H^{-1}\partial H = \partial \log H = -\partial \varphi \) and \(F = \bar\partial \theta = -\bar\partial \partial \varphi = \partial \bar\partial \varphi \); the Chern class is computed by Chern–Weil theory (Proposition 38.2.4).

01EU Definition 43.4.2

A Hermitian line bundle \((L, h)\) is positive if the real \((1,1)\)-form \(\frac{i}{2\pi }F\) is positive definite, that is, if it is the fundamental form of a Hermitian metric on \(X\) (Chapter 45); \(L\) is positive if it admits such a metric. A line bundle is ample if a power of it gives an embedding of \(X\) in projective space (Chapter 48).

01EV Example 43.4.3

On \(\mathbb {C}\mathbb {P}^n\), give \(\mathcal{O}(-1)\) the metric induced from the standard Hermitian metric of \(\mathbb {C}^{n+1}\). On \(U_0 = \{ x_0 \neq 0\} \), with coordinates \(w_j = x_j/x_0\), the section \(\sigma (w) = (1, w_1, \ldots , w_n)\) is a holomorphic frame with \(h(\sigma , \sigma ) = 1 + |w|^2 = e^{-\varphi }\), so by Theorem 43.4.1 \(\frac{i}{2\pi }F = -\frac{i}{2\pi }\partial \bar\partial \log (1 + |w|^2) = -\omega _{FS}\), where \(\omega _{FS}\), the Fubini–Study form, is the global \((1,1)\)-form given on \(U_0\) by \(\frac{i}{2\pi }\partial \bar\partial \log (1 + |w|^2)\) (on \(U_j\) one uses \(\log (|x|^2/|x_j|^2)\) in place of \(\log (1 + |w|^2) = \log (|x|^2/|x_0|^2)\); on overlaps these differ by \(\log |x_k/x_j|^2\), the logarithm of the squared modulus of a nowhere vanishing holomorphic function, which \(\partial \bar\partial \) kills); hence \(\mathcal{O}(1)\) is positive, with \(\frac{i}{2\pi }F = \omega _{FS}\) and \(c_1(\mathcal{O}(1)) = [\omega _{FS}]\), the positive generator of \(H^2(\mathbb {C}\mathbb {P}^n; \mathbb {Z})\) (Example 38.2.5).
