27.5 Upper and lower limits, and series0118

Complete. This chapter is written; its proofs await independent checking.

0119 Definition 27.5.1

For a real sequence \((a_n)\) let \(\limsup _n a_n = \inf _n\sup _{k \geq n}a_k\) and \(\liminf _n a_n = \sup _n\inf _{k \geq n}a_k\), with values in the extended real line.

011A Proposition 27.5.2

  1. A bounded monotone real sequence converges, to its supremum or infimum.

  2. \((a_n)\) converges to \(a \in \mathbb {R}\) if and only if \(\limsup a_n = \liminf a_n = a\).

  3. (Bolzano–Weierstrass) Every bounded sequence in \(\mathbb {R}^n\) has a convergent subsequence.

Proof â–¼

(1) is Proposition 27.2.10. (2) The sequences \(\sup _{k \geq n}a_k\) and \(\inf _{k \geq n}a_k\) are monotone and bracket \(a_n\). If both converge to \(a\), so does \(a_n\); conversely, if \(|a_k - a| {\lt} \varepsilon \) for \(k \geq N\), both lie within \(\varepsilon \) of \(a\) for \(n \geq N\). (3) A bounded set lies in a closed cube, which is compact (Theorem 18.6.5) and hence sequentially compact (Theorem 18.7.4).

011B Definition 27.5.3

Let \(V\) be a normed space. A series \(\sum _n v_n\) converges to \(s\) if the partial sums \(s_N = \sum _{n \leq N}v_n\) converge to \(s\), and it converges absolutely if \(\sum _n\| v_n\| {\lt} \infty \).

011C Proposition 27.5.4

Let \(V\) be a Banach space.

  1. An absolutely convergent series converges, and every rearrangement \(\sum _n v_{\sigma (n)}\) (\(\sigma \) a bijection of \(\mathbb {N}\)) converges to the same sum.

  2. (Comparison) If \(\| v_n\| \leq c_n\) and \(\sum c_n {\lt} \infty \), then \(\sum v_n\) converges absolutely.

  3. (Root and ratio tests) If \(\limsup \| v_n\| ^{1/n} {\lt} 1\), or \(v_n \neq 0\) and \(\limsup \| v_{n+1}\| /\| v_n\| {\lt} 1\), then \(\sum v_n\) converges absolutely. If \(\limsup \| v_n\| ^{1/n} {\gt} 1\), it diverges.

  4. (Geometric series) For \(z \in \mathbb {C}\) with \(|z| {\lt} 1\), \(\sum _n z^n = 1/(1 - z)\).

  5. (Weierstrass \(M\)-test) If \(f_n \colon X \to V\) satisfy \(\sup _x\| f_n(x)\| \leq M_n\) with \(\sum M_n {\lt} \infty \), then \(\sum f_n\) converges uniformly.

Proof â–¼

(1) \(\| s_M - s_N\| \leq \sum _{N {\lt} n \leq M}\| v_n\| \), so the partial sums are Cauchy. For a rearrangement, given \(\varepsilon \) choose \(N\) with \(\sum _{n \geq N}\| v_n\| {\lt} \varepsilon \) and then \(M\) with \(\{ 0, \ldots , N-1\} \subseteq \sigma (\{ 0, \ldots , M\} )\); for \(m \geq M\), \(\| \sum _{k \leq m}v_{\sigma (k)} - s_{N-1}\| \leq \sum _{n \geq N}\| v_n\| {\lt} \varepsilon \), and \(\| s_{N-1} - s\| \leq \varepsilon \). (2) follows from (1). (3) If \(\limsup \| v_n\| ^{1/n} {\lt} q {\lt} 1\), then \(\| v_n\| \leq q^n\) for large \(n\); compare with \(\sum q^n\) using (4). If the ratio limsup is \({\lt} q {\lt} 1\), then \(\| v_n\| \leq Cq^n\) for large \(n\). If \(\limsup \| v_n\| ^{1/n} {\gt} 1\), then \(\| v_n\| {\gt} 1\) infinitely often, so \(v_n \not\to 0\) and the partial sums are not Cauchy. (4) \((1 - z)\sum _{n \leq N}z^n = 1 - z^{N+1}\), and \(|z|^N \to 0\): if \(0 {\lt} |z| {\lt} 1\) write \(1/|z| = 1 + h\), so \(|z|^{-N} \geq 1 + Nh\). (5) The partial sums are bounded and uniformly Cauchy, and the space \(B(X, V)\) of bounded maps is complete (Proposition 18.7.2).

02TC Proposition 27.5.5 More convergence tests

Let \((a_n)\), \((b_n)\) be sequences of real numbers.

  1. If \(\sum a_n\) converges, then \(a_n \to 0\). The converse fails: the harmonic series \(\sum _{n \geq 1}1/n\) diverges.

  2. (Limit comparison) If \(a_n, b_n {\gt} 0\) and \(a_n/b_n \to L \in (0, \infty )\), then \(\sum a_n\) and \(\sum b_n\) both converge or both diverge. In particular this holds if \(a_n \sim b_n\), that is, \(a_n/b_n \to 1\).

  3. (Cauchy condensation) If \(a_1 \geq a_2 \geq \cdots \geq 0\), then \(\sum _{n \geq 1}a_n\) converges if and only if \(\sum _{k \geq 0}2^ka_{2^k}\) converges. Consequently \(\sum _{n \geq 1}n^{-p}\) converges if and only if \(p {\gt} 1\), and \(\sum _{n \geq 2}1/(n(\log n)^p)\) converges if and only if \(p {\gt} 1\).

  4. (Ratio and root) If \(a_n {\gt} 0\), then \(\liminf \frac{a_{n+1}}{a_n} \leq \liminf a_n^{1/n} \leq \limsup a_n^{1/n} \leq \limsup \frac{a_{n+1}}{a_n}\); so whenever the ratio test applies, the root test does too. If \(a_{n+1} \geq a_n {\gt} 0\) for large \(n\), the series diverges. If the limit of the ratios or of the roots is \(1\), no conclusion is possible: \(\sum 1/n\) diverges and \(\sum 1/n^2\) converges, and both have limit \(1\).

  5. (Dirichlet) If \(b_n \in \mathbb {C}\) have bounded partial sums \(B_n = \sum _{k \leq n}b_k\) and \(a_n \geq a_{n+1} \to 0\), then \(\sum a_nb_n\) converges. For \(b_n = (-1)^n\) this is the alternating series test (Lemma 27.5.7 below).

Proof â–¼

(1) \(a_n = s_n - s_{n-1} \to s - s = 0\). For the harmonic series, \(s_{2n} - s_n = \sum _{n {\lt} k \leq 2n}\frac1k \geq n \cdot \frac1{2n} = \frac12\), so the partial sums are not Cauchy.

(2) A series of positive terms converges if and only if its partial sums are bounded (Proposition 27.5.2). For large \(n\), \(\frac L2b_n \leq a_n \leq 2Lb_n\), so the partial sums are bounded for both series or for neither.

(3) For \(2^k \leq n {\lt} 2^{k+1}\) there are \(2^k\) terms, each between \(a_{2^{k+1}}\) and \(a_{2^k}\), so \(\frac12 2^{k+1}a_{2^{k+1}} \leq \sum _{n = 2^k}^{2^{k+1} - 1}a_n \leq 2^ka_{2^k}\). Summing over \(k \leq K\) shows that the partial sums of the two series bound each other, up to a factor \(2\) and the term \(a_1\). For \(a_n = n^{-p}\) with \(p {\gt} 0\), \(2^ka_{2^k} = (2^{1-p})^k\), a geometric series converging if and only if \(p {\gt} 1\); for \(p \leq 0\) the terms do not tend to \(0\). For \(a_n = 1/(n(\log n)^p)\), \(2^ka_{2^k} = (k\log 2)^{-p}\), which reduces to the previous case.

(4) If \(\limsup a_{n+1}/a_n {\lt} q\), then \(a_{n+1} \leq qa_n\) for \(n \geq N\), so \(a_n \leq Cq^n\) and \(a_n^{1/n} \leq C^{1/n}q \to q\); hence \(\limsup a_n^{1/n} \leq q\). The inequality for the \(\liminf \) is proved in the same way. If \(a_n\) is eventually nondecreasing and positive, it does not tend to \(0\).

(5) Summation by parts: for \(m \leq N\), \(\sum _{n=m}^Na_nb_n = a_NB_N - a_mB_{m-1} + \sum _{n=m}^{N-1}(a_n - a_{n+1})B_n\). With \(|B_n| \leq M\) and \(a_n - a_{n+1} \geq 0\), the absolute value is at most \(M(a_N + a_m + (a_m - a_N)) = 2Ma_m\), which tends to \(0\); so the partial sums are Cauchy.

02TD Example 27.5.6

Combining tests. The tests are sufficient conditions, and in practice one combines them: first replace \(a_n\) by a simpler sequence with the same behaviour (limit comparison with an asymptotic equivalent), then apply the ratio, root or condensation test to it.

  1. \(\sum n!/n^n\): the ratio is \((n/(n + 1))^n = (1 + 1/n)^{-n} \to 1/e {\lt} 1\), so the series converges.

  2. \(\sum \sin (1/n)\) diverges and \(\sum (1 - \cos (1/n))\) converges, by limit comparison with \(\sum 1/n\) and \(\sum 1/(2n^2)\), since \(\sin t/t \to 1\) and \((1 - \cos t)/t^2 \to \frac12\) as \(t \to 0\).

  3. \(\sqrt{n + 1} - \sqrt n = 1/(\sqrt{n + 1} + \sqrt n) \sim 1/(2\sqrt n)\); so \(\sum (\sqrt{n + 1} - \sqrt n)\) diverges (its partial sums are \(\sqrt{N + 1} - 1\)) and \(\sum (\sqrt{n + 1} - \sqrt n)/n\) converges, by comparison with \(\sum n^{-3/2}\).

  4. \(\sum _{n \geq 1}\sin (n)/n\) converges by Dirichlet’s test: from \(2\sin \frac12\sin k = \cos (k - \frac12) - \cos (k + \frac12)\) the partial sums of \(\sum \sin k\) telescope and are bounded by \(1/\sin \frac12\). It does not converge absolutely, since \(|\sin n| \geq \sin ^2n = \frac12(1 - \cos 2n)\) and \(\sum \cos (2n)/n\) converges by the same argument while \(\sum 1/n\) diverges.

  5. \(\sum n^2/2^n\) converges by the root test (\(n^{2/n} \to 1\)), and \(\sum 2^n/n^2\) diverges since its terms tend to \(\infty \).

011D Lemma 27.5.7 Alternating series

If \(t_0 \geq t_1 \geq \cdots \geq 0\) and \(t_k \to 0\), then \(S = \sum _k(-1)^kt_k\) converges and \(S_{2m+1} \leq S \leq S_{2m}\) for all \(m\), where \(S_N\) are the partial sums.

Proof â–¼

\(S_{2m+2} - S_{2m} = -t_{2m+1} + t_{2m+2} \leq 0\) and \(S_{2m+3} - S_{2m+1} = t_{2m+2} - t_{2m+3} \geq 0\), and \(S_{2m+1} = S_{2m} - t_{2m+1} \leq S_{2m}\). So the even partial sums decrease, the odd ones increase, every odd one is below every even one, and their difference tends to \(0\).

Rearranging series. A finite sum does not depend on the order of its terms, and by Proposition 27.5.4(1) neither does the sum of an absolutely convergent series. For series that converge but not absolutely the order matters, and Riemann discovered that it matters as much as it possibly could: by reordering the terms one can make the sum anything one likes. A series \(\sum _na_n\) of real numbers is conditionally convergent if it converges but \(\sum _n|a_n| = \infty \); the alternating harmonic series \(\sum _{n \geq 1}(-1)^{n+1}/n\) is the basic example (Lemma 27.5.7 and Proposition 27.5.5(1)). Write \(a^+ = \max (a, 0)\) and \(a^- = \max (-a, 0)\) for the positive and negative parts of a real number, so that \(a = a^+ - a^-\) and \(|a| = a^+ + a^-\).

02ZF Lemma 27.5.8

If \(\sum _na_n\) is a conditionally convergent series of real numbers, then \(a_n \to 0\) and \(\sum _na_n^+ = \sum _na_n^- = \infty \). In particular infinitely many \(a_n\) are positive and infinitely many are negative.

Proof â–¼

\(a_n \to 0\) by Proposition 27.5.5(1). If \(\sum _na_n^+\) were finite, then \(\sum _na_n^- = \sum _n(a_n^+ - a_n)\) would converge, being the difference of two convergent series, and so would \(\sum _n|a_n| = \sum _n(a_n^+ + a_n^-)\), a contradiction. The same argument applies to \(\sum _na_n^-\). A series of non-negative terms with only finitely many nonzero terms is finite, so infinitely many \(a_n^+\) and infinitely many \(a_n^-\) are nonzero.

So the positive terms alone have infinite sum, and so do the negative terms alone; the series converges only because they are interleaved so as to cancel. This is what a rearrangement can exploit.

02ZG Theorem 27.5.9 Riemann’s rearrangement theorem

Let \(\sum _na_n\) be a conditionally convergent series of real numbers, and let \(-\infty \leq \alpha \leq \beta \leq \infty \). There is a bijection \(\sigma \colon \mathbb {N}\to \mathbb {N}\) such that the partial sums \(T_N = \sum _{n \leq N}a_{\sigma (n)}\) satisfy

\[ \liminf _{N \to \infty }T_N = \alpha \qquad \text{and}\qquad \limsup _{N \to \infty }T_N = \beta . \]

In particular, for every \(c \in \mathbb {R}\) some rearrangement converges to \(c\), and some rearrangements diverge to \(\infty \) and to \(-\infty \).

Proof â–¼

Targets. Choose real numbers \(\alpha _k \to \alpha \) and \(\beta _k \to \beta \) with \(\alpha _k {\lt} \beta _k\) and \(\alpha _k {\lt} \beta _{k+1}\) for all \(k \geq k_0\): put \(\beta _k = \beta + \frac1k\), \(k\) or \(-k\) according as \(\beta \) is finite, \(+\infty \) or \(-\infty \), and \(\alpha _k = \alpha - \frac1k\), \(k - 1\) or \(-k - 2\) according as \(\alpha \) is finite, \(+\infty \) or \(-\infty \). One checks the inequalities case by case for \(k\) large (recall \(\alpha \leq \beta \); for instance if \(\alpha = \beta = -\infty \), then \(\alpha _k = -k - 2 {\lt} -k - 1 = \beta _{k+1}\)).

Construction. Let \(p_1 {\lt} p_2 {\lt} \cdots \) be the indices \(n\) with \(a_n \geq 0\) and \(q_1 {\lt} q_2 {\lt} \cdots \) those with \(a_n {\lt} 0\); both lists are infinite by Lemma 27.5.8, and together they contain every index once. We build the rearrangement in stages \(k = k_0, k_0 + 1, \ldots \), each consisting of an up step and a down step. In the up step of stage \(k\) we append the next unused terms \(a_{p_j}\), in order, as long as the running sum is \(\leq \beta _k\), stopping as soon as it exceeds \(\beta _k\). In the down step we append the next unused terms \(a_{q_j}\), in order, until the running sum is \({\lt} \alpha _k\). Each step stops after finitely many terms: the unused positive terms are all but finitely many of the \(a_n^+\), so their sum is still infinite by Lemma 27.5.8, and likewise for the negative terms.

Every index is used. A down step adds at least one term, because it starts with a sum \({\gt} \beta _k {\gt} \alpha _k\); an up step of stage \(k + 1\) adds at least one term, because it starts with a sum \({\lt} \alpha _k {\lt} \beta _{k+1}\). So infinitely many \(p_j\) and infinitely many \(q_j\) are used, and since each list is used in order, all of them are. Hence the order in which the terms are appended defines a bijection \(\sigma \colon \mathbb {N}\to \mathbb {N}\).

The partial sums. Let \(U_k\) be the running sum at the end of the up step of stage \(k\) and \(L_k\) the one at the end of the down step. If the up step added terms, then just before its last term \(a_{u_k}\) the sum was \(\leq \beta _k\), so

\[ \beta _k {\lt} U_k \leq \beta _k + a_{u_k}, \qquad \text{and similarly}\qquad \alpha _k + a_{l_k} \leq L_k {\lt} \alpha _k, \]

with \(a_{l_k} {\lt} 0\) the last term of the down step (for \(k {\gt} k_0\) the up step always adds terms, as shown above). The indices \(u_k\) and \(l_k\) are distinct for distinct \(k\), so they tend to \(\infty \), and \(a_{u_k}, a_{l_k} \to 0\) because \(a_n \to 0\). Hence \(U_k - \beta _k \to 0\) and \(L_k - \alpha _k \to 0\), so \(U_k \to \beta \) and \(L_k \to \alpha \) (in the extended sense when \(\alpha \) or \(\beta \) is infinite). Within an up step the running sum increases, and within a down step it decreases; so for \(N\) in the up step of stage \(k\) we have \(L_{k-1} \leq T_N \leq U_k\), and for \(N\) in the down step \(L_k \leq T_N \leq U_k\). Therefore \(\limsup _NT_N \leq \limsup _kU_k = \beta \) and \(\liminf _NT_N \geq \liminf _kL_k = \alpha \); and the values \(T_N = U_k\) and \(T_N = L_k\) occur for every \(k\), so equality holds in both. The last statement is the case \(\alpha = \beta \).

02ZH Corollary 27.5.10

A series \(\sum _na_n\) of real numbers is absolutely convergent if and only if every rearrangement of it converges, and if and only if all its rearrangements converge to the same sum.

Proof â–¼

If \(\sum _n|a_n| {\lt} \infty \), every rearrangement converges to the same sum by Proposition 27.5.4(1). If \(\sum _n|a_n| = \infty \), either the series diverges, and then the identity rearrangement does not converge, or it is conditionally convergent, and then Theorem 27.5.9 with \(\alpha = \beta = \infty \) gives a rearrangement that diverges.

02ZI Example 27.5.11

  1. Let \(S = 1 - \frac12 + \frac13 - \frac14 + \cdots \). By Lemma 27.5.7, \(\frac12 = S_1 \leq S \leq S_0 = 1\), so \(S \neq 0\). Take one positive term followed by two negative ones:

    \[ 1 - \frac12 - \frac14 + \frac13 - \frac16 - \frac18 + \frac15 - \frac1{10} - \frac1{12} + \cdots \]

    Every term of \(S\) occurs exactly once: the odd denominators in order, and the even denominators in order, two at a time. The \(k\)-th group of three terms is \(\frac{1}{2k - 1} - \frac{1}{4k - 2} - \frac{1}{4k} = \frac{1}{4k - 2} - \frac{1}{4k} = \frac12\bigl(\frac{1}{2k - 1} - \frac{1}{2k}\bigr)\). So the partial sums after \(3m\) terms are half the partial sums of \(S\) after \(2m\) terms, and tend to \(\frac12S\); the partial sums in between differ from these by at most two terms, which tend to \(0\). So this rearrangement converges to \(\frac12S \neq S\).

  2. The proof of the theorem is an algorithm. To rearrange \(S\) so that it converges to \(c = 2\): take \(1 + \frac13 + \frac15 + \cdots \) until the sum exceeds \(2\), which happens at \(1 + \frac13 + \cdots + \frac1{15} \approx 2.02\) (eight terms), then subtract \(\frac12\) to get \(\approx 1.52 {\lt} 2\), then add \(\frac1{17} + \frac1{19} + \cdots \) until the sum exceeds \(2\) again, and so on. The positive terms are used much faster than the negative ones. This is how it must be: a rearrangement with a larger sum takes more positive terms per negative term, just as in (1) taking fewer positive terms per negative term gave a smaller sum.

  3. For complex series the theorem fails as stated: the rearrangements of \(\sum _ni(-1)^{n+1}/n\) have as sums exactly the points of the imaginary axis \(i\mathbb {R}\), by the theorem applied to the real series \(\sum _n(-1)^{n+1}/n\). For series in \(\mathbb {R}^m\) the possible sums of rearrangements form a more complicated set, which can be a line in the plane even when the series does not lie on a line, as the example \(\sum _n\bigl((-1)^{n+1}/n, (-1)^{n+1}/n + 1/n^2\bigr)\) shows: the second coordinate differs from the first by an absolutely convergent series, whose sum does not change, so every sum lies on the line \(y = x + \sum _n1/n^2\), and every point of it occurs.

011E Proposition 27.5.12 Cauchy product

If \(\sum a_n\) and \(\sum b_n\) are absolutely convergent series in \(\mathbb {C}\), then \(c_n = \sum _{k=0}^na_kb_{n-k}\) defines an absolutely convergent series with \(\sum c_n = (\sum a_n)(\sum b_n)\).

Proof â–¼

Let \(A = \sum |a_n|\) and \(B = \sum |b_n|\). Then \(\sum _{n \leq N}|c_n| \leq AB\), so \(\sum c_n\) converges absolutely. The difference \(\sum _{n \leq 2N}c_n - (\sum _{k \leq N}a_k)(\sum _{l \leq N}b_l)\) is the sum of \(a_kb_l\) over \(k + l \leq 2N\) with \(k {\gt} N\) or \(l {\gt} N\), bounded by \(B\sum _{k {\gt} N}|a_k| + A\sum _{l {\gt} N}|b_l| \to 0\).

011F Theorem 27.5.13

Let \(a_n \in \mathbb {C}\) and \(R = 1/\limsup _n|a_n|^{1/n} \in [0, \infty ]\), the radius of convergence. The power series \(\sum _n a_nz^n\) converges absolutely for \(|z| {\lt} R\), uniformly on \(|z| \leq r\) for every \(r {\lt} R\), and diverges for \(|z| {\gt} R\). The series \(\sum _n na_nz^{n-1}\) and \(\sum _n n^2a_nz^n\) have the same radius of convergence.

Proof â–¼

For \(|z| \leq r {\lt} R\) choose \(r {\lt} q {\lt} R\); then \(|a_n| \leq q^{-n}\) for large \(n\), so \(|a_nz^n| \leq (r/q)^n\), and the \(M\)-test applies. For \(|z| {\gt} R\), \(\limsup |a_nz^n|^{1/n} {\gt} 1\). Finally \(n^{1/n} \to 1\): writing \(n^{1/n} = 1 + h_n\), the binomial formula gives \(n \geq \binom {n}{2}h_n^2\), so \(h_n^2 \leq 2/(n-1)\). Hence \(\limsup |n^ka_n|^{1/n} = \limsup |a_n|^{1/n}\).
