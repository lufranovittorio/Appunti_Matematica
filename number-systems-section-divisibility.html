4.5 Divisibility and prime numbers009B

Complete. This chapter is written; its proofs await independent checking.

009C Definition 4.5.1

Let \(a, b \in \mathbb {Z}\). We say \(a\) divides \(b\), written \(a \mid b\), if \(b = ac\) for some \(c \in \mathbb {Z}\). An integer \(p \geq 2\) is prime if its only positive divisors are \(1\) and \(p\). A greatest common divisor of \(a\) and \(b\), not both zero, is a positive common divisor \(d\) divisible by every common divisor.

009D Theorem 4.5.2 Division with remainder

Let \(a, b \in \mathbb {Z}\) with \(b \neq 0\). There are unique \(q, r \in \mathbb {Z}\) with \(a = qb + r\) and \(0 \leq r {\lt} |b|\).

Proof â–¼

Uniqueness: if \(qb + r = q'b + r'\) then \((q - q')b = r' - r\) and \(|r' - r| {\lt} |b|\), so \(q = q'\) and \(r = r'\). Existence: the set \(\{ a - kb : k \in \mathbb {Z}\} \cap \mathbb {N}\) is nonempty (take \(k = -|a|\) if \(b {\gt} 0\) and \(k = |a|\) if \(b {\lt} 0\), for which \(a - kb = a + |a||b| \geq 0\)), so it has a least element \(r = a - qb\). If \(r \geq |b|\), then \(r - |b| = a - (q \pm 1)b\) is a smaller element.

009E Theorem 4.5.3 Bézout

Let \(a, b \in \mathbb {Z}\) be not both zero, and let \(d\) be the least positive element of \(\{ ax + by : x, y \in \mathbb {Z}\} \). Then \(d\) is a greatest common divisor of \(a\) and \(b\), and it is the only one. We write \(d = \gcd (a, b)\).

Proof â–¼

The set contains \(a^2 + b^2 {\gt} 0\), so \(d\) exists; write \(d = ax_0 + by_0\). Divide: \(a = qd + r\) with \(0 \leq r {\lt} d\). Then \(r = a(1 - qx_0) + b(-qy_0)\) lies in the set, so \(r = 0\) by minimality, and \(d \mid a\); similarly \(d \mid b\). Every common divisor of \(a\) and \(b\) divides \(ax_0 + by_0 = d\). If \(d'\) is another greatest common divisor, then \(d \mid d'\) and \(d' \mid d\), and both are positive, so \(d = d'\).

009F Lemma 4.5.4 Euclid

Let \(p\) be prime and \(a, b \in \mathbb {Z}\). If \(p \mid ab\), then \(p \mid a\) or \(p \mid b\).

Proof â–¼

If \(p \nmid a\), then \(\gcd (p, a) = 1\), since it is a positive divisor of \(p\) different from \(p\). By Theorem 4.5.3, \(1 = px + ay\), so \(b = pbx + aby\) is divisible by \(p\).

009G Theorem 4.5.5 Fundamental theorem of arithmetic

Every integer \(n \geq 2\) is a product \(n = p_1 p_2 \cdots p_k\) of primes, and if \(n = q_1 \cdots q_l\) is another such product, then \(k = l\) and the \(q_j\) are a permutation of the \(p_i\).

Proof â–¼

Existence: if some \(n \geq 2\) is not a product of primes, take the least such \(n\). It is not prime, so \(n = ab\) with \(2 \leq a, b {\lt} n\), and \(a\), \(b\) are products of primes, hence so is \(n\). Uniqueness, by induction on \(k\): \(p_k\) divides \(q_1 \cdots q_l\), so by Lemma 4.5.4 (and induction on \(l\)) it divides some \(q_j\), and then \(p_k = q_j\) since \(q_j\) is prime. Cancelling gives two factorisations of \(n/p_k\) and the induction hypothesis applies (if \(k = 1\), then \(n = p_1\) is prime and \(l = 1\)).

009H Theorem 4.5.6 Euclid

There are infinitely many prime numbers.

Proof â–¼

Let \(p_1, \ldots , p_k\) be primes and \(N = p_1 \cdots p_k + 1 \geq 2\). By Theorem 4.5.5, some prime \(p\) divides \(N\). If \(p = p_i\), then \(p\) divides \(N - p_1 \cdots p_k = 1\), which is impossible. So no finite set of primes contains all primes.

009I Example 4.5.7

Repeated division with remainder computes greatest common divisors, since \(\gcd (a, b) = \gcd (b, r)\) when \(a = qb + r\). For \(a = 252\), \(b = 198\): \(252 = 1 \cdot 198 + 54\), \(198 = 3 \cdot 54 + 36\), \(54 = 1 \cdot 36 + 18\), \(36 = 2 \cdot 18\). So \(\gcd (252, 198) = 18\), and going backwards, \(18 = 54 - 36 = 4 \cdot 54 - 198 = 4 \cdot 252 - 5 \cdot 198\).

009J Remark 4.5.8

Unique factorisation is a special property of \(\mathbb {Z}\). In the ring \(\mathbb {Z}[\sqrt{-5}] = \{ a + b\sqrt{-5} : a, b \in \mathbb {Z}\} \) one has \(6 = 2 \cdot 3 = (1 + \sqrt{-5})(1 - \sqrt{-5})\), and none of these four factors can be written as a product of two non-units. Such phenomena are studied in Chapters 8 and 13.
