3.7 The axiom of choice0084

Complete. This chapter is written; its proofs await independent checking.

0085 Definition 3.7.1

A choice function for a set \(F\) of nonempty sets is a function \(c \colon F \to \bigcup F\) with \(c(X) \in X\) for all \(X \in F\). The axiom of choice (AC) states that every set of nonempty sets has a choice function.

0086 Theorem 3.7.2

In ZF, the following statements are equivalent.

  1. The axiom of choice.

  2. (Well-ordering theorem) Every set admits a well-order.

  3. (Zorn’s lemma) Let \((P, \leq )\) be a partially ordered set in which every chain has an upper bound. Then \(P\) has a maximal element.

Proof â–¼

(1) \(\Rightarrow \) (2). Let \(A\) be a set and \(c\) a choice function for \(\mathcal{P}(A) \setminus \{ \emptyset \} \). Fix some \(\star \notin A\). By transfinite recursion let \(F(\alpha ) = c(A \setminus F[\alpha ])\) if \(A \setminus F[\alpha ] \neq \emptyset \), and \(F(\alpha ) = \star \) otherwise, where \(F[\alpha ] = \{ F(\beta ) : \beta {\lt} \alpha \} \). If \(F(\beta ) = \star \), then \(A \subseteq F[\beta ]\), so \(F(\alpha ) = \star \) for all \(\alpha {\gt} \beta \). Hence if \(F(\alpha ) \neq \star \), all \(F(\beta )\) with \(\beta \leq \alpha \) lie in \(A\), and \(F(\alpha ) \notin F[\alpha ]\); so these values are distinct. If \(F(\alpha ) \neq \star \) for all \(\alpha {\lt} h(A)\), then \(F\) would inject \(h(A)\) into \(A\), contradicting Theorem 3.6.9. So there is a least \(\alpha \) with \(F(\alpha ) = \star \), and then \(F|_\alpha \colon \alpha \to A\) is a bijection; transport the order of \(\alpha \).

(2) \(\Rightarrow \) (1). Well-order \(\bigcup F\) and let \(c(X)\) be the least element of \(X\).

(1) \(\Rightarrow \) (3). Suppose \(P\) has no maximal element. Then every chain \(C\) has a strict upper bound: an upper bound \(u\) of \(C\) is not maximal, so there is \(v {\gt} u\). Let \(c\) be a choice function for \(\mathcal{P}(P) \setminus \{ \emptyset \} \) and \(\star \notin P\). Define by transfinite recursion \(F(\alpha ) = c(S_\alpha )\), where \(S_\alpha \) is the set of strict upper bounds of \(F[\alpha ]\), if \(F[\alpha ] \subseteq P\) is a chain and \(S_\alpha \) is nonempty, and \(F(\alpha ) = \star \) otherwise. By induction on \(\alpha \), \(F[\alpha ]\) is a chain in \(P\) on which \(F\) is strictly increasing: if this holds for all \(\beta {\lt} \alpha \) then \(F[\alpha ]\) is a chain, so \(S_\alpha \neq \emptyset \) and \(F(\alpha )\) is greater than all \(F(\beta )\), \(\beta {\lt} \alpha \). Hence \(F\) injects \(h(P)\) into \(P\), contradicting Theorem 3.6.9.

(3) \(\Rightarrow \) (1). Let \(F\) be a set of nonempty sets. Let \(P\) be the set of functions \(c\) with \(\operatorname {dom}(c) \subseteq F\) and \(c(X) \in X\) for all \(X \in \operatorname {dom}(c)\), ordered by inclusion. The union of a chain in \(P\) is in \(P\) and is an upper bound. Let \(c\) be maximal. If \(X \in F\) were not in the domain of \(c\), choose \(x \in X\); then \(c \cup \{ (X, x)\} \) would be larger. So \(c\) is a choice function for \(F\).

0087 Remark 3.7.3

The well-ordering theorem was proved from the axiom of choice by Zermelo; see [Zer08]. Zorn’s lemma is from [Zor35]. It is the form of choice used most often in algebra, for instance to show that every vector space has a basis or that every nonzero ring has a maximal ideal. Gödel showed that if ZF is consistent then so is ZFC [G3̎8], and Cohen that the negation of AC is also consistent with ZF [Coh63]. From now on we work in ZFC.

0088 Proposition 3.7.4

Every set \(A\) has a cardinality \(|A|\). For all sets, \(A \approx B\) if and only if \(|A| = |B|\), and \(A \preceq B\) if and only if \(|A| \leq |B|\). In particular any two sets are comparable: \(A \preceq B\) or \(B \preceq A\).

Proof â–¼

By Theorem 3.7.2, every set can be well-ordered, so \(|A|\) is defined. The first equivalence is clear. If \(|A| \leq |B|\), then \(|A| \subseteq |B|\) and \(A \approx |A| \preceq |B| \approx B\). Conversely, if \(A \preceq B\) and \(|B| {\lt} |A|\), then \(|A| \preceq |B| \subseteq |A|\) and Theorem 3.6.2 would give \(|A| \approx |B|\), contradicting that \(|A|\) is a cardinal. The last statement follows from Theorem 3.5.4.

0089 Proposition 3.7.5

Let \(\kappa \) be an infinite cardinal and \((X_i)_{i \in I}\) a family with \(|I| \leq \kappa \) and \(|X_i| \leq \kappa \) for all \(i\). Then \(|\bigcup _{i \in I} X_i| \leq \kappa \). In particular a countable union of countable sets is countable.

Proof â–¼

We may assume that all \(X_i\) are nonempty. By the axiom of choice there is a family \((g_i)_{i \in I}\) of surjections \(g_i \colon \kappa \to X_i\) (choose one from each nonempty set of surjections). The map \((i, \xi ) \mapsto g_i(\xi )\) is a surjection \(q \colon I \times \kappa \to \bigcup _i X_i\). Since \(I \times \kappa \preceq \kappa \times \kappa \approx \kappa \) by Theorem 3.6.12, there is an injection \(j \colon I \times \kappa \to \kappa \). Sending \(u \in \bigcup _i X_i\) to the least element of \(j[q^{-1}[\{ u\} ]]\) is an injection \(\bigcup _i X_i \to \kappa \), because the sets \(q^{-1}[\{ u\} ]\) are nonempty and pairwise disjoint.

008A Corollary 3.7.6

If \(A\) and \(B\) are nonempty and at least one is infinite, then \(|A \times B| = |A \sqcup B| = \max (|A|, |B|)\), where \(A \sqcup B = (\{ 0\} \times A) \cup (\{ 1\} \times B)\).

Proof â–¼

Let \(\kappa = \max (|A|, |B|)\), an infinite cardinal, and say \(|A| = \kappa \). By Proposition 3.7.4 and Theorem 3.6.12, \(A \times B \preceq \kappa \times \kappa \approx \kappa \) and \(A \sqcup B \preceq 2 \times \kappa \preceq \kappa \times \kappa \approx \kappa \). Conversely \(A\) injects into \(A \sqcup B\), and into \(A \times B\) via \(a \mapsto (a, b_0)\) for a fixed \(b_0 \in B\). Conclude with Theorem 3.6.2.

008B Remark 3.7.7

We write \(2^\kappa \) for \(|\mathcal{P}(\kappa )|\); by Theorem 3.6.3, \(2^\kappa {\gt} \kappa \). The continuum hypothesis (CH) asserts \(2^{\aleph _0} = \aleph _1\). It is independent of ZFC: it can be neither proved [Coh63] nor refuted [G3̎8]. In Chapter 4 we show \(|\mathbb {R}| = 2^{\aleph _0}\).

008C Definition 3.7.8

Let \(\alpha \) be a limit ordinal. A map \(f \colon \beta \to \alpha \) is cofinal if its image is unbounded in \(\alpha \). The cofinality \(\operatorname {cf}(\alpha )\) is the least ordinal \(\beta \) admitting a cofinal map \(\beta \to \alpha \). An infinite cardinal \(\kappa \) is regular if \(\operatorname {cf}(\kappa ) = \kappa \), and singular otherwise.

008D Lemma 3.7.9

Let \(\kappa \) be a regular cardinal and \(X \subseteq \kappa \) a set with \(|X| {\lt} \kappa \). Then \(\sup X {\lt} \kappa \).

Proof â–¼

Let \(\mu = |X| {\lt} \kappa \) and let \(f \colon \mu \to X\) be a bijection. If \(\sup X = \kappa \), then \(f\) is a cofinal map \(\mu \to \kappa \), so \(\operatorname {cf}(\kappa ) \leq \mu {\lt} \kappa \).

008E Proposition 3.7.10

The cardinal \(\omega \) is regular, and every infinite successor cardinal \(\omega _{\alpha + 1}\) is regular.

Proof â–¼

A map from a finite ordinal \(n\) to \(\omega \) has a largest value, so it is not cofinal. Let \(\kappa = \omega _{\alpha + 1}\) and suppose \(f \colon \beta \to \kappa \) is cofinal with \(\beta {\lt} \kappa \). Then \(|\beta | \leq \omega _\alpha \), every \(f(\xi ) {\lt} \kappa \) has \(|f(\xi )| \leq \omega _\alpha \), and \(\kappa = \bigcup _{\xi {\lt} \beta } f(\xi )\) because \(\kappa \) is a limit ordinal. By Proposition 3.7.5, \(|\kappa | \leq \omega _\alpha \), a contradiction.

008F Counterexample 3.7.11

Not every infinite cardinal is regular. The map \(n \mapsto \omega _n\) is cofinal from \(\omega \) to \(\omega _\omega = \sup _n \omega _n\), so \(\operatorname {cf}(\omega _\omega ) = \omega {\lt} \omega _\omega \).

008G Definition 3.7.12

A cardinal \(\kappa \) is strongly inaccessible if it is uncountable, regular, and \(2^\lambda {\lt} \kappa \) for every cardinal \(\lambda {\lt} \kappa \).
