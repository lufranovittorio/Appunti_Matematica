\chapter{The Cycle Class Map}\label{cycle-class}
\chapterstatus{planned}

The cohomology class of an algebraic cycle, and the proof that it is a Hodge class.

\noindent\textbf{Prerequisites.} Chapter~\ref{intersection-theory} (Algebraic Cycles and Chow Groups), Chapter~\ref{gaga} (Analytic Spaces and GAGA), Chapter~\ref{de-rham} (de Rham Cohomology), Chapter~\ref{poincare-duality} (Topological Manifolds and Poincar\'e Duality) and Chapter~\ref{hodge-decomposition} (The Hodge Decomposition).

\noindent\textbf{Planned contents.}
\begin{itemize}
\item Fundamental classes of subvarieties via Borel--Moore homology.
\item Integration currents over singular subvarieties (Lelong's theorem).
\item The cycle class map $\CH^p(X) \to H^{2p}(X, \ZZ)$.
\item Compatibility with pullback, pushforward and products.
\item Classes of cycles are of type $(p,p)$.
\item Cycles and coherent sheaves: the Chern character.
\end{itemize}
