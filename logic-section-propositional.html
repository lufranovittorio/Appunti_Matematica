2.2 Propositional logic004C

Complete. This chapter is written; its proofs await independent checking.

004D Definition 2.2.1

Let \(P\) be a set, whose elements we call propositional variables, and let \(\neg \), \(\to \), \((\) and \()\) be four symbols not in \(P\). A string is a finite sequence of symbols. The set of propositional formulas over \(P\) is the smallest set of strings such that

  1. every \(p \in P\), viewed as a string of length one, is a formula;

  2. if \(\varphi \) is a formula, then \(\neg \varphi \) is a formula;

  3. if \(\varphi \) and \(\psi \) are formulas, then \((\varphi \to \psi )\) is a formula.

Here \(\neg \varphi \) denotes the string consisting of \(\neg \) followed by the symbols of \(\varphi \), and similarly for \((\varphi \to \psi )\).

004E Remark 2.2.2

Every formula is obtained from propositional variables by finitely many applications of the two operations, since the set of such strings contains \(P\) and is closed under the operations. Hence statements about all formulas can be proved by induction on formulas: it suffices to prove them for propositional variables and to show that they are preserved by the two operations.

004F Notation 2.2.3

We use the abbreviations \((\varphi \wedge \psi ) := \neg (\varphi \to \neg \psi )\), \((\varphi \vee \psi ) := (\neg \varphi \to \psi )\) and \((\varphi \leftrightarrow \psi ) := ((\varphi \to \psi ) \wedge (\psi \to \varphi ))\), and we omit outer parentheses when no confusion is possible.

004G Lemma 2.2.4

Let \(\varphi \) be a propositional formula. Then \(\varphi \) contains as many symbols \((\) as symbols \()\). Moreover, every proper initial segment of \(\varphi \) either consists only of symbols \(\neg \) (possibly none), or contains strictly more symbols \((\) than symbols \()\).

Proof â–¼

For a string \(u\) let \(b(u)\) be the number of symbols \((\) in \(u\) minus the number of symbols \()\) in \(u\). We argue by induction on \(\varphi \).

If \(\varphi = p\) is a variable, then \(b(p) = 0\) and the only proper initial segment is empty.

If \(\varphi = \neg \psi \), then \(b(\varphi ) = b(\psi ) = 0\). A proper initial segment of \(\varphi \) is empty or of the form \(\neg u\) with \(u\) a proper initial segment of \(\psi \). By induction, \(u\) consists of symbols \(\neg \) or \(b(u) {\gt} 0\), and the same holds for \(\neg u\).

If \(\varphi = (\psi \to \chi )\), then \(b(\varphi ) = 1 + b(\psi ) + b(\chi ) - 1 = 0\). A nonempty proper initial segment of \(\varphi \) has one of the forms \((u\) with \(u\) an initial segment of \(\psi \), or \((\psi \to u\) with \(u\) an initial segment of \(\chi \) (possibly empty or equal to \(\chi \)). By induction every initial segment \(u\) of \(\psi \) or \(\chi \) satisfies \(b(u) \geq 0\), so these segments have \(b \geq 1\).

004H Theorem 2.2.5 Unique readability

Every propositional formula \(\varphi \) satisfies exactly one of the following: \(\varphi \) is a propositional variable; \(\varphi = \neg \psi \) for a formula \(\psi \); \(\varphi = (\psi \to \chi )\) for formulas \(\psi \) and \(\chi \). In the second case \(\psi \) is uniquely determined, and in the third case \(\psi \) and \(\chi \) are uniquely determined.

Proof â–¼

The three cases are distinguished by the first symbol of \(\varphi \), and in the second case \(\psi \) is \(\varphi \) with its first symbol removed. Suppose \((\psi \to \chi ) = (\psi ' \to \chi ')\) with \(\psi \neq \psi '\). After the first symbol the two strings agree, so one of \(\psi \), \(\psi '\) is a proper initial segment of the other, say \(\psi \) of \(\psi '\). By Lemma 2.2.4, \(b(\psi ) = 0\), so \(\psi \) must consist only of symbols \(\neg \). But every formula contains at least one propositional variable (by induction on formulas), a contradiction. Hence \(\psi = \psi '\), and then \(\chi = \chi '\).

004I Definition 2.2.6

A truth assignment is a map \(v \colon P \to \{ 0, 1\} \). By Theorem 2.2.5, there is a unique map \(\bar v\) from the set of formulas to \(\{ 0, 1\} \), defined by recursion on formulas, such that \(\bar v(p) = v(p)\) for \(p \in P\), \(\bar v(\neg \varphi ) = 1 - \bar v(\varphi )\), and \(\bar v(\varphi \to \psi ) = 0\) if and only if \(\bar v(\varphi ) = 1\) and \(\bar v(\psi ) = 0\). We say that \(v\) satisfies \(\varphi \) if \(\bar v(\varphi ) = 1\), and that \(v\) satisfies a set of formulas \(\Sigma \) if it satisfies every element of \(\Sigma \).

004J Definition 2.2.7

A formula \(\varphi \) is a tautology if every truth assignment satisfies it. A set \(\Sigma \) of formulas tautologically implies \(\varphi \), written \(\Sigma \models \varphi \), if every truth assignment satisfying \(\Sigma \) satisfies \(\varphi \). A set of formulas is satisfiable if some truth assignment satisfies it.

004K Lemma 2.2.8

For every truth assignment \(v\): \(\bar v(\varphi \wedge \psi ) = 1\) if and only if \(\bar v(\varphi ) = \bar v(\psi ) = 1\); \(\bar v(\varphi \vee \psi ) = 1\) if and only if \(\bar v(\varphi ) = 1\) or \(\bar v(\psi ) = 1\); and \(\bar v(\varphi \leftrightarrow \psi ) = 1\) if and only if \(\bar v(\varphi ) = \bar v(\psi )\).

Proof â–¼

\(\bar v(\neg (\varphi \to \neg \psi )) = 1\) if and only if \(\bar v(\varphi \to \neg \psi ) = 0\), that is, \(\bar v(\varphi ) = 1\) and \(\bar v(\neg \psi ) = 0\). Next, \(\bar v(\neg \varphi \to \psi ) = 0\) if and only if \(\bar v(\varphi ) = 0\) and \(\bar v(\psi ) = 0\). The last statement follows from the first and the definition of \(\bar v\) on implications.

004L Example 2.2.9

The following are tautologies, as one checks by computing \(\bar v\) for the finitely many possible values of \(v\) on the variables involved: \(\varphi \vee \neg \varphi \) (excluded middle); \(\neg \neg \varphi \leftrightarrow \varphi \); \(((\varphi \to \psi ) \to \varphi ) \to \varphi \) (Peirce’s law); \(\neg (\varphi \wedge \psi ) \leftrightarrow (\neg \varphi \vee \neg \psi )\) (De Morgan); \((\varphi \to (\psi \to \chi )) \to ((\varphi \to \psi ) \to (\varphi \to \chi ))\). By contrast, \((\varphi \to \psi ) \to (\psi \to \varphi )\) is not a tautology when \(\varphi \) and \(\psi \) are distinct variables.

004M Proposition 2.2.10

Let \(p_1, \ldots , p_n\) be distinct propositional variables, \(n \geq 1\), and let \(F \colon \{ 0,1\} ^n \to \{ 0,1\} \) be any function. There is a formula \(\varphi \) whose variables are among \(p_1, \ldots , p_n\) such that \(\bar v(\varphi ) = F(v(p_1), \ldots , v(p_n))\) for every truth assignment \(v\).

Proof â–¼

For \(\varepsilon \in \{ 0,1\} ^n\) let \(\gamma _\varepsilon = \ell _1 \wedge \cdots \wedge \ell _n\), where \(\ell _i = p_i\) if \(\varepsilon _i = 1\) and \(\ell _i = \neg p_i\) if \(\varepsilon _i = 0\) (with parentheses grouped to the left). By Lemma 2.2.8, \(\bar v(\gamma _\varepsilon ) = 1\) if and only if \(v(p_i) = \varepsilon _i\) for all \(i\). If \(F\) is identically \(0\), take \(\varphi = p_1 \wedge \neg p_1\). Otherwise let \(\varphi \) be the disjunction of the \(\gamma _\varepsilon \) over all \(\varepsilon \) with \(F(\varepsilon ) = 1\). Then \(\bar v(\varphi ) = 1\) if and only if \((v(p_1), \ldots , v(p_n))\) is one of these \(\varepsilon \), that is, if and only if \(F(v(p_1), \ldots , v(p_n)) = 1\).

004N Counterexample 2.2.11

Proposition 2.2.10 fails if only \(\wedge \) and \(\vee \) may be used, taken as primitive connectives with the truth tables of Lemma 2.2.8. Indeed, by induction on such formulas, if \(v(p) \leq w(p)\) for every variable \(p\) then \(\bar v(\varphi ) \leq \bar w(\varphi )\). So no such formula computes the function \(F(x) = 1 - x\).

004O Theorem 2.2.12 Compactness, propositional case

Let \(P\) be countable and let \(\Sigma \) be a set of formulas over \(P\). If every finite subset of \(\Sigma \) is satisfiable, then \(\Sigma \) is satisfiable.

Proof â–¼

Call a set of formulas finitely satisfiable if all its finite subsets are satisfiable. The formulas are finite strings over a countable set of symbols, so they can be enumerated as \(\varphi _0, \varphi _1, \ldots \). Put \(\Delta _0 = \Sigma \), and let \(\Delta _{n+1} = \Delta _n \cup \{ \varphi _n\} \) if this set is finitely satisfiable, and \(\Delta _{n+1} = \Delta _n \cup \{ \neg \varphi _n\} \) otherwise.

Each \(\Delta _n\) is finitely satisfiable. Suppose \(\Delta _n\) is, but neither \(\Delta _n \cup \{ \varphi _n\} \) nor \(\Delta _n \cup \{ \neg \varphi _n\} \) is. Then there are finite \(\Delta , \Delta ' \subseteq \Delta _n\) such that \(\Delta \cup \{ \varphi _n\} \) and \(\Delta ' \cup \{ \neg \varphi _n\} \) are not satisfiable. A truth assignment \(v\) satisfying \(\Delta \cup \Delta '\) satisfies \(\varphi _n\) or \(\neg \varphi _n\), hence one of the two sets; contradiction.

Let \(\Delta = \bigcup _n \Delta _n\). Every finite subset of \(\Delta \) lies in some \(\Delta _n\), so \(\Delta \) is finitely satisfiable; in particular \(\Delta \) never contains both \(\psi \) and \(\neg \psi \). For every formula \(\psi \), exactly one of \(\psi \), \(\neg \psi \) lies in \(\Delta \). Define \(v(p) = 1\) if and only if \(p \in \Delta \). We show by induction on \(\psi \) that \(\bar v(\psi ) = 1\) if and only if \(\psi \in \Delta \). For variables this is the definition. For \(\neg \psi \): \(\bar v(\neg \psi ) = 1\) iff \(\psi \notin \Delta \) iff \(\neg \psi \in \Delta \). For \(\psi \to \chi \): if \((\psi \to \chi ) \in \Delta \), \(\psi \in \Delta \) and \(\chi \notin \Delta \), then \(\neg \chi \in \Delta \) and the finite set \(\{ \psi \to \chi , \psi , \neg \chi \} \) is not satisfiable. If \((\psi \to \chi ) \notin \Delta \), then \(\neg (\psi \to \chi ) \in \Delta \); if moreover \(\psi \notin \Delta \) or \(\chi \in \Delta \), then \(\Delta \) contains \(\{ \neg (\psi \to \chi ), \neg \psi \} \) or \(\{ \neg (\psi \to \chi ), \chi \} \), neither of which is satisfiable. So \((\psi \to \chi ) \in \Delta \) if and only if \(\psi \notin \Delta \) or \(\chi \in \Delta \), which by induction is equivalent to \(\bar v(\psi \to \chi ) = 1\). Hence \(v\) satisfies \(\Delta \supseteq \Sigma \).

004P Remark 2.2.13

The theorem holds for arbitrary sets \(P\), but the proof then needs a form of the axiom of choice (for instance Zorn’s lemma, Chapter 3) to replace the enumeration of all formulas.
