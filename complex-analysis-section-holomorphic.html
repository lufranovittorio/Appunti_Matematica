28.2 Holomorphic functions0147

Complete. This chapter is written; its proofs await independent checking.

0148 Definition 28.2.1

Let \(U \subseteq \mathbb {C}\) be open. A function \(f \colon U \to \mathbb {C}\) is holomorphic if the limit \(f'(a) = \lim _{h \to 0}(f(a + h) - f(a))/h\), \(h \in \mathbb {C}^\times \), exists for every \(a \in U\). An entire function is one holomorphic on \(\mathbb {C}\).

0149 Proposition 28.2.2 Cauchy–Riemann

Identify \(\mathbb {C}\) with \(\mathbb {R}^2\) and write \(f = u + iv\). Then \(f\) is holomorphic at \(a\) if and only if \(f\) is differentiable at \(a\) as a map of real variables (Definition 26.10.2) and its derivative is complex linear, which holds if and only if

\[ \partial _xu = \partial _yv, \qquad \partial _yu = -\partial _xv \quad \text{at } a. \]

Then \(f'(a) = \partial _xu + i\partial _xv\). Sums, products, quotients and composites of holomorphic functions are holomorphic, with the usual rules.

Proof â–¼

Complex differentiability at \(a\) says \(f(a + h) = f(a) + ch + o(|h|)\) with \(c = f'(a) \in \mathbb {C}\), which is real differentiability with \(Df(a)\) the real linear map \(h \mapsto ch\), that is, with matrix \(\left(\begin{smallmatrix} \alpha & -\beta \\ \beta & \alpha \end{smallmatrix}\right)\) for \(c = \alpha + i\beta \). Comparing with the Jacobian matrix \(\left(\begin{smallmatrix} \partial _xu & \partial _yu \\ \partial _xv & \partial _yv \end{smallmatrix}\right)\) gives the equations. The rules follow as in Proposition 26.6.2, whose proofs are valid over \(\mathbb {C}\).

014A Example 28.2.3

Polynomials are entire; \(1/z\) is holomorphic on \(\mathbb {C}^\times \); power series are holomorphic in their disc of convergence, with the termwise derivative (Theorem 26.6.19); \(\exp \) is entire with \(\exp ' = \exp \). The function \(\bar z\) is nowhere holomorphic, since \(\partial _xu = 1 \neq -1 = \partial _yv\).

014B Definition 28.2.4

A path is a piecewise continuously differentiable map \(\gamma \colon [a, b] \to \mathbb {C}\); it is closed if \(\gamma (a) = \gamma (b)\). Its image is \(\gamma ^*\) and its length is \(L(\gamma ) = \int _a^b|\gamma '(t)|\, dt\). For continuous \(f\) on \(\gamma ^*\),

\[ \int _\gamma f(z)\, dz = \int _a^bf(\gamma (t))\gamma '(t)\, dt. \]
014C Lemma 28.2.5

The integral is unchanged by increasing \(C^1\) reparametrisations, changes sign under reversal, and \(|\int _\gamma f| \leq L(\gamma )\sup _{\gamma ^*}|f|\). If \(f = F'\) for a holomorphic \(F\) on an open set containing \(\gamma ^*\), then \(\int _\gamma f = F(\gamma (b)) - F(\gamma (a))\); in particular \(\int _\gamma f = 0\) for closed \(\gamma \). For the circle \(\gamma (t) = a + re^{2\pi it}\), \(t \in [0, 1]\), one has \(\int _\gamma (z - a)^n\, dz = 0\) for \(n \neq -1\) and \(= 2\pi i\) for \(n = -1\).

Proof â–¼

Reparametrisation and reversal follow from the substitution rule (Corollary 26.8.4), the estimate from Proposition 26.8.2. If \(f = F'\), then \((F \circ \gamma )' = f(\gamma )\gamma '\) on each \(C^1\) piece, so the integral telescopes by the fundamental theorem of calculus. For the circle and \(n \neq -1\), \((z - a)^n\) has the primitive \((z - a)^{n+1}/(n + 1)\); for \(n = -1\) the integral is \(\int _0^12\pi i\, dt\).
